# UI/UX референсы для калькулятора подбора насосов

> Сводка для калькулятора КНС. Дата: 2026-05-02.
> Цель — собрать лучшие практики двухрежимного интерфейса, опросных листов, инженерных wizard.

---

## 1. NIELSEN NORMAN GROUP — Wizards: Definition and Design Recommendations

**URL:** https://www.nngroup.com/articles/wizards/

### Ключевые тезисы (применимо к нашему калькулятору):

1. **Wizards — для новичков и редких процессов** (configuration, setup), НЕ для опытных пользователей с повторяющимися задачами. **Это идеально матчится с нашим режимом «Любитель»** (новичок ставит КНС один-два раза в жизни).
2. **Прогресс-бар обязателен** — отображать список/диаграмму всех шагов с подсветкой текущего. Снижает когнитивную нагрузку.
3. **Линейный порядок шагов** — нельзя пропускать или переходить в произвольном порядке (для wizard). Но в режиме «Профессионал» это правило **должно нарушаться** — инженер хочет редактировать любой параметр в любой момент.
4. **Описательные кнопки навигации** — не «Далее», а «Далее → выбор насоса» или «Далее → расчёт сети».
5. **Сохранение прогресса** — wizard должен быть «gracefully interruptible»: можно прервать и вернуться. Для инженера, отвлёкшегося на звонок прямо на стройке, — критично.
6. **Помощь в контексте** — справочная информация рядом с полем (тултипы, expandable панели), не модалки и не отдельные страницы.
7. **Самодостаточность шагов** — на каждом шаге всё нужное под рукой, не нужно идти искать в другие части приложения.

### Применение к нашему дизайну:

- **Любитель:** строгий wizard 5-7 шагов, прогресс-бар, тултипы с пояснениями ([что такое напор?]), линейный порядок.
- **Профессионал:** «приборная панель» с одним длинным экраном/несколькими табами, можно редактировать любое поле, мгновенный пересчёт результата, экспорт PDF с любого момента.

## 2. AWWWARDS — Multi-step Forms / Configurators

**URL ленты:** https://www.awwwards.com/inspiration/interactive-multistep-form

### Топ-референсы из ленты:

- **Casella Catering Configurator** — https://www.awwwards.com/sites/casella-catering-configurator
  Образец красивого конфигуратора со «sleek interface» и intelligent input validation. Применимо: мы делаем конфигуратор КНС/ЛОС.
- **Multi-step Lead Form (Circlemount)** — https://www.awwwards.com/inspiration/multi-step-lead-form-circlemount-service-agency
  Лидогенерационный многошаговый формуляр. Применимо: финал калькулятора → опросный лист → отправка дилеру.

### Тренды дизайна 2024-2026 (наблюдения по ленте Awwwards):

1. **Glassmorphism + Neumorphism** в полях ввода;
2. **Микроанимации** на смене шагов (Framer Motion / View Transitions API);
3. **Прогресс — числовой и визуальный** одновременно;
4. **Контекстная помощь** через side panel с illustrations;
5. **Темная тема по умолчанию** для технических калькуляторов (снижает усталость глаз инженера);
6. **AI-подсказки inline** — поле имеет «Spark» иконку → подсказка от AI (что коррелирует с нашей мульти-агентной архитектурой).

## 3. РОССИЙСКИЕ ИНЖЕНЕРНЫЕ КАЛЬКУЛЯТОРЫ (общие)

### Kalk.pro
**URL:** https://kalk.pro/

**Что это:** агрегатор инженерных калькуляторов — лестницы, стропила, фундамент, бетон, обои. Для каждой задачи — отдельный калькулятор с вводом размеров и визуализацией 3D.

**Сильные стороны:**
- 3D-превью результата (для нашего: 3D-схема КНС с насосами + трубопроводом — сильный USP);
- Простой интерфейс «один большой шаг — куча полей слева — результат справа»;
- Печать результата в PDF;
- Бесплатно без регистрации.

**Слабости:**
- Нет двухрежимности (для всех уровней одинаковый интерфейс);
- Простоватый дизайн (не Awwwards-уровень).

### Kalk.bz
**URL:** https://kalk.bz/

Аналог kalk.pro, инженерные калькуляторы для СНГ.

## 4. ОПРОСНЫЕ ЛИСТЫ КАК UX-ПАТТЕРН (примеры из инжиниринга)

### КНС-опросные листы — типовая структура (см. `competitors_calculators.md`)

UX наблюдения:
- Большинство опросных листов — **PDF-формы для скачивания** (антипаттерн в 2026 — пользователь должен заполнять в Acrobat, печатать, сканировать, отправлять);
- Прогрессивные сайты (superkns.ru, plumb.ru) дают **интерактивную форму** прямо на сайте;
- Хорошие: SFA, ZavodKNS, Иртыш-ЭКО (Взлёт);
- **Лучший подход:** наш калькулятор сам генерирует опросный лист на основе введённых данных и отправляет дилеру. Не пользователь печатает форму — а калькулятор её формирует.

### Структура полей (для нашей реализации):

См. `competitors_calculators.md` раздел «Типовые поля опросного листа КНС». 6 групп: Гидравлика / Стоки / Площадка / Электрика / Управление / Конструктив. ~30-40 полей в полном опросном листе.

В режиме «Любитель» — **показываем только первую группу + 2-3 поля из других** (тип объекта + число пользователей + длина напорки). Остальное либо берём по умолчанию, либо запрашиваем уже на этапе «опросный лист → дилеру».

В режиме «Профессионал» — все 30+ полей доступны, но сгруппированы и с умолчаниями.

## 5. ДОПОЛНИТЕЛЬНЫЕ ИДЕИ (за пределами поиска)

### A. Конверсия Любитель → Профессионал

Кнопка «**+ Уточнить параметры (для инженера)**» прямо на финальном шаге упрощённого режима. При клике открываются дополнительные поля без сброса введённых данных.

### B. Live Q-H визуализация

При вводе любого параметра (расход, длина трубы, диаметр, материал) — **мгновенный пересчёт** характеристики сети и подсветка топ-3 насосов на одной диаграмме Q-H. Это «вау-эффект», которого нет у большинства конкурентов.

### C. AI-агент-консультант (наша мульти-агентная архитектура)

Боковая панель с чат-агентом: «**Как сварщик Алексей** — помогу разобраться». Агент:
- Объясняет термины (что такое NPSH, что такое Q-H, какая разница между vortex и cutter);
- Уточняет ввод (пользователь написал «дача на 5 человек, септик» → агент выводит уточняющие вопросы);
- Предлагает альтернативы (если выбран дорогой Grundfos → «бюджетный аналог Иртыш ЦМФ 16-25»);
- Bilingual ru/uz (см. `user_persona_welder.md`).

### D. Mobile-first + PWA

Сварщик/монтажник на объекте, телефон, перчатки, маска. UX-требования:
- Крупные tap-targets (≥48px);
- Высокий контраст (поверка маской);
- Голосовой ввод (диктовка цифр);
- Офлайн-режим (стройка без интернета);
- Светлая + тёмная тема + «солнечный день» режим (HDR-контраст).

### E. PDF-выгрузка как «коммерческое предложение»

В конце расчёта — кнопка «Сформировать КП». PDF содержит:
- Обложку с лого Серво-Полимер;
- Расчёт (с цитированием СП 32, СП 30);
- Спецификацию насоса + комплектующих;
- Ориентировочную смету;
- QR-код на сохранённую сессию (можно прислать дилеру и продолжить);
- Подпись и контакты.

## 6. РЕЗЮМЕ — UI-PRINCIPLES ДЛЯ НАШЕГО КАЛЬКУЛЯТОРА

| Принцип | Реализация |
|---|---|
| **Двухрежимность** | Любитель = wizard, Профессионал = dashboard |
| **Прогресс-бар** | Только в Любителе |
| **Контекстная помощь** | Tooltips + AI-агент в боковой панели |
| **Live-расчёт** | Q-H пересчитывается на каждый ввод |
| **Mobile-first PWA** | Перчатки/маска/офлайн |
| **PDF-выгрузка** | Опросный лист + КП + сохранение сессии (QR) |
| **AI-агент** | Bilingual ru/uz, мульти-агентная архитектура |
| **БД насосов** | Multi-brand, расширяемая |
| **Нормативы** | Цитаты СП 32/30/31 inline, ссылки на источники |
| **Конверсия в лид** | На любом шаге «Связаться с инженером» |
