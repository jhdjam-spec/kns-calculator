## 5. ГНОМ (АО ГМС Ливгидромаш / АО Ливнынасос, Орловская обл.)

**Бренд:** ГНОМ — старейшая российская марка дренажных/грязевых насосов. ГНОМ = «Грязевой Насос Одноступенчатый Моноблочный».

### Назначение
Перекачка загрязнённой воды плотностью до 1100 кг/м³, твёрдых включений до **10% по массе** при размере частиц **до 5 мм** (важно: НЕ для фекалий с крупными включениями!).

### Линейка
| Тип | Особенность |
|---|---|
| Бытовой чугунный | Стандарт |
| 1ГНОМ (пластик) | Облегчённый, для легких задач |
| Тр (Temperature-resistant) | До 60°C |
| Ex | Взрывозащищённое исполнение |

**Производительность:** 10-100 м³/ч, **напор:** 8-50 м (модели ГНОМ 10-10, 16-16, 25-20, 40-25, 53-10, 100-25 и т.д.).

**Маркировка:** ГНОМ Q-H {Тр}{Ex} {V} (например: ГНОМ 40-25Тр 380В).

### Источники

- https://pumpedia.ru/product/drenazhnye-nasosy/gnom/livgidromash/

- http://www.mos-nasos.ru/catalog/gnom/
- https://livnasos.pro/ — АО «Ливнынасос», современный производитель

> **Важная оговорка:** ГНОМ — это **дренажные** насосы, для канализации в классическом смысле (с фекалиями) подходят ограниченно. Калькулятор должен корректно различать: для септиков/КНС — НЕ ГНОМ; для строительного дренажа, осушения котлованов — ГНОМ идеально.

## ПРОБЕЛЫ — закрыть в deep-research

1. **PDF-каталог KAIQUAN WQ полностью** — структурированные таблицы всех моделей с Q-H точками. Источник: https://pump.ru/, https://ugpromsnab.ru/.
2. **Antarus** — каталог с antarus.ru.
3. **LEO** — каталог с leo-pumps.ru.
4. **Иртыш** — каталог с vzlet-omsk.ru, плюс опросные листы по типам станций.
5. **ГМС Ливгидромаш** — полный каталог ГНОМ с типоразмерами.
6. **Прайс-листы** — ориентировочные цены 2026 г. от трёх независимых дилеров (для оценки сметы в калькуляторе).
7. **Q-H кривые в машинно-читаемом виде** — у большинства производителей кривые только в pdf как картинки. Нужно либо договариваться с производителями (API/BD), либо парсить вручную, либо использовать библиотеку готовых кривых типа PumpData.io.
8. **Графический парсер кривых** — на следующем этапе оценить открытые библиотеки (например, WebPlotDigitizer, plotdigitizer Python) для пакетного извлечения Q-H точек из pdf.
9. **Сертификаты соответствия** — для каждой модели нужен ГОСТ Р/ТР ТС-сертификат (особенно для проектов с госэкспертизой). Внести в БД.
10. **Аналитика отказов / MTBF** — если найдём, повысит ценность калькулятора (выбор по надёжности, а не только Q-H).
