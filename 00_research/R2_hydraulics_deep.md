## 1. Гидроудар (Жуковский)

### 1.1 Базовая формула
```
ΔH = (a · Δv) / g                           [м вод. ст.]
ΔP = ρ · a · Δv                             [Па]
```
где `a` — скорость распространения волны давления в жидкости в трубе, `Δv` — изменение скорости (м/с) при остановке/пуске, `g = 9.81 м/с²`, `ρ` ≈ 1000 кг/м³ для воды.

Точная формула для скорости волны в трубе (учёт упругости стенки):
```
a = sqrt( (K/ρ) / (1 + (K/E) · (D/e) · c1) )
K = модуль объёмной упругости воды ≈ 2.2 ГПа
E = модуль Юнга материала трубы (Па)
D = внутренний диаметр, e = толщина стенки
c1 = коэффициент закрепления трубы (≈1)
```
Для калькулятора достаточно табличных средних:

### 1.2 Скорость волны `a` по материалам (типовые значения)

| Материал трубы | E, ГПа | a, м/с | Примечание |
|---|---:|---:|---|
| Сталь | 200 | **1100–1200** | для DN50–400, e=стандарт |
| Чугун (серый, ВЧШГ) | 100–170 | **1000–1200** | ВЧШГ ближе к 1200 |
| Бетон / асб-цемент | 30–40 | **1200–1400** | толстая стенка → высокая `a` |
| ПВХ (PVC) | 3.0 | **300–600** | сильно зависит от SDR |
| ПЭ100 (HDPE) | 1.0 | **200–400** | типично 290–350 для PN10 |

**Источник:** MDPI (FSI water hammer comparative analysis), IWA AQUA viscoelastic pipeline, Mueller Water Products.

### 1.3 Когда гидроудар становится критичным

Критическое (фаза-) время:
```
T_крит = 2L / a       [с]   ← время, за которое волна доходит до конца трассы и возвращается
```
- Если **t_закрытия задвижки < T_крит** → развивается **полный** ΔH Жуковского (быстрое закрытие).
- Если t_закрытия > 10·T_крит → ΔH ≈ ΔH_max · T_крит / t_закрытия (медленное закрытие, прямая зависимость).

**Численные ориентиры для нашего сегмента:**

| L, м | a (сталь, м/с) | T_крит, с | a (ПЭ100, м/с) | T_крит, с |
|---:|---:|---:|---:|---:|
| 100 | 1150 | 0.17 | 350 | 0.57 |
| 500 | 1150 | 0.87 | 350 | 2.86 |
| 1000 | 1150 | 1.74 | 350 | 5.71 |
| 2000 | 1150 | 3.48 | 350 | 11.4 |

**Пример (DEP-19):** L=2000 м, ПЭ100, v=1.5 м/с, остановка насоса 1 с (быстрое закрытие):
```
ΔH = 350 · 1.5 / 9.81 = 53.5 м  → недопустимо для PN10 (труба = 100 м вод. ст. = 10 бар)
```
То же в стали: ΔH = 1150·1.5/9.81 = **176 м** → разрушит даже PN16.

### 1.4 Меры защиты (для алгоритма / hand-off)

1. **Медленное закрытие задвижек:** t ≥ 10·T_крит = 20·L/a. Для L=1000 м, ПЭ → 57 с минимум.
2. **Обратные клапаны с замедлителем (tilting / nozzle-check)** — критично на напорной линии за насосом.
3. **Гидроаккумулятор / воздушный колпак** на коротких высоконапорных линиях.
4. **Surge tank (расширительная башня)** на длинных трассах.
5. **Гасители пневматические** (Charlatte, Flamco) — для L > 500 м.
6. **VFD soft-stop** на насосе — линейная разгрузка за 5–15 с.

**Триггер калькулятора:** при `L > 500 м` И `v > 1.0 м/с` — рассчитать ΔH = a·v/g, сравнить с PN_трубы; если ΔH > 50% от PN — обязательный hand-off + рекомендация защитного оборудования.

## 2. Параллельная работа насосов

### 2.1 Сложение Q-H характеристик

При параллельной работе **н одинаковых насосов** на общую сеть:
- При фиксированном H (одной точке) Q_общ = n · Q_одного **в идеальной геометрии**, но
- характеристика сети — парабола `H_сеть = dH + k·Q²`, поэтому при росте Q растёт H_сеть → рабочая точка сдвигается «вверх и вправо», но **не вдвое**.

```
H_общ.кривая(Q) = H_одного(Q/n)
```
(абсцисса делится на n при сохранении ординаты).

### 2.2 Реальное соотношение Q_общ / Q_одного

| n насосов | dH доминирует (мало k) | Сеть с большой долей трения |
|---:|---:|---:|
| 1 | 1.00 | 1.00 |
| 2 | 1.85–1.95 | **1.55–1.70** ← наш типовой случай КНС с L>200м |
| 3 | 2.6–2.8 | 1.9–2.2 |

**Источник:** U.S. DOE «Optimize Parallel Pumping», Pumps & Systems, ASHRAE-AEE.

**Критическое наблюдение исследования (см. references):**
> при коэффициенте кратности потока 1.6 максимальный КПД сохраняется ≥85% от номинального; при кратности 2.0 КПД падает до **≤70%**, электропотребление при росте Q всего на 25% увеличивается на **62%**.

### 2.3 Смещение рабочей точки и КПД

При параллельной работе каждый насос работает **левее** своей одиночной рабочей точки (меньше Q_на_насос, больше H). Это:
- **Хорошо**, если одиночный режим был справа от BEP (зона перегрузки) → пара уходит к BEP.
- **Плохо**, если одиночный был в BEP → пара уходит влево от BEP, η падает на 5–15%.

**Правило для DEP-15:**
```
Q_расч_на_один_насос_в_паре = (0.55…0.60) · Q_общий_расч
H_расч_на_один_насос_в_паре =  H_общий_расч (тот же H)
```
Подбираем по этой Q-H (а не Q_общий ÷ 2, как в наивной схеме).

### 2.4 Дополнительные правила

- **Не более 4** одинаковых насосов в параллель — дальше провал КПД и нестабильность.
- **Не смешивать** разнокалиберные насосы в параллель (тот, у кого max H ниже — будет работать в обратном режиме / закроется обратным клапаном).
- На каждом насосе **обязательно** обратный клапан (иначе при остановке — обратный поток через стоящий насос).

## 3. Вязкостные поправки HI (ANSI/HI 9.6.7-2021)

### 3.1 Когда применять

- **ν ≤ 5 cSt** → поправки не нужны (вода ν=1.0 cSt при 20°C).
- **5 < ν < 300 cSt** → стандартная процедура HI 9.6.7 (область применения).
- **ν > 300 cSt** или жидкость не-ньютоновская (густой шлам, тяжёлые нефтешламы) → метод HI **не применим**, нужен hand-off + спец. насосы (винтовые / шнековые).

Для канализации:
- Хоз-быт ν ≈ 1.0–1.5 cSt → поправки не нужны.
- Промстоки маслосодержащие, шламовые → **измерить ν**, если >5 cSt — применять.

### 3.2 Структура метода (поправки CQ, CH, Cη)

Базовая идея:
```
Q_visc = CQ · Q_water           (на BEP)
H_visc(Q) = CH(Q/Q_BEP) · H_water(Q/CQ)
η_visc = Cη · η_water
```

Все три коэффициента <1 (вязкая жидкость **снижает** Q, H, η).

**Параметр B** (HI 2010+) — единый аргумент для всех трёх C-коэффициентов:
```
B = 16.5 · ν^0.5 · H_BEP^0.0625 / (Q_BEP^0.375 · N^0.25)

ν — кинематическая вязкость, cSt
H_BEP — напор в BEP по воде, м
Q_BEP — подача в BEP по воде, м³/ч
N — об/мин
```
Область применения: **B ∈ [1, 40]**. При B < 1 → поправки не требуются. При B > 40 → метод не работает.

### 3.3 Типовые значения для ориентира (B ≈ 5–15, 50% Q_BEP, средние насосы)

| ν, cSt | B (для типового канального насоса 30 м³/ч, 20 м, 1450 об/мин) | CQ | CH (в BEP) | Cη |
|---:|---:|---:|---:|---:|
| 1 (вода) | <1 | 1.00 | 1.00 | 1.00 |
| 10 | 2.5 | 0.95 | 0.95 | 0.85 |
| 50 | 5.5 | 0.88 | 0.88 | 0.65 |
| 100 | 7.8 | 0.82 | 0.82 | 0.55 |
| 300 | 13.5 | 0.70 | 0.70 | 0.40 |

(Точные значения из графика HI 9.6.7 рис. 9.6.7.1; в калькулятор завести аппроксимацию по B.)

### 3.4 Пересчёт мощности

```
N_вал_visc = ρ_visc · g · Q_visc · H_visc / η_visc
```
Так как η падает быстрее всего, мощность растёт значительно: для ν=100 cSt мощность вала может быть **в 1.7× больше**, чем для воды при том же Q-H.

**Триггер калькулятора:** при wastewater_type = industrial и наличии масел/шламов — обязательно hand-off + запросить ν у инженера.

## 5. PN-классы ПЭ100 трубы

### 5.1 Связь SDR ↔ PN при 20°C, вода, MRS=10 МПа, C=1.25

PE100: MRS = 10 МПа, проектный коэффициент C = 1.25 (для воды по EN 12201).

```
PN = (20 · σ) / (SDR − 1)
σ = MRS / C = 10 / 1.25 = 8 МПа
→ PN = 160 / (SDR − 1)   [бар]
```

**Стандартизованная таблица (округление до ряда ISO):**

| SDR | Расчётный PN, бар | Стандарт PN | Применение в КНС/НС |
|---:|---:|---:|---|
| 7.4 | 25.0 | **PN25** | редко, очень высокий напор |
| 9 | 20.0 | **PN20** | высоконапорные ВЗУ |
| 11 | 16.0 | **PN16** | стандарт магистральной канализации с гидроударом |
| 13.6 | 12.7 | **PN12.5** | средний напор, длинные трассы |
| 17 | 10.0 | **PN10** | **default напорной канализации КНС** |
| 17.6 | 9.65 | PN10 (с запасом) | |
| 21 | 8.0 | **PN8** | низконапорные, короткие |
| 26 | 6.4 | **PN6.3** | гравитационные/полунапорные |
| 33 | 5.0 | **PN5** | дренаж, выпуски |
| 41 | 4.0 | PN4 | очень редко |

**Источники:** EN 12201-2, ISO 4427-2, pe100plus.com, Firat PE100 catalogue, Uponor PE100 Technical Datasheet, EngineeringToolbox.

### 5.2 Температурная коррекция

PN указан при **20°C**. При повышении T:
- 30°C → коэф. 0.87 (PN10 фактически = 8.7 бар)
- 40°C → 0.74
- 50°C → 0.62
- 60°C → 0.50
- 70°C → 0.40
- 80°C → 0.32 (предел применения PE100)

Для горячих стоков (T>30°C) — обязательное снижение класса.

### 5.3 Правило для калькулятора (DEP-19)

```
P_рабочее_трубы ≥ (H_расч + ΔH_гидроудар) / 10.2     [бар, 10.2 м вод.ст. = 1 бар]
P_рабочее_трубы / k_T ≥ ...                          (k_T — температурная коррекция)
→ выбираем PN из ряда {6.3, 8, 10, 12.5, 16, 20, 25}
→ обратно: SDR = 1 + 160/PN
```

### 6.4 Расширения / сужения

**Внезапное расширение** (D₁ → D₂, D₂ > D₁):
```
ζ = (1 − (D₁/D₂)²)²       — относится к скорости ДО расширения (v₁)
```
| D₁/D₂ | ζ |
|---:|---:|
| 1.0 | 0.00 |
| 0.8 | 0.13 |
| 0.6 | 0.41 |
| 0.4 | 0.71 |
| 0.2 | 0.92 |
| 0 (выход в резервуар) | **1.00** |

**Внезапное сужение** (D₁ → D₂, D₂ < D₁):
```
ζ ≈ 0.5 · (1 − (D₂/D₁)²)   — относится к скорости ПОСЛЕ сужения (v₂)
```
| D₂/D₁ | ζ |
|---:|---:|
| 1.0 | 0.00 |
| 0.8 | 0.18 |
| 0.6 | 0.32 |
| 0.4 | 0.42 |
| 0.2 | 0.48 |
| 0 (вход из резервуара, sharp) | **0.50** |
| Вход скруглённый | 0.05–0.10 |

### 6.6 Default-набор для типовой обвязки КНС (внутри корпуса, L=0)

| Элемент | Кол-во | ζ ед. | Σζ |
|---|---:|---:|---:|
| Отвод 90° R/D=1.5 | 4 | 0.21 | 0.84 |
| Тройник проходной | 1 | 0.10 | 0.10 |
| Задвижка | 1 | 0.15 | 0.15 |
| Обратный клапан | 1 | 8.0 | 8.0 |
