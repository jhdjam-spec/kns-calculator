# Теория подбора насосов для КНС/НС/ЛОС/станций повышения давления

> Сводка для калькулятора. Дата: 2026-05-02. Источники по URL.

---

## 1. ФОРМУЛА ПОЛНОГО НАПОРА

```
H = H_геом + H_тр + H_м + H_зап
```

| Компонент | Что считается |
|---|---|
| **H_геом** | геодезическая разность отметок (от уровня жидкости в приёмном резервуаре до точки сброса/ввода в коллектор), м |
| **H_тр** | потери напора по длине (трение по Дарси-Вейсбаху или Шевелеву), м |
| **H_м** | потери напора в местных сопротивлениях (отводы, тройники, задвижки, обратные клапаны), м |
| **H_зап** | свободный напор/запас на излив (обычно 1-3 м для канализации, до 5-10 м для систем повышения давления) |

В практике подбора КНС часто используется упрощённая формула:
```
H_расч = H_геом + H_потерь · (1,1...1,2)   // где 10-20% — запас
```

## 2. ПОТЕРИ ПО ДЛИНЕ — ФОРМУЛА ДАРСИ-ВЕЙСБАХА

```
H_тр = λ · (L / D) · (v² / 2g)     [м]
```

- λ — коэффициент гидравлического сопротивления (безразмерный)
- L — длина трубопровода, м
- D — внутренний диаметр, м
- v — средняя скорость, м/с
- g — 9,81 м/с²

Источник: https://ru.wikipedia.org/wiki/Формула_Дарси_—_Вейсбаха

### Коэффициент λ — формула Альтшуля (универсальная для турбулентного режима Re > 4000):

```
λ = 0,11 · ((k_э / D) + (68 / Re))^0,25
```
где `Re = v·D/ν`, ν — кинематическая вязкость (для воды при 20°C = 1,01·10⁻⁶ м²/с), k_э — эквивалентная шероховатость стенки.

Источники:
- https://ros-pipe.ru/clauses/raschet-poter-napora-v-truboprovodakh/
- https://inner.su/articles/formula-darsi-veysbakha/
- https://apeshnik.narod.ru/Gidravlika/gidrodin/gdn7.htm

### Эквивалентная шероховатость k_э, мм (фрагмент таблицы — стальные трубы)

| Тип трубы | k_э, мм |
|---|---|
| Стальные бесшовные новые | 0,014 |
| Стальные сварные новые | 0,05 |
| Стальные после умеренной коррозии | 0,15-0,2 |
| Стальные старые, заржавленные | 1,0 |

Источник: https://ros-pipe.ru/clauses/raschet-poter-napora-v-truboprovodakh/

> **Пробел:** k_э для ПЭ (типично 0,007-0,01 мм), ПВХ (0,01-0,02 мм), чугуна (0,25-1,0 мм), бетона (0,3-3,0 мм), асбоцемента (0,03-0,1 мм) — нужно подтянуть из СП 31 и из спецификаций производителей труб (Корсис ТУ).

### Альтернатива — формулы Шевелева (СНиП/СП РФ традиция):

Для напорных стальных труб (вода/стоки):
```
1000·i = A·v² / D^m   (где i — гидравлический уклон, безразмерный)
```
Коэффициенты A и m табличны (Шевелев Ф.А. — классика). Используется в СП 31.13330.

> **Пробел:** конкретные значения A, m для разных материалов и режимов из СП 31 — на следующем этапе.

## 3. МЕСТНЫЕ СОПРОТИВЛЕНИЯ — ФОРМУЛА ВЕЙСБАХА

```
H_м = ζ · (v² / 2g)     [м]
```
где ζ — коэффициент местного сопротивления (безразмерный), таблично для каждого элемента.

### Таблица ζ (фрагмент — турбулентный режим)

| Элемент | ζ |
|---|---|
| Задвижка открытая 100% | 0,15 |
| Задвижка открытая 50% | 2,0 |
| Обратный клапан DN 80-100 | 8,0 |
| Обратный клапан DN 250-300 | 2,0 |

Источник: https://ros-pipe.ru/clauses/raschet-poter-napora-v-truboprovodakh/

> **Пробел (критичный для калькулятора):** в найденном источнике нет коэффициентов для отводов 90° (ζ ≈ 0,5-1,1), 45° (ζ ≈ 0,3), тройников (ζ ≈ 1,0-2,0), переходников (ζ ≈ 0,1-0,5), вентилей (ζ ≈ 3-5), всасывающего колокола (ζ ≈ 2-10). Нужно вытянуть из Идельчика «Справочник по гидравлическим сопротивлениям» — на следующем этапе.

В практике расчёта КНС применяют упрощение: **сумма всех местных потерь = 10-30% от потерь по длине**, что закладывается коэффициентом 1,1-1,3 в формулу.

## 4. NPSH И КАВИТАЦИЯ

### Определения

- **NPSHa (Available)** — фактический кавитационный запас на всасывающем патрубке, определяется системой;
- **NPSHr (Required)** — требуемый запас, паспорт насоса (зависит от Q, есть кривая в каталоге);
- Условие безкавитационной работы: **NPSHa ≥ NPSHr + запас (0,5-1 м)**.

Источники: https://www.maxplant.ru/article/pump_npsh.php; https://kron-pump.ru/poleznaya-informatziya/npsh-opredelenie-i-raschet/; https://nasostmn.ru/articles/chto-takoe-npsh-npsha-npshr-i-kavitatsiya

### Формула максимальной геодезической высоты всасывания

```
H_max = H_atm − NPSHr − H_f − H_v − H_s
```
- H_atm — атмосферное давление (10,33 м водного столба на уровне моря)
- NPSHr — требуемый кавитационный запас (паспорт)
- H_f — потери напора во всасывающем трубопроводе
- H_v — давление насыщенных паров жидкости (для воды 20°C ≈ 0,24 м; 60°C ≈ 2,03 м)
- H_s — запас безопасности 0,5-1,5 м

> Теоретический предел всасывания на уровне моря — 10,33 м. Практически — 6-7 м для большинства насосов при 20°C.

> Для **погружных** КНС-насосов NPSH практически не лимитирует: насос всегда «под заливом» (давление столба жидкости над ним).

## 5. РАБОЧАЯ ТОЧКА Q-H, КПД, МОЩНОСТЬ

### Рабочая точка

Точка пересечения характеристики **сети** (квадратичная парабола от Q) и характеристики **насоса** (Q-H кривая из паспорта). Калькулятор должен:
1. По вводу пользователя построить характеристику сети: `H_сети(Q) = H_геом + k·Q²`, где k — суммарный гидравлический модуль;
2. По БД насосов найти модели, у которых рабочая точка попадает в зону максимального КПД (η_max ± 5-10%);
3. Отсортировать кандидатов по запасу/цене/мощности.

### Мощность на валу

```
N_вал = ρ · g · Q · H / η     [Вт]
```
- ρ = 1000 кг/м³ для воды (для стоков 1010-1050 кг/м³)
- Q — м³/с
- H — м
- η — КПД насоса (доля)

```
N_сети = N_вал / η_двиг   (η_двиг ≈ 0,85-0,95)
```

Дополнительный коэффициент запаса по мощности: 1,1-1,3 в зависимости от типа стоков.

## 6. КОЭФФИЦИЕНТ НЕРАВНОМЕРНОСТИ ВОДООТВЕДЕНИЯ

См. `norms.md` (раздел СП 32). Расчётный максимальный секундный расход:
```
q_max.sec = q_сред.сут · K_gen.max / (24·3600)     [л/с]
```

Полный алгоритм для калькулятора:
1. По типу объекта (коттедж/гостиница/офис) и числу пользователей считаем **q_сред.сут** в л/сут (СП 30 табл. А.2);
2. Переводим в средний секундный расход;
3. Применяем K_gen.max из СП 32 табл. 1 (3,0...1,44 в зависимости от расхода);
4. Получаем расчётный пиковый расход — **это Q насоса**.

> Полную таблицу извлечь из PDF на следующем этапе. По доступным комментариям:

## 8. ТИПЫ РАБОЧИХ КОЛЁС — ВЫБОР ПОД ТИП СТОКОВ

Источник: https://blog.craneengineering.net/impeller-types-for-pumping-ragging-and-solids; https://wilo.com/weil/...; https://www.deppmann.com/blog/...

| Тип колеса | Преимущества | Недостатки | Применение |
|---|---|---|---|
| **Vortex (вихревое, свободно-вихревое)** | Свободный проход без касания; идеально для волокнистых, тряпичных, неоднородных стоков | КПД на 25-30% ниже non-clog | Гостиницы, ТРЦ, рестораны (всё что флашут — салфетки, одноразка), высокое содержание твёрдых |
| **Single/Multi-channel (одноканальное/многоканальное закрытое)** | Высокий КПД (60-80%), большой свободный проход 50-100 мм | Чувствительно к волокнам — закусывает | Бытовые стоки от частного дома, коттеджа — после песколовки |
| **Open / Semi-open (полуоткрытое)** | Простое, дёшево, ремонтопригодно | Меньший свободный проход, эрозионный износ | Малые ЛОС, дренаж, малые расходы |
| **Cutter / Grinder (режущий/измельчитель)** | Малый диаметр напорного трубопровода (DN 32-65), измельчает всё подряд | Высокое потребление, износ ножей, шум | Малые КНС с длинной напоркой (коттедж > 50 м до коллектора), плохие подъезды для обслуживания |

**Правило выбора для калькулятора (черновое):**
- Если расчёт на **гостиницу/ТРЦ/общественное здание** → vortex (consumer-proof);
- Если **частный дом / коттедж** → single-channel или cutter (если трасса >50 м);
- Если **дождевая КНС** → channel или vortex (без cutter);
- Если **пром. стоки с включениями** → vortex или специализированный.

## 9. ОБЪЁМ ПРИЁМНОГО РЕЗЕРВУАРА КНС

Формула из АВОК (https://www.abok.ru/for_spec/articles.php?nid=8295) — с отсылкой к СП 32:

```
V_пр = Q / (4 · z)     [м³]
```
- Q — расход стоков, м³/ч
- z — число допустимых пусков насоса в час (4-15 в зависимости от мощности; чем мощнее — тем реже)

Глубина приёмного резервуара:
```
h_пр = V_пр / S_дна
```

В практике дополнительно учитывают «минимальный уровень перед нижним поплавком» и «аварийный объём» — итого V_общ ≈ 1,5-2 · V_пр.
