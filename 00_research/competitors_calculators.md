## ИНОСТРАННЫЕ — мейджоры

### 1. Grundfos Product Center (GPC)
**URL:** https://product-selection.grundfos.com/front-page.html

**Что это:** флагманский SaaS для подбора насосов Grundfos. Бывший WebCAPS, переписанный в новой парадигме.
**Доступ:** бесплатно, без регистрации (некоторые функции — после регистрации). Онлайн + offline-версия для Windows.
**Языки:** RU доступен, плюс ~24 языка.

**Функционал:**
- **«Быстрый подбор насоса»** — режим для пользователей, знающих свои Q и H. Вводит расход и напор → получает топ-N насосов.
- **«Подбор по применению»** — режим визарда: «отопление / водоснабжение / канализация / охлаждение / ...» → серия вопросов → подбор серии и модели.
- **Замена** — поиск аналога существующего насоса по марке/модели.
- **Анализ Q-H кривой** в браузере (интерактивная), сравнение нескольких насосов.
- **Документы:** ТКП, чертежи, видео по монтажу, спецификация запчастей.
- **PDF-выгрузка:** опросный лист, Pump Selection Sheet, спецификация.

**UX-фишки:**
- Чистый layout, левая панель ввода + правая визуализация Q-H;
- При вводе данных мгновенно перерисовывает кривую;
- Поддержка стоимости жизненного цикла (LCC) с расчётом окупаемости.

**Источники:**
- https://by.grundfos.com/grundfos-product-center.html
- https://nasostmn.ru/articles/programma-podbora-oborudovaniya-grundfos-product-center-(gpc)
- https://smtrading.ru/text/grundfos-product-center-teper-podbor-oborudovaniya-stal-proshche-i-bystree

### 2. Wilo Select 4
**URL:** https://wilo.com/ru/ru/Проектировщикам/Wilo-Select/

**Что это:** аналог GPC от Wilo. Online + Desktop. 24 языка.

**Функционал:**
- Подбор/замена насоса (можно вводить параметры существующего насоса другого бренда → подобрать аналог Wilo);
- Расчёт стоимости жизненного цикла (LCC) и срока окупаемости — фишка Wilo;
- Энергоаудит существующих насосов + экономический эффект замены;
- Q-H интерактив, Q-η, NPSH, Q-N (мощность);
- Печать паспорта подбора, заказ через дилера.

**Особенность:** Wilo Select 4 акцентирован на ЭЛЕКТРОЭКОНОМИЮ — это маркетинговый USP против Grundfos.

**Источники:**
- https://wilo.com/ru/ru/Проектировщикам/Wilo-Select/
- https://wilo.com/kz/ru/Проектировщикам/Wilo-Select/

### 6. Ridan (Pump Select) — конфигуратор
**URL:** https://ridan.ru/instruments/configurator-pumps

**Структура (4 этапа):**
1. **Выбор режима:** «Назначение системы» (упрощённый, для не-инженеров) ИЛИ «Семейство насосов» (для инженеров, выбирают серию вручную).
2. Ввод параметров (расход, напор, температура, тип жидкости).
3. Расчёт + визуализация: топ-моделей с Q-H кривыми.
4. **Оформление:** PDF-лист подбора, добавление в корзину, опросный лист для запроса у специалистов.

**Сильные стороны UX:**
- Реальная двухрежимность ✓ (как нужно нашему калькулятору);
- Прямая интеграция с складом/корзиной;
- PDF-расчётный лист с кодами моделей.

**Слабости (пробелы рынка):**
- Не показывает мобильную версию явно;
- Узкий BD (только Ridan);
- Нет опросника для нестандартных задач (где надо звонить инженеру).

**Типовые поля опросного листа КНС (синтез по нескольким источникам):**

1. **Гидравлика:**
   - Расход стоков (л/с или м³/сут или м³/ч)
   - Геодезический напор (м)
   - Длина и диаметр напорного трубопровода
   - Глубина залегания подводящего коллектора
2. **Стоки:**
   - Тип (бытовые / производственные / ливневые / смешанные)
   - Содержание включений (волокнистые, абразивные, фекалии)
   - Температура (°C)
   - pH, агрессивность
3. **Площадка:**
   - Климатический район (СНиП «Строительная климатология» / СП 131.13330)
   - Уровень грунтовых вод
   - Тип грунта
   - Сейсмика
4. **Электрика:**
   - 220 В / 380 В / 6 кВ
   - Мощность ввода
   - Резервный ввод (1 или 2 категория электроснабжения)
5. **Управление:**
   - Поплавковые выключатели / гидростатический датчик / ультразвук
   - Шкаф управления (стандартный / частотный преобразователь / ЧРП на каждый насос)
   - Диспетчеризация (GSM / Modbus / OPC-UA / интеграция в АСУ)
6. **Конструктив:**
   - Материал корпуса (стеклопластик / ПЭ / нерж. сталь / бетон)
   - Диаметр и высота
   - Тип крышки/люка (пешеходная / автомобильная А-15 / Б-125 / D-400)
   - Утепление, обогрев

## ВЫВОДЫ ДЛЯ НАШЕГО КАЛЬКУЛЯТОРА

### Что взять из лучших практик:
1. **Двухрежимность** — реализовано у Ridan (Назначение системы / Семейство насосов). У нас должно быть жёстче: «Любитель» = только Q,H,тип объекта; «Профессионал» = все 30+ полей опросного листа + ручная подгонка кривых.
2. **Q-H кривая интерактивная** (Grundfos, Wilo) — обязательно.
3. **PDF-выгрузка опросного листа** + спецификация подбора — must-have для лидогенерации.
4. **Wizard с прогресс-баром** (Ridan) — но с возможностью пропускать шаги для «Профессионала».
5. **Расчёт LCC и окупаемости** (Wilo) — хороший дифференциатор для КНС (электроэнергия — большая статья OPEX).
6. **Мобильная версия** (Grundfos) — критично, инженеры проектируют на объекте с планшетом.
7. **Поиск аналогов** (Grundfos, Wilo) — пользователь вводит модель Grundfos SLV → калькулятор предлагает аналог Иртыш/Antarus/KAIQUAN.
8. **Опросный лист как fallback** — если калькулятор не справился с нестандартной задачей, отправляет лид на инженера.

### Чего нет на рынке (наша ниша):
1. Калькулятор, **специализированный на КНС/ЛОС РФ-рынка** с нормативными таблицами СП 30/31/32, актуальными K_gen.max, опросными листами по умолчанию;
2. **Multi-brand-БД** — большинство калькуляторов привязаны к одному производителю; наша задача — поддержка нескольких (Иртыш, KAIQUAN, Antarus, LEO, ГНОМ);
3. **Локализованная PWA**-версия для сварщиков/монтажников с офлайн-режимом и крупными элементами UI (см. user persona `user_persona_welder.md`);
4. **AI-агент для нестандартных задач** — если ввод неполный, агент уточняет вопросами (мульти-агентная архитектура — изначальная фишка проекта).
