# Публичные эталоны (обезличенные)

Эта папка содержит **обезличенные** версии эталонных проектов из реальной практики Серво-Юг и партнёров.

## Что обезличено

- `gip`, `director`, `developer`, `head_of_construction`, `n_kontrol` → `[Роль]`
- `contract` → `[contract_id]`

## Что сохранено

Технические данные, шифры проектов, города расположения, юридические лица заказчиков (публично известные), нормативная база — всё остаётся для возможности воспроизведения расчётов и калибровки калькулятора.

## Скрипт обезличивания

`backend/_scripts/anonymize_etalons.py` — детерминированно превращает приватные эталоны (`02_dataset/etalons/downloads_*.json` в gitignore) в публичные.

## Файлы

- `etalons_public_2026-05-09.json` — 4 эталона из массива Downloads 2026-05-09 (Волноваха, Евпатория, Бондаревская ВЭС, Астрахань)
