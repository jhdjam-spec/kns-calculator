# Единый датасет — Калькулятор КНС/НС/СПД

**Версия:** 0.1
**Дата:** 2026-05-02
**Статус:** этап MVP, теоретическая база + структура БД насосов
**Лицензия:** MIT (для GitHub-публикации)

## Что внутри

Эта директория — **единый source of truth** для движка калькулятора. Всё что здесь — машинно-читаемое и готовое к импорту в backend (Python/FastAPI).

```
02_dataset/
├── README.md                       ← этот файл
├── theory/
│   ├── formulas.md                 ← все рабочие формулы с инженерными пометками
│   ├── coefficients.json           ← k_э, ζ, скорости, K_gen — машинно-читаемо
│   └── reliability_categories.md   ← СП 32 табл. 16-17, типовые схемы N+M
├── pumps/
│   ├── schema.json                 ← JSON-схема одной записи насоса
│   ├── pumps.json                  ← каталог насосов (наполнение по мере парсинга)
│   ├── producers.json              ← 8 брендов (KAIQUAN, Antarus, LEO, Aquario/Belamos/Unipump, Grundfos, Wilo, KSB, Pedrollo)
│   └── seed_kaiquan_50WQS202.json  ← один эталонный насос для теста алгоритма
├── fittings/
│   ├── schema.json                 ← схема записи арматуры
│   └── fittings_seed.json          ← минимальный набор обвязки КНС (8 позиций)
└── ENGINEER_NOTES.md               ← пометки «не работает / требует уточнения» по всему датасету
```

## Принципы организации

1. **JSON для данных, MD для теории** — машина читает первое, человек ориентируется по второму
2. **Все числовые таблицы — в `theory/coefficients.json`** — никаких разрозненных таблиц в текстах
3. **Инженерные пометки — в `ENGINEER_NOTES.md`** — там фиксируется всё «это не подходит / это под вопросом»
4. **Версионирование:** каждый JSON имеет поле `_version` и `_updated`
5. **Источники цитируются:** каждая таблица/формула несёт `_source` URL

## Связь с другими частями проекта

- `00_research/` — исходный web-research (теория, нормы, GitHub, MCP, конкуренты)
- `01_local_audit/` — аудит локальных файлов на Downloads

- `02_dataset/` — **этот** консолидированный источник для движка
- `03_implementation/` (будущее) — Python код калькулятора

## Лицензия и публикация

При публикации на GitHub:
- Лицензия **MIT** для кода и схем
- Тексты нормативных документов (СП 32, СП 31, ГОСТ Р 53682) — **только ссылки на первоисточник**, без копирования
- Q-H кривые и характеристики насосов производителей — **только агрегированные envelope** (Q_min, Q_max, H_min, H_max, P_max). Полные кривые — у производителей в открытом доступе через их каталоги
