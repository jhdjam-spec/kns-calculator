# Карта зависимостей — что от чего зависит при подборе насоса

**Версия:** 0.2 | **Дата:** 2026-05-03
**Changelog v0.2:** добавлены DEP-30..36 по результатам R2/R3 deep-research (air-locking, термозащита, phase-monitor, AOR/POR, NPSH при горячих стоках, anchoring SF, СПД ΔP старт/стоп).
**Цель:** показать ВСЕ причинно-следственные связи в расчёте КНС/НС/СПД, чтобы алгоритм НЕ выдал нерабочее решение.

Каждая зависимость снабжена:
- **DEP-XX** — идентификатор связи
- **причина → следствие**
- **антипаттерн** (что произойдёт, если связь нарушить)
- **проверка** (как алгоритм должен это контролировать)

---

## Слой 1. Входные данные → расчётные параметры

### DEP-01: Тип объекта → нормы расхода → Q_avg
```
Тип потребителя (квартира/гостиница/ТРЦ/...)
       ↓
Норма расхода л/сут на единицу (СП 30 А.2)
       ↓
Q_avg_сут = N_единиц × норма
       ↓
Q_avg_ls = Q_avg_сут / 86400
```
**Антипаттерн:** взять норму квартиры (200 л/сут) для гостиницы (220 л/сут на номер) → недооценка Q на 10-30%.
**Проверка:** строгий справочник из `coefficients.json::norms_water_consumption_lpd`, без свободного ввода нормы.

### DEP-02: Q_avg → K_gen.max → Q_расчётный
```
Q_avg_ls
       ↓
K_gen.max (СП 32 табл. 1, интерполяция по Q_avg)
       ↓
Q_max = Q_avg × K_gen.max  ← ЭТО ПОДАЁМ В МАТЧИНГ
```
**Антипаттерн:** считать Q без K_gen → насос работает на пределе при пиковой нагрузке, частые пуски, перегрев.
**Проверка:** алгоритм автоматически применяет K_gen, не требует от пользователя.

### DEP-03: Высоты точек → dH (геометрический напор)
```
H_точки_сброса − H_уровня_приёма = dH
```
**Антипаттерн:** пользователь указывает «перепад высот объекта» (например, 50 м между этажами) вместо реального dH насоса (5 м между приёмным резервуаром и колодцем сброса).
**Проверка:** UI должен показать СХЕМУ с двумя точками: 1) уровень жидкости в приёмном резервуаре КНС; 2) точка ввода в коллектор/самотёчную сеть.

### DEP-04: Длина трассы L + материал + Q → диаметр D
```
L (м) + материал (k_э) + Q (м³/с) + v_target (1.0...1.5 м/с)
       ↓
D = sqrt(4·Q / (π·v_target))
       ↓
Округление вверх до стандартного ряда [50,63,75,90,...,400] мм
       ↓
v_actual = 4·Q / (π·D²)
       ↓
Контроль: 0.7 ≤ v_actual ≤ 2.5 м/с
```
**Антипаттерн-1:** взять D = DN насоса (например, DN50) для Q=30 м³/ч → v=4.2 м/с → износ труб + гидроудар.
**Антипаттерн-2:** взять D вдвое больше расчётного (DN100 для Q=30 м³/ч) → v=1.06 м/с — но при стоках с твёрдыми включениями скорость падает ниже 0.7 → заиливание.
**Проверка:** алгоритм НЕ использует DN насоса как D трубы, всегда подбирает по v_target.

## Слой 2. Гидравлические потери

### DEP-05: D, v, L, k_э → Re → λ → H_тр
```
D, v → Re = v·D/ν
v, k_э → λ = 0.11·((k_э/D) + (68/Re))^0.25     (Альтшуль)
λ, L, D, v → H_тр = λ·(L/D)·(v²/2g)
```
**Антипаттерн:** взять λ=0.025 «по умолчанию» (для гладких труб) при материале «бетон» (k_э=1 мм) → недооценка H_тр в 2-3 раза.
**Проверка:** k_э из материала, всегда через формулу — никаких «среднестатистических λ».

### DEP-06: Состав обвязки → ζ → H_м
```
[отводы, задвижки, обр.клапаны, тройники] (количество × ζ_элемента)
       ↓
Σζ
       ↓
H_м = Σζ · v² / (2g)
```
**Антипаттерн-1:** не учитывать обратный клапан (ζ=8 для DN80) → недооценка H_м на 30-50%.
**Антипаттерн-2:** для L=0 (внутренняя обвязка КНС) считать H_м=0 → реально там 4 отвода + АТМ + задвижка + обратный клапан = 2-3 м потерь.
**Проверка:** для L=0 принимаем H_м = 2.0 м фиксировано; для L>0 — Σζ из default-набора (4 отвода + 2 арматуры) или из ввода пользователя в L1.

### DEP-07: H_тр + H_м + dH → H_full (расчётный напор насоса)
```
H_расч = (dH + H_тр + H_м) × (1 + safety)
safety = 0.10 (default), 0.05 (короткая обвязка), 0.20 (длинная трасса)
```
**Антипаттерн:** safety=0 → насос на пределе, работает 24/7 на 100% мощности, износ за полгода.
**Проверка:** safety никогда не <5%, default 10%.

## Слой 3. Свойства жидкости

### DEP-08: Тип стоков → плотность → мощность на валу
```
wastewater_type → ρ (1000-1050 кг/м³)
ρ, Q, H, η → N_вал = ρ·g·Q·H/η
```
**Антипаттерн:** для промстоков (ρ=1050) использовать ρ=1000 → недооценка мощности на 5%, выбирается двигатель с недостаточным запасом.
**Проверка:** ρ из справочника по wastewater_type.

### DEP-09: Тип стоков → свободный проход колеса → допустимые типы насосов
```
domestic   → free_passage ≥ 50 мм → vortex/single-channel/multi-channel
drainage   → free_passage ≥ 10 мм → open/channel
industrial → free_passage ≥ 80 мм → vortex/cutter
```
**Антипаттерн:** дренажный насос (free_passage=10 мм, open impeller) для хоз-быта → забивается тряпьём за неделю.
**Проверка:** ЖЁСТКИЙ фильтр в матчинге, не score, а исключение.

### DEP-10: Тип стоков → pH/абразив → материалы
```
domestic               → чугун OK
drainage               → чугун OK
industrial кислые      → нерж 316
industrial абразивные  → нерж 304 + износостойкое колесо
industrial нефтесодерж → специальное Ex-исполнение
```
**Антипаттерн:** чугунный насос на промстоки с pH<5 → сквозная коррозия за 3 месяца.
**Проверка:** при wastewater_type=industrial — обязательный hand-off к инженеру для уточнения pH/абразива.

### DEP-11: Температура жидкости → давление паров → NPSHa
```
T (°C) → H_v (м вод. ст.) — таблица в coefficients.json::vapour_pressure_water_m
H_v ↑ при T ↑
NPSHa = H_atm − H_v − H_f − H_z (для поверхностных насосов)
```
**Антипаттерн:** не учесть T для горячих стоков (банно-прачечные, +60°C, H_v=2 м) → кавитация даже на залитом насосе.
**Проверка:** для T>30°C обязательно показать тултип «горячие стоки — расчёт NPSHa обязателен».

## Слой 4. Подбор насоса

### DEP-12: Q, H_full, тип стоков → фильтр БД → кандидаты
```
1. Q ∈ [Q_min·0.85, Q_max·1.15] насоса
2. H_full ∈ [H_min, H_max·1.05]
3. wastewater_type ∈ pump.wastewater_compat
4. free_passage ≥ требуемый
5. _engineer_flag != 'not_recommended'
```
**Антипаттерн:** если фильтр пропускает на ±50% диапазона — будут предложения где насос работает в зоне 30% КПД, перегревается.
**Проверка:** жёсткий фильтр ±15% по Q, ±5% по H_max.

### DEP-13: Кандидаты → расстояние от BEP → ранжирование
```
distance_to_BEP = |Q_user − Q_BEP| / Q_BEP
       ↓
score (BEP_proximity weight 0.40)
```
**Антипаттерн:** ранжировать по цене → выбирается насос с Q_BEP далеко от Q_user → КПД 30% вместо 50% → расход электричества +60%, окупаемость минус.
**Проверка:** BEP_proximity — главный фактор, цена — последний.

### DEP-14: КПД в рабочей точке → мощность на валу → выбор двигателя
```
η_op (интерполяция из qh_curve) → N_вал = ρ·g·Q·H/η_op
N_двиг ≥ N_вал × safety_factor (1.10-1.25)
```
**Антипаттерн:** взять η=η_BEP вместо η_op → недооценка N_вал на 10-20% → двигатель работает на пределе.
**Проверка:** обязательная интерполяция КПД в Q_user; если нет полной кривой — флаг `_engineer_flag=needs_review`.

### DEP-15: Параллельная работа насосов (для схем 2+1, 3+1)
```
2 одинаковых насоса в параллель НЕ дают 2×Q при том же H
Реально: Q_общ ≈ 1.6×Q_одного, H_общ = H_одного
       ↓
характеристика сети сдвигает рабочую точку влево
       ↓
КПД каждого падает на 5-10%
```
**Антипаттерн:** считать «2 насоса = 2×Q» → недоподача при пиковой нагрузке.
**Проверка:** при N_working > 1 алгоритм должен использовать характеристики ПАРАЛЛЕЛЬНОЙ работы, не одиночной.

## Слой 5. Резервирование и пуски

### DEP-16: Категория объекта → схема резервирования
```
I    → 2+1 минимум
II   → 1+1 минимум
III  → 1+1 (бытовая) / 1+0 (дождевая)
```
**Антипаттерн:** I категория с 1+0 → перерыв подачи стоков → штраф Росприроднадзора + аварийный сброс.
**Проверка:** при I/II — минимум 1 резервный, всегда.

### DEP-17: Мощность насоса → допустимое число пусков/час → объём приёмного резервуара
```
P (кВт) → z (пусков/час) — таблица в coefficients.json
Q, z → V_приёмного = Q / (4·z)
       ↓
Высота приёмного резервуара = V_приёмного / S_дна + запас
       ↓
Высота КНС-корпуса = высота приёма + надстройка
```
**Антипаттерн:** взять z=15 (как для малого насоса) для большого 90 кВт → V_приёмный недостаточный → насос пускается каждые 4 минуты → перегрев двигателя за месяц.
**Проверка:** z из таблицы по фактической P_install, V_приёмного — расчётно.

### DEP-18: Уровни поплавков → стабильность работы
```
4 поплавка минимум:
1. Стоп-уровень (нижний, выше всаса насоса)
2. Старт-1 (включение 1-го насоса)
3. Старт-2 / Авария (включение 2-го или сигнал)
4. Переполнение (аварийный сигнал, иногда сброс)
```
**Антипаттерн:** 2 поплавка (только старт/стоп) → нет аварийного контроля → перелив.
**Проверка:** в BOM всегда минимум 4 поплавка.

## Слой 6. Напорный трубопровод

### DEP-19: L > 500 м → расчёт гидроудара → выбор класса трубы по давлению
```
L (м) + v (м/с) → ΔH_гидроудар = (a · v) / g  (формула Жуковского)
       a — скорость звука в жидкости в трубе (1000-1400 м/с для воды в стальной трубе)
       ΔH может достигать 30-50 м для длинных трасс
       ↓
Рабочее давление трубы ≥ H_расч + ΔH_гидроудар
       ↓
Выбор PN6 / PN10 / PN16 по требуемому давлению
```
**Антипаттерн:** для L=2000 м взять PE100 SDR17 PN10 без учёта гидроудара → разрыв трубы при остановке насоса.
**Проверка:** при L>500 м — флаг «расчёт гидроудара требуется», hand-off к инженеру.

### DEP-20: Скорость ≥ 0.7 м/с → защита от заиливания
```
Если v_actual < 0.7 м/с → стоки осаждаются на дне трубы
       ↓
Постепенное сужение сечения → рост H_тр → перегрузка насоса
       ↓
За 1-3 года — полное забивание участка
```
**Антипаттерн:** взять трубу с большим запасом (D=315 для Q=30 м³/ч → v=0.4 м/с) → заиливание.
**Проверка:** v_actual в [0.7, 2.5] — жёсткий контроль; если выходит — изменить D.

### DEP-21: Глубина заложения → требования к материалу + кольцевая жёсткость SN
```
Глубина 1.5-3 м, грунт обычный → SN8
Глубина 3-6 м или транспортная нагрузка → SN16
Под проездом / автобан → труба-футляр
```
**Антипаттерн:** SN8 под автодорогой → деформация трубы за 1-2 года.
**Проверка:** в опроснике L2 — обязательно глубина и тип нагрузки.

## Слой 7. Электрика и шкаф управления

### DEP-22: Мощность всех насосов суммарно → категория электроснабжения → ШУ с АВР
```
Σ P_install < 5 кВт → III категория, без АВР, ШУ простой
Σ P_install 5-50 кВт → II категория, АВР опционально
Σ P_install > 50 кВт → I категория, АВР обязателен
```
**Антипаттерн:** для крупной КНС с насосами 22 кВт каждый — ШУ без АВР → при пропадании одной фазы насосы стоят.
**Проверка:** в BOM-генераторе ШУ выбирается с учётом категории.

### DEP-23: Тип насоса (обычный / cutter / >7.5 кВт) → плавный пуск / ЧРП
```
< 7.5 кВт         → прямой пуск OK
7.5-22 кВт         → плавный пуск рекомендован
> 22 кВт ИЛИ cutter → плавный пуск ОБЯЗАТЕЛЕН
СПД (постоянное давление) → ЧРП ОБЯЗАТЕЛЕН
```
**Антипаттерн:** прямой пуск двигателя 30 кВт → пусковой ток 6-7×Iном → провалы напряжения, износ контакторов.
**Проверка:** в BOM выбор ШУ автоматический по P и type.

### DEP-24: Среда взрывоопасная → Ex-исполнение всё (насос + ШУ + кабели)
```
wastewater_type=industrial с углеводородами/растворителями
       ↓
Все компоненты класса Ex (ATEX/ГОСТ Р 51330)
       ↓
Цена ×2-3 от обычного исполнения
```
**Антипаттерн:** обычный насос на стоки с парами ацетона → искра → пожар.
**Проверка:** в L1 поле `Ex_required` — boolean. При true — фильтр БД исключает не-Ex модели.

## Слой 8. Корпус КНС

### DEP-25: Объём приёмного резервуара + поплавки → размеры корпуса
```
V_общий = V_приёмный × 1.5-2 (мин. уровень + аварийный)
S_дна и H_корпуса связаны: V = S_дна × H_рабочий
       ↓
Стандартные D корпусов: 1000, 1200, 1500, 1590, 2000, 2400, 3000, 4200 мм
```
**Антипаттерн:** взять корпус слишком узкий → высота 6+ м → проблема с монтажом и обслуживанием.
**Проверка:** соотношение H/D ≤ 3-4 для удобного обслуживания.

### DEP-26: Грунт + УГВ → необходимость якорения + выбор материала
```
Высокий УГВ (выше дна корпуса) → якорная плита обязательна (риск всплытия)
Слабый грунт                   → расширенное основание
Агрессивный грунт              → стеклопластик, не ПЭ
```
**Антипаттерн:** ПЭ корпус без якорения при УГВ выше дна → всплытие при опорожнении на ремонт.
**Проверка:** в L2 опроснике — обязательно УГВ и тип грунта.

## Слой 9. Особенности СПД

### DEP-27: СПД ≠ КНС — иной алгоритм
```
КНС:
  • Управление по уровню (поплавки)
  • Параметр: Q
  • Включается-выключается дискретно
  • Рабочая точка одна

СПД:
  • Управление по давлению
  • Параметр: H_const + Q_variable
  • Постоянная работа с регулировкой ЧРП
  • Рабочая точка плавающая
```
**Антипаттерн:** считать СПД как КНС с тем же алгоритмом → выбирается не та серия (погружные WQ вместо многоступенчатых CR/MVI).
**Проверка:** type=booster_station — отдельная ветка алгоритма.

### DEP-28: СПД → гидроаккумулятор → размер
```
Q_max системы (л/мин) → объём бака (л)
Типовой расчёт:  V_бак ≥ Q_max × 1 минута
Для Q=10 м³/ч (167 л/мин) → V_бак ≥ 167 л → ближайший 200 л
```
**Антипаттерн:** СПД без бака или с маленьким баком → насос пускается каждые 10-20 секунд → перегрев.

### DEP-29: СПД → датчики давления (всас + выход) + контроль сухого хода
```
Датчик всаса      → защита от сухого хода (P_всас < 0.5 бар → стоп)
Датчик выхода      → регулировка частоты (PID-контур)
Datalogger опц.    → история работы для диспетчеризации
```
**Антипаттерн:** СПД без датчика всаса → при отключении подачи воды насос работает «всухую» → сгорание уплотнений за 30 секунд.

## Слой 10 (v0.2). Воздухоудаление и термозащита

### DEP-30: Длинная напорка с подъёмами → air release valves
```
L > 100 м с участками подъём-спуск
       ↓
Газ накапливается на high points (особенно при v < 1 м/с)
       ↓
Эффективное сечение трубы падает
       ↓
Точка работы насоса смещается влево по Q-H кривой
       ↓
Recirculation, перегрев, износ
```
**Антипаттерн:** длинная напорная трасса с подъёмами без воздухоотводчиков → постепенное снижение Q на 30-50%.
**Проверка:** в L1/L2 поле «есть ли подъёмы на трассе» → если да и L>100 → флаг «нужны air-release valves в high points».

### DEP-31: Мощность насоса → необходимая термозащита обмоток
```
P ≤ 5.5 кВт          → thermal_overload (минимум)
5.5 кВт ≤ P ≤ 7.5    → +PTC или PT100
P > 7.5 кВт           → +phase_monitor (3ф)
```
**Антипаттерн:** ШУ погружного 11 кВт без PTC → при cycling-инциденте обмотки сгорают раньше срабатывания thermal_overload (20 сек задержка).
**Проверка:** BOM-генератор автоматически подбирает ШУ с нужным набором защит.

### DEP-32: Ток ≥ 7.5 кВт + 3 фазы → phase_monitor relay
```
3-фазный двигатель ≥7.5 кВт + reverse phase → вибрация и износ за часы
3-фазный двигатель + single-phasing → сгорание за 5-30 секунд
       ↓
phase_monitor отключает за 0.1-1 секунду
```
**Антипаттерн:** ШУ без phase_monitor для 3ф 15 кВт → авария при кратковременном отключении одной фазы.
**Проверка:** обязательно в BOM для всех 3ф ≥7.5 кВт.

## Слой 11 (v0.2). Зона работы насоса (AOR/POR)

### DEP-33: Q_user относительно Q_BEP → допустимость работы
```
Q_user ∈ [70%, 120%] от Q_BEP   → POR (Preferred) — composite_score МАКС
Q_user ∈ [40%, 150%] от Q_BEP   → AOR — score × 0.7 penalty
Q_user вне AOR                    → ИСКЛЮЧИТЬ из кандидатов
```
**Антипаттерн:** «насос Q_max=100 м³/ч, у нас 30 м³/ч → выбираем» → 30% от Q_BEP, recirculation, износ.
**Проверка:** в матчинге сначала проверяется AOR, потом ранжирование по POR-proximity.

### DEP-34: T_жидкости > 40°C → NPSH обязателен ДАЖЕ для погружных
```
T = 60°C → H_v = 2.03 м (давление паров)
T = 80°C → H_v = 5.4 м
       ↓
NPSHa = (P_atm - H_v) - z_всас + (Hg слой жидкости над насосом)
       ↓
При T=80°C NPSHa может быть отрицательным → кавитация на залитом насосе!
```
**Антипаттерн:** банно-прачечный комплекс, стоки +60°C, погружной без NPSH-проверки → кавитация.
**Проверка:** для T>40°C — обязательный NPSH-расчёт даже для погружных. Триггер hand-off TRIG-4.

### DEP-35: УГВ + материал корпуса → anchoring SF
```
ПЭ-корпус удельный вес 0.97 < 1
       ↓
При УГВ выше дна и опорожнении → подъёмная сила
       ↓
Якорная плита: вес плиты × SF ≥ подъёмная сила × 1.25
       ↓
SF минимум = 1.10 (NPCA), recommended = 1.25
```
**Антипаттерн:** ПЭ-корпус КНС 1500/3200 без якорения, УГВ 1м выше дна → при опорожнении на сервис всплывает.
**Проверка:** в L2 обязательно поле «УГВ относительно дна корпуса» → расчёт якорения.

### DEP-36: СПД → ΔP старт/стоп → ёмкость гидробака
```
ΔP старт/стоп ≥ 0.5 бар (минимум, рекомендуется 1.0-1.4)
       ↓
V_бак ≥ Q_max[л/мин] × 1 минута / (ΔP/P_max × 4)
       ↓
Для Q=10 м³/ч (167 л/мин), ΔP=1 бар, P_max=6 бар → V_бак ≥ 80 л → ставим 100 л (ближайший std)
```
**Антипаттерн:** СПД с ΔP=0.3 бар → пуск каждые 5-10 секунд → сгорание мотора за месяц.
**Проверка:** для type=booster_station — обязательная проверка ΔP и подбор бака.

## Слой 12 (v0.2). Гидроудар (для L>500 м)

### DEP-37: L>500 м → расчёт гидроудара Жуковского → выбор PN-класса трубы
```
L > 500 м, материал трубы (a, м/с)
       ↓
T_крит = 2L/a (сек)
       ↓
Если время закрытия задвижки/обр.клапана < T_крит → прямой удар: ΔH = a·v/g
       ↓
PN-класс трубы должен держать (H_full + ΔH) с запасом
```
**Антипаттерн (повторно из §11 formulas.md):** L=2000м ПЭ100 SDR17 PN10 без расчёта → разрыв трубы при отключении питания.
**Проверка:** триггер L>500 → флаг «расчёт гидроудара требуется» + рекомендация nozzle-check вместо ball-check.
