## §1. Полный напор насоса

### ✅ Базовая формула
```
H_full = dH + H_тр + H_м + H_зап
```

| Член | Что | Откуда |
|---|---|---|
| dH | Геометрический перепад точек, м | вход пользователя L0 |
| H_тр | Потери на трение по длине, м | формула Дарси-Вейсбаха ниже |
| H_м | Местные потери, м | сумма ζ·v²/(2g) или 10–15% от H_тр |
| H_зап | Запас, м | 0.10·(dH+H_тр+H_м) по умолчанию |

### ⚠️ Упрощённая формула (для предварительного подбора без точных потерь)
```
H_расч = dH + H_потерь × 1.15
```
**Когда применима:** L0 если пользователь не указал материал и кол-во арматуры.
**Не применима:** для трасс L > 500 м или с большим числом отводов — погрешность >25%.

## §2. Потери на трение по длине

### ✅ Дарси-Вейсбах (универсальная)
```
H_тр = λ · (L / D) · (v² / 2g)        [м]
```
g = 9.81 м/с². v = Q / (π·D²/4).

### ✅ Альтшуль для турбулентного режима (Re > 4000)
```
λ = 0.11 · ((k_э/D) + (68/Re))^0.25
```
Re = v·D/ν. ν(вода 20°C) = 1.01·10⁻⁶ м²/с.

**Когда применима:** напорная канализация, КНС, СПД при типовых v=1–2.5 м/с.

### ❌ Шевелев (классика СНиП)
```
1000·i = A·v² / D^m
```
**Не используем в L0:** коэффициенты A,m требуют точного знания материала и режима, а у нас вход — только 3 поля. **Подключаем в L2 (режим инженера).**

## §3. Местные потери

### ✅ Вейсбах (основная формула, v0.2)
```
H_м = Σ(ζᵢ) · v² / (2g)             [м]
```
ζ из `coefficients.json::local_resistance_zeta` (точные значения Идельчика).

### ✅ Default Σζ для типовой обвязки КНС (v0.2)
```
Типовой набор: 4×отвод_90°_R/D=1.5 + АТМ_DN50-100 + задвижка_открытая + обр.клапан_DN50-80 + выход_в_резервуар
Σζ = 4×0.21 + 0.80 + 0.15 + 8.0 + 1.0 = 10.79

При v=1.5 м/с:  H_м = 10.79 · 1.5²/(2·9.81) = 1.24 м
При v=1.0 м/с:  H_м = 0.55 м
```
Это коэффициент `typical_kns_obvyazka_sum_zeta` из coefficients.json.

### ⚠️ DEPRECATED v0.1 (упрощение)
~~`H_м ≈ 0.15 · H_тр`~~ — давало 0 при L=0 (нет трения), некорректно.
~~`H_м = 2.0 м фикс при L=0`~~ — слишком грубо, реально 1.0–1.3 м.

**v0.2: всегда считаем H_м через Σζ × v²/(2g).**

### 🔴 КРИТИЧНО: обратный клапан доминирует
ζ обратного клапана DN50-80 ≈ 8.0 (74% от Σζ типовой обвязки!).
**Замена:** ball-check (ζ=8) → **nozzle-check (ζ=1.5)** даёт экономию H_м в 4 раза.

## §4. NPSH и кавитация

### ⚠️ Максимальная высота всасывания
```
H_max_suction = H_atm − NPSHr − H_f − H_v − H_s
```
- H_atm = 10.33 м (уровень моря)
- NPSHr — паспорт насоса
- H_v — давление паров (см. coefficients.json::vapour_pressure_water_m)
- H_s — запас 0.5–1.5 м

### ❌ Не применяем для погружных КНС
Погружной насос всегда «под заливом» — NPSH не лимитирует. **NPSH-проверку включаем только для:** СПД с поверхностной установкой (Wilo-COR, Grundfos Hydro MPC, KSB Hyamat) и сухих установок.

## §5. Рабочая точка и КПД

### ✅ Характеристика сети (квадратичная парабола)
```
H_сети(Q) = dH + k · Q²
```
k — суммарный гидравлический модуль системы (зависит от L, D, материала, ζ).

### ✅ Рабочая точка
Точка пересечения H_насоса(Q) (паспортная Q-H кривая) и H_сети(Q).

### ✅ Мощность на валу
```
N_вал = ρ · g · Q · H / η             [Вт]
```
- ρ из `coefficients.json::wastewater_density_kgm3`
- Q в м³/с (! не м³/ч)
- η — КПД насоса в рабочей точке (доля)

### ✅ Электрическая мощность
```
N_сети = N_вал / η_двиг              [Вт]
η_двиг ≈ 0.85–0.95 в зависимости от P (выше — для больших)
```

### ⚠️ Запас по мощности
```
P_install ≥ N_сети × safety_factor
```
safety_factor ∈ [1.10, 1.25] — см. `coefficients.json::pump_power_safety_factor`.

## §6. Расход и неравномерность

### ✅ Расчётный пиковый расход (для подбора КНС)
```
Q_max = Q_avg × K_gen.max
```
K_gen.max — `coefficients.json::K_gen_max` (интерполяция).

### ✅ Из л/сут в м³/ч
```
Q_m3h = Q_lpd / 24 / 1000 × N_users × K_gen.max
```

### ⚠️ Для L0 «3 поля + норматив»
Если пользователь ввёл «150 номеров гостиницы» — алгоритм:
1. Q_avg_сут = 150 × 220 л/сут = 33 000 л/сут = 33 м³/сут
2. Q_avg_ls = 33000/86400 = 0.38 л/с → попадает в категорию <5 → K_gen.max = 3.0
3. Q_max = 0.38 × 3.0 = 1.15 л/с = **4.1 м³/ч**

**Это идёт на вход в матчинг.**

## §7. Объём приёмного резервуара КНС

### ✅ Формула АВОК (отсылка к СП 32)
```
V_приёмный = Q / (4 · z)              [м³]
```
- Q в м³/ч
- z — допустимое число пусков насоса в час (`coefficients.json::pump_starts_per_hour_max`)

### ✅ Полный объём корпуса с запасом
```
V_общий ≈ 1.5–2.0 × V_приёмный
```
(минимальный уровень + аварийный запас)

## §8. Подбор диаметра напорного трубопровода

### ✅ По заданной скорости (default v_target = 1.2 м/с)
```
D = sqrt(4 · Q / (π · v_target))      [м]
```
Q в м³/с. Округление вверх до ближайшего из стандартного ряда `coefficients.json::standard_pipe_diameters_mm`.

**Контроль:** v_фактическая = 4·Q/(π·D²), должна быть в [0.7, 2.5] м/с (см. velocity_limits_ms).

### ⚠️ Для длинных трасс (L > 1000 м)
Лучше брать **v_target = 1.0 м/с** — снижает потери на трение и затраты на электричество, хоть и увеличивает капекс на трубу.

### ❌ «Брать D всегда равным напорному патрубку насоса»
Распространённая ошибка. Это даёт скорость 2.5+ м/с при типичных Q, что приводит к избыточным потерям трения и износу. **Не делаем.**

|---|---|---|
| domestic | ≥50 | vortex, single-channel, multi-channel |

## §11. Гидроудар по Жуковскому (v0.2 НОВОЕ)

### ✅ Формула Жуковского
```
ΔH_удар = a · v / g     [м]
```
- `a` — скорость распространения ударной волны в трубе, м/с (см. `coefficients.json::wave_speed_ms_by_pipe_material`)
- `v` — скорость потока перед остановкой, м/с

### ✅ Критическое время
```
T_крит = 2L / a    [сек]
```
Если время закрытия задвижки t < T_крит — **прямой удар** (полная амплитуда ΔH = a·v/g).
Если t ≥ 10·T_крит — **слабый удар** (амплитуда падает в ~10 раз).

### ⚠️ Триггер калькулятора
**При L > 500 м:** обязательный расчёт гидроудара. Класс PN-трубы выбирать по сумме (H_full + ΔH_удар).
Пример: ПЭ100, L=2000 м, v=1.5 м/с, a=320 → ΔH = 49 м → если базовый H=15 м, общий PN-класс должен держать 64 м (~6.5 бар) → SDR21 PN8 минимум.

### ❌ ПЭ100 SDR17 PN10 для L=2000 м без расчёта гидроудара
Распространённая ошибка. Реально нужно SDR21 (PN8 при 20°C) или защита (soft-stop ЧРП, гидроколпак).

## §12. Параллельная работа насосов (v0.2 НОВОЕ)

### ✅ Реальное соотношение Q_общ / Q_одного

| n насосов | Q_общ / Q_одного (трение домин.) | Q_общ / Q_одного (статика домин.) |
|---|---|---|
| 2 | 1.55–1.70 | 1.85–1.95 |
| 3 | 2.10–2.40 | 2.70–2.85 |
| 4 | 2.60–3.00 | 3.50–3.75 |

**НЕ умножайте Q одного на N! Реально получается меньше.**

### ✅ Правило подбора параллельных
Каждый насос проектировать на:
```
Q_one = (0.55–0.60) × Q_total_required
H_one = H_full (тот же что для системы)
```

### ❌ «Q одного × 2 = Q общий»
Самая частая ошибка проектирования. Реально 1.6× при нормальной обвязке.

### ⚠️ КПД параллельной работы
При кратности 1.6× (правильный подбор) — каждый насос работает в 85% КПД.
При попытке выжать 2.0× — КПД падает до ≤70%, расход энергии +25%.

## §13. Поправки на вязкость (HI 9.6.7) (v0.2 НОВОЕ)

### ⚠️ Когда применять
ν > 5 cSt — для воды ν=1 cSt, для разбавленных стоков ~1.5–2 cSt, для густых промстоков 20–200 cSt.

### ✅ Поправочные коэффициенты
```
Q_real = Q_паспорт × C_Q
H_real = H_паспорт × C_H
η_real = η_паспорт × C_eta
```
| ν, cSt | C_Q | C_H | C_eta |
|---|---|---|---|
| 5 | 0.96 | 0.96 | 0.92 |
| 50 | 0.88 | 0.88 | 0.65 |
| 100 | 0.82 | 0.82 | 0.55 |
| 200 | 0.75 | 0.75 | 0.42 |

### ❌ Подбор насоса для шламов по паспорту воды
При ν=100 cSt реальная Q будет 82% от паспортной → недоподача на 20%.
**При промстоках с подозрением на высокую вязкость — обязательный hand-off инженеру.**

## §14. AOR/POR зоны (ANSI/HI 9.6.3) (v0.2 НОВОЕ)

### ✅ Preferred Operating Region (POR)
```
70% × Q_BEP ≤ Q_рабочая ≤ 120% × Q_BEP
```
**Зона continuous operation — обязательна для КНС/НС/СПД 24/7.**

### ⚠️ Allowable Operating Region (AOR)
```
40% × Q_BEP ≤ Q_рабочая ≤ 150% × Q_BEP
```
Только для intermittent (кратковременные пиковые режимы).

### ❌ Работа вне AOR
- Износ подшипников/уплотнений ускоряется в 2–5 раз
- Recirculation на низких Q (<50% BEP)
- Cavitation на высоких Q (>120% BEP)

### ✅ Калькулятор должен:
- Кандидатов **в POR** → composite_score максимум
- Кандидатов **в AOR но вне POR** → penalty 0.3 в score
- Кандидатов **вне AOR** → исключить из выдачи (даже если Q-H envelope формально совпадает)

## §15. Расширения СП 32 + HI 9.6.x + HI 9.8 (R4 deep-research, 2026-05-04)

Добавлено по итогам обзора учебников Идельчика, Чугаева, Lobanoff & Ross, Karassik, KSB Lexicon, Hydraulic Institute Standards, СП 32.13330.2018 + дополнения АВОК и Flotenk. Полный список источников — в `00_research/R4_textbooks_deep.md`.

### ✅ §15.1. V_min — нижний контроль объёма приёмного резервуара
```
V_min = Q_1н × 5 / 60          [м³]
```
Q_1н — производительность одного насоса в м³/ч; 5 минут — минимум для откачки одним насосом без cycling-смерти.

**Применение:** калькулятор должен брать `V = max(V_рез по СП 32, V_min)` — иначе при малых Q расчётный V даёт недостаточный рабочий объём.

**Источник:** АВОК ст. 8095, Flotenk

### ✅ §15.2. Расширенная формула резервуара для α≥2 насосов
```
V = (T·Q)/(4·n·1000) + (α-1)·ΔH·S          [м³]
```
- T — время цикла в секундах (T = 3600/z, где z — число пусков/час)
- Q — подача одного насоса, л/с
- n — число одновременно работающих насосов
- α — общее число насосов (рабочие + резервные)
- ΔH — расстояние между датчиками уровня (м), типично 0.15–0.30 м
- S — площадь сечения резервуара, м²

**Источник:** Stormwater, Flotenk (по СП 32 п.8.2.10)

### ✅ §15.3. Минимальное время работы между пусками
```
t_min = 60 / z          [мин]
V_раб > (Q_нас − Q_приток) × t_min
```
**z по СП 32 п.8.2.15** (актуальная редакция):
- ≤22 кВт: z = 6 пусков/час
- 22–55 кВт: z = 10
- ≥55 кВт: z = 15

**ВАЖНО:** в нашем `coefficients.json::pump_starts_per_hour_max` шкала перевёрнута (большие z для малых насосов). Это литература производителей (Grundfos, Wilo); СП 32 нормирует **минимально допустимый рабочий цикл** — обратное правило. Для production использовать **min(z_СП 32, z_паспорт)**.

### ✅ §15.4. ΔP_сброс в формуле H_full
```
H_full = dH + H_тр + H_м + ΔP_сброс + H_зап
```
**ΔP_сброс — свободный напор в точке сброса:**
- ≥1 м для бытовых стоков (сброс в колодец-смотровый)
- ≥3–5 м для дождевых (сброс в напорный коллектор)
- 0 м только для свободного слива в открытый водоём

**Источник:** МФМЦ Коломна, СП 31 §11

В §1 это пока зашито в H_зап (10–15%), но при ΔP_сброс=5 м запаса 10% от dH=5+H_тр=15 = 2 м может **не хватить**. Для длинных трасс с ΔP_сброс — выделять явно.

### ✅ §15.5. Минимальное погружение всасывающего патрубка (HI 9.8)
```
S_min / D = 1 + 2.3 × Fr
Fr = v / √(g · D)
```
- S_min — минимальное расстояние от поверхности воды до верха раструба, м
- D — диаметр всасывающего раструба, м
- v — скорость в раструбе, м/с
- g = 9.81 м/с²

**Применение:** для расчёта минимального **рабочего уровня** в корпусе КНС. Если уровень опустится ниже S_min → воздухозабор → кавитация → удар по подшипникам. Для типового погружного с DN50 раструбом и v=1.5 м/с: Fr ≈ 2.14, S_min/D ≈ 5.92, S_min ≈ 0.30 м.

**Источник:** Hydraulic Institute ANSI/HI 9.8-2024 «Pump Intake Design»

### ✅ §15.6. Specific Speed Ns (нс) для подбора колеса
```
Ns = n × √Q / H^0.75            [RPM·m³/s·m, СИ]
n — об/мин, Q — м³/с, H — м
```
**Допустимые диапазоны для канализационных:**
- Ns < 15 — радиальное колесо, низкий КПД (≤55%), но высокий H
- 15 ≤ Ns ≤ 80 — рабочий диапазон vortex/single-channel/multi-channel
- Ns > 80 — осевое, риск кавитации, малый H

**Применение:** добавить в composite_score фильтр `Ns_compatibility` — penalty для Ns < 15 и Ns > 80.

**Источник:** KSB Centrifugal Pump Lexicon, Lobanoff & Ross гл.2

### ✅ §15.7. NPSH margin по HI 9.6.1-2024
```
NPSHa ≥ NPSHR + max(1.0 м, 0.1 × NPSHR)
```
NPSHR — паспортное значение (с margin от NPSH3).
NPSHa — доступный NPSH на месте установки.

**Замена нашего «0.5–1.5 м запас» на формулу с обоснованием.** Минимум 1 м всегда, а для крупных насосов (NPSHR>10 м) — 10% от паспортного.

**Источник:** Hydraulic Institute ANSI/HI 9.6.1-2024

### ✅ §15.8. Якорный коэффициент безопасности для ПЭ-корпуса
```
F_подъём = ρ_воды × g × V_корпуса_погружённого
F_якоря = m_плита·g + m_грунта·g − F_арх_плиты
SF = F_якоря / F_подъём ≥ 1.10 (NPCA), ≥ 1.25 для зон с УГВ
```
Применение: при УГВ выше дна корпуса (юг РФ, прибрежные зоны) — расчёт обязателен; для D=2000 мм H=5000 мм объём вытеснения ~15.7 м³ → F_подъём ≈ 154 кН — серьёзная сила, без якоря ПЭ-корпус всплывает.

**Источник:** NPCA (National Precast Concrete Association) Anchoring Guidelines

### ⚠️ §15.9. Минимальная скорость 1.0 м/с в напорной канализации — жёсткий фильтр
```
v_min_pressure_sewage = 1.0 м/с (СП 32 §5.4)
v_min_drainage = 0.7 м/с (поверхностные стоки — без волокон)
v_min_clean = 0.6 м/с (после очистных)
```
**Для напорной бытовой канализации 1.0 м/с — это фильтр, не рекомендация.** Меньшая скорость → заиливание гарантированно. В `auto_select_diameter_mm` подбор диаметра должен вернуть **наибольший D, при котором v ≥ 1.0** (а не «целевые 1.2 м/с»).

### ⚠️ §15.10. Выбор z с учётом категории надёжности
СП 32 п.6.1 + табл.16/17:
- I категория → 2 рабочих + 1 резерв на месте + 1 на складе; z может быть **меньше** (резерв чаще включается)
- II категория → 1+1; z по мощности (СП 32 §8.2.15)
- III категория → 1+0 для малых, 1+1 для крупных

**Применение:** при `reliability_category="I"` снижать z в 1.5 раза (запас на резервирование).

## ❌ Решения, КОТОРЫЕ НЕ РАБОТАЮТ для нашего сегмента

### ❌ «Подбор только по Q без учёта H»
Часто менеджеры так делают — выдаёт некомпетентный результат. **Калькулятор обязан считать H_full.**

### ❌ «Один насос на все типы стоков»
Нельзя — vortex с КПД 35% на хоз-быт это норма, но на ливнёвку чистую — переплата по электричеству 30%/год. Сегментация обязательна.

### ❌ «Российский эквивалент Grundfos = всегда KAIQUAN»
Не всегда — у KAIQUAN нет полного покрытия CR-серии Grundfos (многоступенчатые СПД). Для СПД лучше Antarus MLV или Wilo-Helix.

### ❌ «Запас по напору 5%»
Слишком оптимистично. Минимум 10%, для длинных трасс — 15–20%. На L0 фиксируем 10%.

### ❌ Использование чугунных труб для новой напорной канализации
Морально устаревшее решение. Default — **ПЭ100 SDR17**. Чугун — только при реконструкции существующих сетей.

### ❌ NPSH-расчёт для погружных КНС
Не имеет смысла — насос всегда залит. Включаем только для СПД с сухой установкой.

### ❌ Подбор по нижнему пределу диапазона производителя
Если у насоса Q_min=10, а пользователь хочет 11 — это **на грани**, КПД низкий, кавитация возможна. Алгоритм должен предпочитать модели где Q_user попадает в **80% от Q_BEP** (best efficiency point).
