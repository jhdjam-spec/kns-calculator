# Категории надёжности КНС и схемы резервирования

**Версия:** 0.1 | **Дата:** 2026-05-02
**Источник:** СП 32.13330.2018 раздел 8.1 (табл. 16) и раздел 8.2 (табл. 17)
**⚠️ Статус:** интерпретация по косвенным цитатам. Дословный текст таблиц 16 и 17 — **пробел**, требует OCR PDF (есть локально).

## Таблица 16 — Критерии категорий

| Категория | Критерий | Применение |
|---|---|---|
| **I**   | Перерыв работы недопустим | Крупные города, промстоки опасных производств, объекты с особыми требованиями |
| **II**  | Кратковременный перерыв допустим | Средние н/п, типовые жилые/коммерческие |
| **III** | Перерыв подачи влечёт прекращение водоснабжения поселений до **5000 человек** | Коттеджи, дачи, малые сёла, СНТ |

Цитата из источника (kpee.ru, косвенно по СП 32):
> «III категория насосной станции систем канализации возможна только в случае, если перерыв подачи сточных вод в ней влечёт за собой прекращение водоснабжения поселений численностью до 5000 [человек]»

## Таблица 17 — Схемы резервирования (интерпретация)

| Категория | N рабочих | N резервных | Запас на складе | Типовая схема |
|---|---|---|---|---|
| **I**   | ≥2 | ≥1 | 24-72 часа | 2+1, 3+2, 4+2 |
| **II**  | ≥1 | ≥1 | опционально | 1+1, 2+1 |
| **III** | ≥1 | ≥1 | не требуется | 1+1 (бытовая), 1+0 допустимо для дождевой |

> ⚠️ **ВАЖНО:** для дождевой канализации III категории СП 32 (примечание к табл. 17) разрешает 1+0 (без резерва) — это уникальный случай. Для бытовой III категории резерв обязателен.

## ✅ Дефолт калькулятора (L0)

**По умолчанию: II категория, схема 1+1**

Обоснование:
- 70% коммерческих заказов попадают в II категорию (типовая жилая/коммерческая застройка)
- Схема 1+1 — минимально достаточная по нормам
- Если объект сложнее — менеджер переключает в L1 «Уточнить» и выбирает категорию вручную

## ❌ Не работающие схемы (для нашего сегмента)

### ❌ «1+0 для коттеджа на 5 человек»
Не подходит — даже III категория требует 1+1 для бытовой канализации. Без резерва клиент будет звонить в субботу при выходе из строя единственного насоса.

### ❌ «Хранить резервный на складе вместо установки»
Невыгодно — установка резервного насоса в КНС стоит ~30% стоимости насоса (направляющие, кабель, поплавок). Купить «на склад» нельзя сэкономить — придётся вызывать монтажников при поломке.

### ❌ «3+1 для частного дома»
Избыточно. На частного клиента такая схема никогда не уйдёт по цене. Если по подсчётам нужно 3 рабочих — это уже не индивидуалка.

## Карта решения «категория → резервирование» для алгоритма

```python
def get_redundancy(category: str, wastewater_type: str) -> dict:
    """Возвращает (n_working, n_reserve, n_storage)"""
    if category == "I":
        return {"working": 2, "reserve": 1, "storage": 1}
    elif category == "II":
        return {"working": 1, "reserve": 1, "storage": 0}
    elif category == "III":
        if wastewater_type == "drainage":  # дождевая
            return {"working": 1, "reserve": 0, "storage": 0}
        else:  # хоз-быт
            return {"working": 1, "reserve": 1, "storage": 0}
```
