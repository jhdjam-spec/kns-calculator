# Модель горизонтальной ПП-ёмкости (источник: Серво-Юг калькулятор)

**Версия:** 0.1 | **Дата:** 2026-05-03
**Источник:** `Калькулятор стоимости емкостей.ods` (Серво-Юг). Все формулы и константы извлечены из листа Sheet1.

> Документ описывает математическую модель **расчёта стоимости и массы горизонтальной ПП-ёмкости**. Применяется как для товарных ёмкостей, так и для **корпусов КНС** (см. `kns_corpus_rules.md`).

## 2. Производные расчёты (порядок важен)

### 2.1 Объём (для информации)

```
V_m3 = π · (D/2)² · L / 1_000_000_000
```

(D в мм, L в мм → V в м³)

### 2.2 Подбор листа на перегородку (B14, дискретная функция от D)

```python
sheets_per_baffle = match D_mm:
    960  → 0.33
    1280 → 0.50
    1430 → 0.50
    1500 → 0.50
    1910 → 1.00
    2000 → 1.00
    2100 → 1.00
    2200 → 1.00
    2300 → 1.50
    2400 → 1.50
    2500 → 1.50
    3000 → 2.00
    3200 → 2.30
    3400 → 2.50
    3600 → 2.60
    *    → ошибка (значение не из стандартного ряда)
```

**Что это:** сколько листов исходного материала уходит на одну перегородку при разделке. Связано с раскроем стандартного листа ~1500×3000 мм.

### 2.3 Количество перегородок (B15)

```
n_baffles = ceil(L_mm / baffle_step_m / 1000) + 1
```

`+1` — потому что концевые крышки тоже считаются перегородками.

### 2.4 Длины профилей (E15..E18)

```
total_bands     = (n_baffles - 1) · bands_per_section            # B9
length_bands_m  = total_bands · π · D_mm / 1000                  # окружность × N
length_profiles_corpus_m = profiles_longitudinal · L_mm / 1000   # продольные на корпусе
length_profiles_baffles_m = n_baffles · D_mm · profiles_per_baffle / 1000  # на перегородках
length_profiles_total_m = length_bands_m + length_profiles_corpus_m + length_profiles_baffles_m
```

### 2.5 Площади листов (E25..E27)

```
sheets_corpus  = ceil(L_mm / 1500 · D_mm · π / 3000, step=0.5)
                # длина по периметру × длина по оси, в стандартных листах 1500×3000

sheets_baffles = n_baffles · sheets_per_baffle  # из B14

sheets_bands   = ceil(length_bands_m / 100 · 11, step=0.5)
                # из 1 листа выходит ~100 м бандажа при ширине 11 (мм-полоса)
```

### 2.6 Массы (E3, E4, E6)

Плотность ПП-листа: `ρ × A` упаковано в коэффициент **4.14 кг/(мм·м²-листа)** (= 0.92 г/см³ × 4.5 × 1).

```
mass_corpus_kg = 4.14 · sheets_corpus · t_corpus_mm
                + 4.14 · sheets_baffles · t_baffle_mm
                + 4.14 · sheets_bands · t_band_mm

mass_profiles_kg = length_profiles_total_m · 3.6     # 3.6 кг/м для усиливающего профиля

mass_total_kg = mass_corpus_kg + mass_profiles_kg
```

### 2.7 Стоимость (E7, E19, E20)

```
cost_pp_rub = mass_corpus_kg · price_pp_kg · 1.15 · 2
              # × 1.15 — наценка/отходы; × 2 — ПП дважды (внутренняя + наружная стенка?
              # фактически: коэф. конверсии «нетто-материал → брутто с раскроем и сваркой»)

cost_profiles_rub = length_profiles_total_m · price_profile_m

cost_total_rub = cost_pp_rub + cost_profiles_rub
```

## 3. Граф зависимостей (что от чего считается)

```
ВХОДЫ ПОЛЬЗОВАТЕЛЯ
  L_mm, D_mm, t_corpus_mm, t_baffle_mm, t_band_mm,
  baffle_step_m, bands_per_section, profiles_per_baffle, profiles_longitudinal
       │
       ▼
ШАГ 1. ДИСКРЕТНЫЕ ВЫБОРЫ
  D_mm  ─ должен быть из стандартного ряда (15 значений) ──▶ sheets_per_baffle (B14)
       │
       ▼
ШАГ 2. ГЕОМЕТРИЯ
  V_m3                 = f(D, L)
  n_baffles            = ceil(L / baffle_step) + 1
  total_bands          = (n_baffles - 1) · bands_per_section
       │
       ▼
ШАГ 3. ДЛИНЫ ПРОФИЛЕЙ
  length_bands_m            = total_bands · π · D / 1000
  length_profiles_corpus_m  = profiles_longitudinal · L / 1000
  length_profiles_baffles_m = n_baffles · D · profiles_per_baffle / 1000
  length_profiles_total_m   = SUM
       │
       ▼
ШАГ 4. ПЛОЩАДИ ЛИСТОВ
  sheets_corpus  = ceil(L / 1500 · D · π / 3000)
  sheets_baffles = n_baffles · sheets_per_baffle
  sheets_bands   = ceil(length_bands_m / 100 · 11)
       │
       ▼
ШАГ 5. МАССЫ
  mass_corpus_kg   = 4.14 · (sheets_corpus·t_c + sheets_baffles·t_b + sheets_bands·t_band)
  mass_profiles_kg = length_profiles_total_m · 3.6
  mass_total_kg    = SUM
       │
       ▼
ШАГ 6. СТОИМОСТЬ
  cost_pp_rub        = mass_corpus_kg · price_pp_kg · 1.15 · 2
  cost_profiles_rub  = length_profiles_total_m · price_profile_m
  cost_total_rub     = SUM
```

## 4. Что нужно проверить и улучшить

### ⚠️ Открытые вопросы по модели

1. **`× 1.15 · 2` в формуле cost_pp_rub** — не разобран. `1.15` похоже на коэффициент отходов (15%), но `×2` подозрителен. Возможные интерпретации:
   - двойная стенка (футляр)
   - конверсия нетто-материал → брутто-стоимость с учётом обрезков и сварки
   - **Запросить у Серво-Юг** уточнение этого коэффициента
2. **3.6 кг/м в массе профилей** — это конкретный профиль усиления (предположительно прямоугольный 50×100 мм или швеллер). Уточнить SKU.
3. **`sheets_bands = ceil(L_bands / 100 · 11)`** — деление на 100 (метров с одного листа?) и умножение на 11 — нужна интерпретация.
4. **Толщина стенки vs давление/глубина** — в этом калькуляторе НЕТ зависимости толщины от грунтового давления. Это **только калькулятор стоимости**, не прочности. Для КНС-корпуса нужна отдельная проверка по СП и СНиП на гидростатическое давление + грунт.

### Что НЕ покрывает модель (требуется доработка для КНС)

- Якорная плита при УГВ выше дна (см. `coefficients.json::anchoring_safety_factor`)
- Усиление под нагрузкой грунта (для горизонтально лежащей в земле ёмкости)
- Стоимость монтажа, доставки, КИП

## 5. Использование модели для подбора КНС-корпуса

В калькуляторе насосов после успешного подбора насоса можно **рекомендовать корпус КНС**:

1. По объёму V_прёмного (см. coefficients.json::pump_starts_per_hour_max и формулу `V = Q / (4z)`)
2. **V_общий = 1.5–2.0 × V_приёмного** (запас на минимальный уровень + аварию)
3. Подобрать **D × L** так, чтобы V_цилиндра ≥ V_общий и **H/D ≤ 4** (см. NOT_OK-22)
4. Подставить D, L в эту модель — получить массу и стоимость корпуса

**Особенности для КНС-корпуса** (vs обычная горизонтальная ёмкость):
- КНС обычно **вертикальная** (стоит на дне), а калькулятор для горизонтальной — **формулы массы корпуса можно адаптировать** (та же цилиндрическая стенка, но без перегородок), но величина `n_baffles` для КНС обычно 2 (только верхняя крышка и нижнее дно).
- **Толщина стенки** должна выдержать гидростатическое давление столба жидкости на глубине.

→ Соответственно для КНС-корпуса используем **упрощённую** версию модели (см. `tank_calculator_models.json::kns_vertical_corpus`).
