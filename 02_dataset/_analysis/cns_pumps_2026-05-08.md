# Серия ЦНС — глубокое исследование 2026-05-08

**Цель:** заполнить главную дыру БД калькулятора КНС в диапазоне H=150-600м и выше.
**Применение:** ППД (поддержание пластового давления нефть/газ), шахтный водоотлив,
пожарные СПД I категории высокого давления, магистральные водоводы, питательные ТЭЦ.

## ГОСТ 10407-88 — основа маркировки

`ЦНС <Q>-<H>` где:
- `ЦНС` — центробежный насос секционный (горизонтальный, для воды, t≤45°C, pH 7-8.5)
- `ЦНСГ` — Г = горячая вода 45-105°C
- `ЦНСМ` — М = масло (t=50-55°C, кинематическая вязкость 20-25 сСт)
- `ЦНСН`/`ЦНСНт` — Н = нефть (плотность 700-1050 кг/м³, до 90% обводнение, ≤3% газа)
- `ЦНСК` — К = кислотная вода (pH 3.5-8.5)
- `ЦНСА`, `ЦНСГА` — А = агрегатная поставка с двигателем
- `ЦНСв` — вертикальное исполнение (горячее водоснабжение)
- `<Q>` — номинальная подача м³/ч (фиксированный размер корпуса серии)
- `<H>` — номинальный напор м (определяется числом ступеней 2-10)

## Замечания по импорту в БД

1. КПД и NPSHr нормированы по сериям (одинаковы для всех типоразмеров серии Q):
   - 13/38: КПД ~50/63%, NPSHr 3-3.6 м
   - 60: КПД ~70%, NPSHr 4.5 м
   - 105: КПД 64%, NPSHr 6.0 м
   - 180: КПД 70%, NPSHr 6.0 м
   - 300: КПД 70%, NPSHr 6.0 м
   - 500: КПД 71%, NPSHr 5.0 м
   - 850: КПД 72%, NPSHr 5.0 м
2. Все модели — горизонтальные, многоступенчатые (2-10 секций).
3. Производитель основной = Ливгидромаш ИЛИ Ясногорский (взаимозаменяемы).
4. Все есть в реестре Минпромторг по 719 ПП → преференция 30% по 44-ФЗ.
5. Поле `application` для калькулятора: "ппд" (ЦНС 180/500), "пожарка-спд" (ЦНС 38/60),
   "магистраль" (ЦНС 300/850), "шахтный-водоотлив" (ЦНС 60/180), "нефтехимия" (ЦНС 105/180).
6. БД-поля для ЦНС: добавить флаг `cns_type ∈ {вода, горячая, нефть, масло, кислота}`
   соответствующий буквам Г/Н/М/К после ЦНС.
