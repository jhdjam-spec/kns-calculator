## Замечания и пробелы

1. **ANTARUS прайс закрытый** — нужен прямой запрос через 8-800-550-50-70 или дилера ВИТО Групп. Для нашего региона (Краснодар) ANTARUS — стратегический партнёр, целесообразно сделать B2B-договор и получить дилерский прайс.

2. **KAIQUAN прайс через ACO** — также по запросу. Эталонный кейс АртВинд Мысхако (50WQ/S 20-22-3 за ~80-120 тыс ₽) — единственный точный ценовой anchor.

3. **Серия ВТ / ЕВРО для ANTARUS** — в задаче упомянута, но в открытом каталоге не найдена. Возможные интерпретации:
   - "ВТ" — это шифр исполнения "Торцевая Втулка" в обозначении НК2-50/16/8/1,1-**ТВ**-10М, а не отдельная серия
   - "ЕВРО" — устаревшее название серии или название станций ANTARUS-ЕВРО (для повышения давления, не для канализации)
   - **Action item:** уточнить у заказчика Серво-Юг точное значение ВТ/ЕВРО, возможно, это бренд в его частной номенклатуре.

4. **СМЗ Сибнасос ≠ существующий бренд** — в задаче, вероятно, объединены 2 разных: **СМЗ (Средневолжский, Самара)** + **СЭМЗ (Сибирский, Томск)**. В отчёте я разделил.

5. **ФГПУ "Молот" ≠ существующий завод** — ФГПУ это тип насоса (Фекально-Грязевой Полупогружной Удлинённый), а не имя производителя. Реальные производители — Белнаспорм, ЗВУ, АГРЕГАТ-СПб.

6. **Шторм-Ф ≠ погружной фекальный** — это пожарная насосная установка (МВК), не отдельный фекальный бренд.

7. **Цены 2026 актуальные на 2026-05-08** — сильно скакать (валютные колебания, санкции). Регулярная переоценка раз в квартал.

8. **Q-H кривые для бюджетных насосов** — у LEO/Fancy/КАЙКUAN в публичной документации только точка номинала. Для калькулятора применять стандартный профиль:
   - Vortex: Q@H_max = 0.6×Q_BEP, BEP в середине, Q_max = 1.2×Q_BEP при H=0
   - Channel: более крутой Q-H, BEP ближе к Q_max

9. **NPSHr для бюджетных** — не указывается. Применять консервативно:
   - Бытовые 0.55-2.2 кВт: NPSHr = 4-5 м
   - Коммерческие 3-7.5 кВт: NPSHr = 5-6 м
   - Промышленные ≥11 кВт: NPSHr = 6-8 м

10. **Свободный проход** — критичный параметр для канализации:
    - WQ vortex без cutter: 50-110 мм
    - WQ closed channel: 40-65 мм
    - WQ-W / WQK / WQ/S cutter: 30 мм (после измельчения)
