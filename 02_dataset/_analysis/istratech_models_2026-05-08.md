- Конкретные значения **H, η, NPSHr** для большинства типоразмеров — публикуются только в виде единого графика серии в PDF-каталоге
- Полная номенклатура **ВО** (инлайн) — на сайте только серия без размеров
- Полная номенклатура **KMG** — есть только в составе HC-FS станций
- Подтверждение по **Hydro MPC** — конкретных моделей нет, только параметры до 400 м³/ч / 170 м
- Серии **NK, NB** прямо в каталоге не выделены (вероятно поглощены в KMG)
- Регистрация в реестре gisp.gov.ru — нужно проверить вручную по ИНН ИСТРАТЕХ

## 10. Рекомендации для БД калькулятора

1. Для **L0/Wizard** (быстрый подбор) — использовать ряд BM 1/3/5/10/15/20 с подтверждёнными ценами, помечать `manufacturer: ИСТРАТЕХ`.
2. Для **L1** (инженерный) — добавить BM 32/45/64 + HC-FS станции с пометкой `requires_dealer_quote: true`.
3. **Q@BEP** для BM рядов хорошо аппроксимировать номиналом ряда (1, 3, 5, 10, 15, 20, 32, 45, 64 м³/ч). H рассчитывать как `n_ступ × ΔH_ступ`, где ΔH_ступ ≈ 1,5–3,0 м для BM 64, 5–6 м для BM 1.
4. **Преимущество для гос-тендеров:** ИСТРАТЕХ — производитель РФ → проходит ПП РФ № 1875 (запрет на параллельный импорт Grundfos с апреля 2025).
5. **Аналог-маппинг** Grundfos↔ИСТРАТЕХ внести в pumps.json как поле `grundfos_equivalent` для авто-подбора замены при импортозамещении.
6. **Для бытовых/малых КНС** (Q≤2 м³/ч, H≤30 м) подходят BM 1-x и BM 3-x — конкуренция с Pedrollo SAR 550.
7. **Для промышленных КНС/НС** (Q=10–30 м³/ч, H=20–80 м) — BM 10/15/20 — прямой конкурент Grundfos CR.
8. Для расчёта мотора брать MIR IE3 — экономия ≈ 30 % vs импортный аналог.
