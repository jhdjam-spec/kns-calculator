# 1. БАЗОВЫЕ ЗАКОНЫ И ФОРМУЛЫ

## 1.1 Уравнение неразрывности (continuity equation)

### 1.1.1 Дифференциальная форма
Для произвольной сжимаемой среды:

```
∂ρ/∂t + ∇·(ρv) = 0
```

где
- ρ [кг/м³] — плотность,
- v [м/с] — вектор скорости,
- t [с] — время,
- ∇· — оператор дивергенции.

### 1.1.2 Интегральная форма (для трубопровода)
Для несжимаемой жидкости (ρ = const) и установившегося режима:

```
Q = v · A = const
```

где
- Q [м³/с] — объёмный расход,
- v [м/с] — средняя скорость в сечении,
- A [м²] — площадь живого сечения.

### 1.1.3 Следствие для трубы переменного диаметра
```
v₁ · A₁ = v₂ · A₂
v₁ · D₁² = v₂ · D₂²    (для круглых труб)
```

Из этого получается **обратная квадратичная зависимость** скорости от диаметра — важна при расчёте всасывающего патрубка (см. §7 NPSH).

### 1.1.4 Для двухфазной смеси (грязная вода)
```
Q_mix = Q_water + Q_solids
ρ_mix = ρ_w·(1−φ) + ρ_s·φ
```

где φ — объёмная доля твёрдой фазы. Для бытовых стоков φ ≤ 0,5 % (см. СП 32 п. 6.2.4).

## 1.2 Уравнение Бернулли

### 1.2.1 Идеальная жидкость, без потерь
Для линии тока установившегося течения невязкой несжимаемой жидкости (классический Бернулли, 1738):

```
p/ρ + v²/2 + g·z = const
```

В единицах напора (разделили на g):

```
p/(ρ·g) + v²/(2·g) + z = H = const   [м]
```

три слагаемых:
- **p/(ρg)** — пьезометрический напор (potential head from pressure);
- **v²/(2g)** — скоростной (динамический) напор;
- **z** — геометрический напор.

### 1.2.2 Реальная жидкость с потерями
Между сечениями 1 (вход) и 2 (выход):

```
z₁ + p₁/(ρg) + α₁·v₁²/(2g) = z₂ + p₂/(ρg) + α₂·v₂²/(2g) + h_w(1→2)
```

где
- α — коэффициент Кориолиса (для турбулентного режима α≈1,05–1,10; для ламинарного α=2,0);
- h_w(1→2) [м] — суммарные потери напора между сечениями (линейные + местные).

### 1.2.3 С учётом насоса
```
z₁ + p₁/(ρg) + α₁·v₁²/(2g) + H_pump = z₂ + p₂/(ρg) + α₂·v₂²/(2g) + h_w
H_pump = (z₂−z₁) + (p₂−p₁)/(ρg) + (α₂v₂²−α₁v₁²)/(2g) + h_w
```

Это базовая формула подбора насоса по геометрической высоте + потерям. Реализована в `pump_calculator/physics.py::compute_required_head()`.

### 1.2.4 Вывод (краткий)
Из уравнения Эйлера для идеальной жидкости вдоль линии тока:
```
∂v/∂t + (v·∇)v = −∇p/ρ + g
```
Для установившегося течения (∂/∂t=0) и интегрирования вдоль линии тока с учётом g = −∇(gz):
```
∇(v²/2 + p/ρ + gz)·dl = 0  ⇒  v²/2 + p/ρ + gz = const
```

### 1.2.5 Pитфоллы (что часто забывают)
- **Бернулли работает вдоль одной линии тока**. Применять между двумя точками потока — допустимо только если жидкость потенциальна (безвихревая).
- **Слагаемое α·v²/(2g)** забывают на свободной поверхности резервуара (там v ≈ 0 ⇒ член обнуляется).
- **Знак гидроудара** при экстремально быстром закрытии: основная формула Бернулли неприменима — нужна формула Жуковского (см. §8).

## 1.3 Уравнение количества движения (momentum equation)

### 1.3.1 Интегральная форма (теорема импульсов)
Для контрольного объёма с установившимся течением:

```
ΣF = ρ·Q·(v_out − v_in)
```

В компонентах:
```
F_x = ρ·Q·(v_out,x − v_in,x)
F_y = ρ·Q·(v_out,y − v_in,y)
```

### 1.3.2 Сила реакции на колено 90°
Для горизонтального колена 90° с расходом Q:
```
R_x = ρQ·v + p·A    (по оси входа)
R_y = ρQ·v + p·A    (по оси выхода)
|R|  = √(R_x² + R_y²)
```

Это **основа расчёта анкеровки трубопровода** в местах поворотов. Для DN150 трубы со скоростью 2 м/с и давлением 0,6 МПа сила реакции составит ~16 кН на колено — критично для крепления.

### 1.3.3 Уравнение в форме Навье-Стокса (для CFD)
```
ρ·(∂v/∂t + (v·∇)v) = −∇p + μ∇²v + ρg + F
```
где
- μ [Па·с] — динамическая вязкость,
- F — внешние объёмные силы.

В цилиндрических координатах (для осесимметричного потока) — основа решения течений в насосе через ANSYS CFX.

# 2. РЕЖИМЫ ПОТОКА

## 2.1 Число Рейнольдса (Re) — главный критерий

### 2.1.1 Определение
```
Re = v·D/ν = ρ·v·D/μ
```

Физический смысл — отношение сил инерции к силам вязкости.

### 2.1.2 Критические значения для круглой трубы
| Режим           | Re               | Профиль скорости    | λ (коэф. Дарси)   |
|-----------------|------------------|---------------------|-------------------|
| Ламинарный      | Re ≤ 2300        | параболический      | λ = 64/Re         |
| Переходный      | 2300 < Re < 4000 | неустойчивый        | λ — нет формулы (интерполяция / запас) |
| Турбулентный гидравлически гладкий | 4000 < Re < Re_кр1 | плоский ядро + пристенный слой | по Блазиусу или Альтшулю |
| Турбулентный смешанный             | Re_кр1 < Re < Re_кр2 | — | по формуле Колбрука или Альтшуля |
| Турбулентный квадратичный (вполне шероховатый) | Re > Re_кр2 = 500/(ε/D) | — | λ = f(ε/D) только |

где ε — абсолютная шероховатость стенки, D — диаметр.

### 2.1.3 Для некруглых сечений
Применяется **гидравлический диаметр**:
```
D_h = 4·A/P
```
где A — площадь живого сечения, P — смоченный периметр.

Для прямоугольника a×b:
```
D_h = 2ab/(a+b)
```

Для безнапорного потока в круглой трубе наполовину (полукруг):
```
D_h = D    (площадь πD²/8, периметр πD/2)
```

---

## 2.2 Ламинарный режим (Re < 2300)

### 2.2.1 Профиль скорости (Пуазейль)
В круглой трубе радиуса R:
```
v(r) = v_max·(1 − (r/R)²)
v_max = 2·v_avg
v_avg = (R²/8μ)·(−dp/dx) = ΔP·D²/(32·μ·L)
```

### 2.2.2 Закон Гагена-Пуазейля
```
Q = (π·D⁴)/(128·μ·L) · ΔP
ΔP = (128·μ·L·Q)/(π·D⁴)
```

### 2.2.3 Коэффициент сопротивления Дарси
```
λ_lam = 64/Re
```

### 2.2.4 Где встречается в КНС
- Длинные тонкие напорные трубопроводы малых КНС (DN50–DN80) при низких расходах (Q < 1 л/с).
- Дренажные трубопроводы с илом (повышенная вязкость).
- Штатно для бытовых КНС редко — обычно турбулентный.

---

## 2.3 Переходный режим (2300 < Re < 4000)

### 2.3.1 Особенности
- Поток нестабилен — пятна Эммонса, перемежаемость.
- Прогноз потерь сложен: возможны как ламинарные, так и турбулентные участки.
- Гидравлические схемы лучше **избегать** этого диапазона: либо перейти в турбулентный (увеличить v), либо в ламинарный (уменьшить v).

### 2.3.2 Расчётная практика
- Применять формулу турбулентного режима с **запасом 1,15–1,25** на λ.
- Альтернативно — линейная интерполяция между λ_lam(2300) и λ_turb(4000).

### 2.3.3 В КНС
Возникает при **частичной загрузке погружного насоса** или в узких сетях ливневой канализации в межсезонье.

---

## 2.4 Турбулентный режим (Re > 4000)

### 2.4.1 Структура потока
- **Вязкий подслой** (laminar sublayer): δ_v = 5·ν/u_τ, где u_τ = √(τ_w/ρ).
- **Буферная зона**: 5 < y⁺ < 30.
- **Логарифмическое ядро**: y⁺ > 30, профиль u⁺ = (1/κ)·ln(y⁺) + B (κ ≈ 0,41, B ≈ 5,0).

### 2.4.2 Безразмерные переменные
```
y⁺ = y·u_τ/ν
u⁺ = v/u_τ
```

### 2.4.3 Гидравлическая шероховатость
- **Гладкая** (hydraulically smooth): ε⁺ = ε·u_τ/ν < 5 ⇒ ε «утоплена» в вязком подслое.
- **Полностью шероховатая** (fully rough): ε⁺ > 70 ⇒ λ зависит только от ε/D.
- **Промежуточная** (transitional rough): 5 < ε⁺ < 70 ⇒ λ зависит от Re и ε/D.

### 2.4.4 Абсолютная шероховатость ε для распространённых труб (мм)
| Материал                                        | ε, новые | ε, эксплуатируемые |

| Сталь оцинкованная                              | 0,1–0,2  | 0,3–0,5           |

| Чугун с цементно-песчаной обмазкой              | 0,1–0,2  | 0,3               |
| Бетон (гладкий)                                 | 0,3–0,8  | 0,5–3,0           |
| Бетон (грубый, обычная опалубка)                | 1,0–3,0  | 2,0–5,0           |
| Полиэтилен ПЭ100 (ПНД)                          | 0,007    | 0,01              |
| Полипропилен ПП                                 | 0,005    | 0,008             |
| Поливинилхлорид (ПВХ-У/ПВХ-О)                   | 0,005    | 0,008             |

# 3. ГИДРАВЛИЧЕСКИЕ СОПРОТИВЛЕНИЯ

## 3.1 Линейные потери (по длине)

### 3.1.1 Универсальная формула Дарси-Вейсбаха
```
h_f = λ · (L/D) · v²/(2g)
ΔP = λ · (L/D) · ρv²/2
```

где
- h_f [м] — потери напора по длине,
- ΔP [Па] — потери давления,
- λ [-] — коэффициент гидравлического трения,
- L [м] — длина участка,
- D [м] — внутренний диаметр,
- v [м/с] — средняя скорость,
- g = 9,80665 м/с² — ускорение свободного падения.

### 3.1.2 Формулы для λ

#### Ламинарный режим
```
λ = 64/Re                         (точно, выводимо из Пуазейля)
```

#### Турбулентный гидравлически гладкий — Блазиус (4·10³ < Re < 10⁵)
```
λ = 0,3164/Re^0,25
```

#### Турбулентный гидравлически гладкий — Никурадзе (10⁵ < Re < 10⁸)
```
λ = 0,0032 + 0,221/Re^0,237
```

#### Универсальная Колбрука-Уайта (неявная, ВСЕ турбулентные режимы)
```
1/√λ = −2·log₁₀(ε/(3,7D) + 2,51/(Re·√λ))
```

Это **самая точная** формула. Решается итерациями. В `physics.py` — через scipy.optimize.brentq.

#### Явная аппроксимация Свами-Джейна (Swamee-Jain, 1976)
```
λ = 0,25 / [log₁₀(ε/(3,7D) + 5,74/Re^0,9)]²
```
Точность ±1 % от Колбрука-Уайта в диапазоне 5·10³ ≤ Re ≤ 10⁸ и 10⁻⁶ ≤ ε/D ≤ 0,01. Подходит для embedded расчётов.

#### Альтернативная Хааланда (Haaland, 1983)
```
1/√λ = −1,8·log₁₀((ε/(3,7D))^1,11 + 6,9/Re)
```
Точность ±2 % от Колбрука; быстрее, но чуть менее точна.

#### Формула Альтшуля (для смешанной зоны, СНГ-классика)
```
λ = 0,11·(ε/D + 68/Re)^0,25
```
Используется в **российских СП и ВНТП** до сих пор (особенно в ВНТП 25-87).

#### Формула Шифринсона (для полностью шероховатой)
```
λ = 0,11·(ε/D)^0,25
```

### 3.1.3 Альтернативные эмпирические формулы

#### Хазен-Вильямса (для воды, СИ-форма)
```
h_f = 10,67·L·Q^1,852 / (C^1,852 · D^4,87)        [м]
```
где C — коэффициент Хазена-Вильямса:

| Материал                  | C            |
|---------------------------|--------------|
| Сталь новая               | 130–140      |
| Сталь старая              | 80–100       |
| Чугун новый               | 130          |
| Чугун старый              | 80           |
| Бетон                     | 100–140      |
| ПВХ, ПЭ                   | 140–150      |
| Стеклопластик             | 145–150      |

Применяется для **холодной воды** в диапазоне v = 0,6–3,0 м/с. **Не работать** для илов, вязких жидкостей, горячей воды.

#### Шези-Маннинга (для безнапорных потоков)
```
v = (1/n)·R^(2/3)·i^(1/2)
```
где
- n — коэффициент шероховатости Маннинга,
- R = A/P — гидравлический радиус,
- i — гидравлический уклон.

Коэффициенты Маннинга n:
| Материал лотка                  | n              |
|---------------------------------|----------------|
| ПНД, ПВХ                        | 0,009–0,011    |
| Бетон гладкий                   | 0,012–0,014    |
| Бетон обычный                   | 0,014–0,017    |
| Чугун новый                     | 0,011–0,013    |
| Чугун старый                    | 0,015–0,020    |
| Сталь                           | 0,011–0,014    |
| Грунтовый канал гладкий         | 0,022–0,030    |
| Грунтовый канал заросший        | 0,035–0,060    |

Используется для расчёта **самотёчных коллекторов** (СП 32 п. 6.3).

### 3.1.4 Что выбрать в kns-calculator
- Расчёт напорной части КНС → **Колбрук-Уайт через Свами-Джейна** (`physics_advanced.py::darcy_factor()`).
- Самотёчный коллектор → **Маннинг**.
- Старые СНиПовые поверочные расчёты → Альтшуль (для совместимости с проектными расчётными записками).
- Быстрая прикидка для воды → Хазен-Вильямс.

## 3.2 Местные сопротивления (по элементам)

### 3.2.1 Универсальная формула
```
h_loc = ζ · v²/(2g)
ΔP_loc = ζ · ρv²/2
```

где ζ — коэффициент местного сопротивления (КМС), v — скорость в **референсном сечении** (обычно входное; уточнять по справочнику!).

### 3.2.2 Эквивалентная длина
Часто удобно представить местное сопротивление как «эквивалент» прямого участка:
```
L_экв = ζ·D/λ
```

Полезно для быстрых прикидок: один полнопроходной шаровой кран DN150 ≈ 1 м эквивалентной длины ПЭ-трубы при v ~ 1,5 м/с.

### 3.2.3 Сложение
При последовательной установке местные сопротивления **суммируются**:
```
ζ_total = Σ ζ_i
```

Но если расстояние между ними < 30·D, появляется **взаимное влияние** (см. Идельчик-92 §3-2). Применяется поправка ζ' = ζ·k_взаим, k обычно 1,1–1,3.

# 4. РАСЧЁТ ХАРАКТЕРИСТИКИ СИСТЕМЫ

## 4.1 Уравнение характеристики

Кривая «потребный напор системы» H_sys(Q):
```
H_sys(Q) = H_st + R · Q² · μ_корр
```

где
- **H_st** — статический напор (геометрия + противодавление):
  ```
  H_st = z_конец − z_насос + (p_конец − p_атм)/(ρg)
  ```
- **R** — гидравлическое сопротивление сети:
  ```
  R = (8/π²g) · [Σᵢ (λᵢ·Lᵢ/Dᵢ⁵) + Σⱼ (ζⱼ/Dⱼ⁴)]
  ```
- **μ_корр** — поправка на вязкость / шероховатость / температуру (обычно 1,0–1,3).

## 4.2 Графоаналитический подбор насоса

Рабочая точка — пересечение Q-H насоса и H_sys системы:
```
H_pump(Q*) = H_sys(Q*)
```

Должна лежать в **POR** (preferred operating range, обычно 70–120 % BEP) или хотя бы в **AOR** (allowable, 50–125 % BEP). См. ANSI/HI 9.6.3.

## 4.3 Чувствительность к параметрам

### 4.3.1 Что влияет на H_sys
- **L** (длина) — линейно;
- **D** (диаметр) — H_sys ~ 1/D⁵ (огромное влияние!);
- **ε** (шероховатость) — слабо для турбулентного гладкого, сильно для шероховатого;
- **ζ** (арматура) — линейно;
- **Q** — квадратично (для турбулентного режима).

### 4.3.2 Пример для DN150 → DN200 при том же Q
```
λ_150 ≈ 0,022; L = 100 м; v_150 = Q/A = 1,77 м/с (при Q=125 м³/ч)
λ_200 ≈ 0,021; v_200 = 1,00 м/с
h_f(150) = 0,022·(100/0,150)·1,77²/(2·9,81) = 2,34 м
h_f(200) = 0,021·(100/0,200)·1,00²/(2·9,81) = 0,54 м
```
**Уменьшение почти в 4,3 раза при увеличении DN на 1 шаг.** Отсюда — типичная ошибка проектировщиков, экономящих на диаметре, но платящих за электроэнергию насоса всю жизнь.

### 4.3.3 Эконом-оптимум диаметра (Dunn-Hudson)
Оптимальная скорость v_opt в напорном трубопроводе с учётом капекс vs опекс:
```
v_opt = (2·E_loss / (k_pipe · t_срок))^0,33    [приближённо 1,0–2,5 м/с для воды]
```
- E_loss — стоимость потерянной электроэнергии за срок,
- k_pipe — стоимость погонного метра трубы.

Для России на 2026 г.: типичный оптимум v = 1,3–1,8 м/с для напорной канализационной трубы DN100-300. Ниже — труба окупается дольше; выше — слишком большие потери.

## 4.4 Эквивалентная длина (alternative form)

Сводим все местные потери к эквивалентной длине прямой трубы:
```
L_экв = ΣL_i + (D/λ)·Σζⱼ
h_total = λ·(L_экв/D)·v²/(2g)
```

Удобно для **быстрой прикидки в Excel**, но менее наглядно для анализа.

# 5. Q-H ХАРАКТЕРИСТИКИ НАСОСОВ

## 5.1 Типы динамических насосов

### 5.1.1 Радиальный (центробежный)
- Поток: радиальный (от центра к периферии).
- Q-H: круто падает (классический «крутопадающий»).
- BEP: 60–85 % η.
- Применение: КНС, водоснабжение, циркуляция.
- Производители для KNS: Grundfos SE/SEG, ИСТРА, Pedrollo, KAIQUAN, ANTARUS, CNP.

### 5.1.2 Осевой (пропеллерный)
- Поток: вдоль оси.
- Q-H: «горбатая» (нестабильная зона при частичной нагрузке!).
- BEP: 75–88 % η.
- Применение: большие расходы при малых напорах (Q > 1000 м³/ч, H < 10 м).
- В КНС встречается редко (только для очень крупных НС).

### 5.1.3 Диагональный (полуосевой / mixed flow)
- Поток: под углом к оси.
- Промежуточные характеристики между радиальным и осевым.
- BEP: 80–88 %.
- Применение: КНС с большим расходом (Q = 200–2000 м³/ч, H = 10–30 м) — ИСТРА серия CDC, Grundfos KPL.

### 5.1.4 Винтовой (Архимед, screw pump)
- Поток: гравитационный + перекачка через шнек.
- Не имеет «классической» Q-H; Q зависит от наклона и обводнения.
- BEP: 65–75 % η, но КПД мало деградирует с износом.
- Применение: иловые насосы, КНС со включениями (ANTARUS Spiraflo).

### 5.1.5 Винтовой Mono (positive displacement progressing cavity)
- Поток: объёмный (positive displacement).
- Q-H: почти вертикальная линия (Q ≈ const при любом H).
- BEP: 50–70 % η.
- Применение: иловые насосы ЛОС, дозирование химии.

> **В KNS-калькуляторе** базовая модель — радиальный центробежный (95 % случаев). Винтовые/диагональные — отдельные ветки L1.

## 5.2 Уравнение Эйлера для лопастного насоса

Теоретический напор бесконечнолопастной машины:
```
H_t∞ = (u₂·c₂u − u₁·c₁u) / g
```
где
- u — окружная скорость колеса в радиусе r (u = ω·r);
- c_u — проекция абсолютной скорости на окружное направление.

С учётом конечного числа лопастей:
```
H_t = ψ_S · H_t∞      (ψ_S = 0,7–0,85 — поправка Пфлейдерера)
```

С учётом гидравлических потерь в самом насосе:
```
H = η_h · H_t        (η_h = 0,85–0,95 для нормальных насосов)
```

## 5.3 Типичные зависимости (для расчёта Q-H по эталону)

При фиксированной геометрии и оборотах:
```
H(Q) = a·Q² + b·Q + c    (квадратичная регрессия; реализована в physics.py через МНК)
P(Q) = d·Q + e           (потребляемая мощность ≈ линейна для центробежных)
η(Q) = (ρ·g·Q·H) / P
NPSHr(Q) = f·Q² + g·Q + h
```

> Стандартная аппроксимация Q-H по 5–7 точкам каталога с коэффициентом R² ≥ 0,995.

## 5.4 Специфическая скорость n_s

### 5.4.1 Формула (российская / СИ-форма, через об/мин и м³/с, м)
```
n_s = n · √Q / H^0,75       [в системе СНГ]
```

n — об/мин; Q — м³/с; H — м.

В **американской** системе (Karassik):
```
N_s = N · √Q_gpm / H_ft^0,75
N_s [US] ≈ 51,6 · n_s [SI]
```

### 5.4.2 Классификация по n_s (СИ)
| n_s          | Тип           | Пример                              | η_max |
|--------------|---------------|-------------------------------------|-------|
| 10–30        | Винтовой / плунжерный | МНДП, Mono, NEMO            | 50–70 |
| 30–60        | Радиальный высоконапорный (тихоходный) | Многоступенчатые, ЦНС | 65–80 |
| 60–150       | Радиальный нормальный | Grundfos SE, ANTARUS-N      | 75–85 |
| 150–300      | Диагональный  | Grundfos KPL, ИСТРА CDC             | 82–90 |
| 300–600      | Осевой        | Wilo Axial, Бакинский ОПВ           | 85–93 |
| > 600        | Гипершвидк. осевой | (редко в КНС, гидротурбины) | до 95 |

### 5.4.3 Зачем нужно n_s
- **Подбор типа** насоса по требуемому Q и H.
- **Геометрические пропорции** колеса — D₂/D₁, b₂/D₂.
- **Допустимый NPSHr** — пропорционален n_s^(4/3) при прочих равных.

### 5.4.4 Пример
КНС с Q = 50 м³/ч = 0,01389 м³/с, H = 25 м, n = 1450 об/мин:
```
n_s = 1450 · √0,01389 / 25^0,75 = 1450 · 0,1179 / 11,18 = 15,3
```
Очень низкое n_s — задача на грани «винтовой / тихоходный радиальный». В реальности применят радиальное колесо с ψ < 0,5 (плохой КПД ~62 %). Лучше **повысить обороты до 2900 об/мин**:
```
n_s = 2900 · 0,1179 / 11,18 = 30,6
```
В оптимальной зоне нормального центробежного — η будет 75–80 %.

# 6. ЗАКОНЫ ПОДОБИЯ (AFFINITY LAWS)

## 6.1 Изменение оборотов n (для одного и того же колеса)
```
Q₂/Q₁ = n₂/n₁
H₂/H₁ = (n₂/n₁)²
P₂/P₁ = (n₂/n₁)³
NPSHr₂/NPSHr₁ = (n₂/n₁)²
```

> **Применение в ПЧ-управлении.** При снижении n на 20 % напор падает на 36 %, мощность — на 49 %. Поэтому ПЧ так эффективен в системах с переменным расходом.

## 6.2 Изменение диаметра колеса D (для одного корпуса)

### 6.2.1 Классическая форма (Karassik §2.5)
```
Q₂/Q₁ = (D₂/D₁)³
H₂/H₁ = (D₂/D₁)²
P₂/P₁ = (D₂/D₁)⁵
```

> **Применение в обточке колеса** для подгонки рабочей точки. Допустимая обточка — до 80 % от исходного D₂ (дальше — резкое падение η).

### 6.2.2 Уточнённая форма для частичной обточки (Stepanoff)
Для одного корпуса при обточке только D₂ (выходной диаметр):
```
Q₂/Q₁ = D₂_new/D₂_old
H₂/H₁ = (D₂_new/D₂_old)²
```
(показатели меньше, потому что входной диаметр и геометрия канала остаются.)

## 6.3 Поправка на вязкость (ANSI/HI 9.6.7)

Для жидкостей с вязкостью ν > 4,3·10⁻⁵ м²/с (43 cSt) применяется коррекция параметров:
```
Q_visc = C_Q · Q_water
H_visc = C_H · H_water
η_visc = C_η · η_water
P_visc = ρ_visc · g · Q_visc · H_visc / η_visc
```

Коэффициенты C_Q, C_H, C_η берутся из карт Hydraulic Institute (зависят от Q, H, ν). Грубая аппроксимация:

| ν, cSt    | C_Q       | C_H       | C_η       |
|-----------|-----------|-----------|-----------|
| 10        | 1,00      | 1,00      | 1,00      |
| 50        | 0,99      | 0,98      | 0,93      |
| 100       | 0,97      | 0,95      | 0,87      |
| 200       | 0,94      | 0,90      | 0,75      |
| 500       | 0,87      | 0,80      | 0,55      |
| 1000      | 0,80      | 0,70      | 0,35      |
| 2000      | 0,70      | 0,55      | 0,15      |

Для бытовых стоков (ν ≈ 1 cSt) поправка не нужна. Для полигонного фильтрата с илом (ν до 10 cSt) — поправка минимальна. Для иловых смесей >5 % сухого вещества — обязательно.

## 6.4 Подобие через число Эйлера

Для динамических насосов общая безразмерная характеристика:
```
ψ = g·H / u₂²        (коэффициент напора)
φ = Q / (u₂·A₂)      (коэффициент подачи)
```
Геометрически подобные насосы имеют одинаковые ψ, φ при одинаковых n_s.

## 6.5 Когда подобие НЕ работает

- При сильном изменении n_s (более ±15 % от исходного).
- При большой обточке колеса (> 20 %).
- При смене лопастной системы (новые лопасти, открытое vs закрытое колесо).
- При переходе из одной зоны Re в другую (эффект Re — изменение η).

# 7. КАВИТАЦИЯ И NPSH

## 7.1 Физика кавитации

### 7.1.1 Условие возникновения
Кавитация начинается, когда статическое давление на лопасти насоса падает ниже **давления насыщенных паров** жидкости при текущей температуре:
```
p_local < p_sat(T)
```

Давление насыщенных паров воды:

| T, °C | p_sat, кПа абс | h_sat, м (= p_sat/ρg) |
|-------|----------------|-------------------------|
| 0     | 0,611          | 0,062                   |
| 10    | 1,228          | 0,125                   |
| 20    | 2,339          | 0,238                   |
| 30    | 4,247          | 0,432                   |
| 40    | 7,384          | 0,752                   |
| 50    | 12,35          | 1,259                   |
| 60    | 19,94          | 2,033                   |
| 70    | 31,19          | 3,180                   |
| 80    | 47,39          | 4,832                   |
| 90    | 70,14          | 7,150                   |
| 100   | 101,33         | 10,33                   |

При 80 °C — порог кавитации в **20 раз выше**, чем при 20 °C. Поэтому горячая вода требует **затопления насоса** (positive suction head).

### 7.1.2 Стадии кавитации
1. **Зародышевая** (incipient): первые пузыри, шум, η не падает (NPSHi).
2. **Развивающаяся** (developing): h-кривая «качается», падение η на 1–2 %.
3. **3% падение Q-H** — нормативная точка NPSH3 (по ISO 9906).
4. **Развитая кавитация**: η падает >5 %, шум, вибрация, быстрая эрозия.
5. **Срыв подачи** (vapor lock): подача прекращается.

## 7.2 Определения NPSH

### 7.2.1 NPSHa (Available — доступный)
Определяется системой (трубопровод + резервуар):
```
NPSHa = (p_atm − p_sat)/(ρg) + (z_liq − z_pump) − h_loss_suction
```
- **p_atm** — атмосферное давление в приёмном резервуаре (обычно 101,325 кПа на уровне моря; меньше на высоте — см. §7.4);
- **p_sat** — давление насыщенных паров при T;
- **z_liq − z_pump** — разница уровней (положительна при затопленном насосе);
- **h_loss_suction** — потери напора в трубопроводе ОТ приёмного резервуара ДО входа в насос.

### 7.2.2 NPSHr (Required — требуемый)
Определяется насосом, **берётся из каталога производителя**. Зависит от Q (растёт с ростом Q).

### 7.2.3 NPSHi (Incipient cavitation)
Точка начала кавитации (без падения подачи). Обычно:
```
NPSHi ≈ 1,5–2,5 · NPSH3
```

### 7.2.4 NPSH margin (запас)
```
NPSH_margin = NPSHa − NPSHr
```

**Рекомендуемые запасы (Hydraulic Institute / Karassik §2.6):**
| Применение                              | NPSH_margin           |
|-----------------------------------------|-----------------------|
| Чистая вода, базовые насосы             | ≥ 0,6 м или ≥ 1,3·NPSHr |
| Горячая вода (T > 80°C)                 | ≥ 1,5 м или ≥ 1,5·NPSHr |
| Бытовые стоки                           | ≥ 1,0 м или ≥ 1,3·NPSHr |
| Промстоки агрессивные                   | ≥ 1,5 м или ≥ 1,5·NPSHr |
| Иловые смеси, фильтрат                  | ≥ 2,0 м или ≥ 1,7·NPSHr |
| Котловая вода, конденсат высокого качества | ≥ 3,0 м            |
| Углеводороды лёгкие (гидрокарбон.)      | ≥ 1,2 м или ≥ 1,2·NPSHr |
| Сероводородосодержащие нефтесмеси       | ≥ 2,5 м               |

## 7.3 Влияние температуры

При увеличении T:
- p_sat растёт по экспоненте → NPSHa уменьшается.
- ρ уменьшается → ещё немного снижает NPSHa.
- NPSHr почти не меняется (зависит от геометрии колеса, не от свойств жидкости).
- Практически: при 80 °C NPSHa ниже на 2,5–4 м по сравнению с 20 °C.

> **Кейс:** котельная циркуляционный насос на 95 °C. Для тёплых сетей — насос ставится после расширительного бака, под избыточным давлением 0,5–0,8 бар, чтобы p_atm + p_изб > p_sat + ρg·h_всас + h_loss + NPSHr.

## 7.4 Влияние высоты над уровнем моря

```
p_atm(z) = p₀ · (1 − L·z/T₀)^(g·M/(R·L))
```
В упрощённой форме:
```
p_atm(z) ≈ 101,325 · (1 − 0,0000226·z)^5,256    [кПа]
```
где z в метрах.

| Высота z, м | p_atm, кПа | h_atm, м вод. ст. |
|-------------|------------|-------------------|
| 0           | 101,33     | 10,33             |
| 200         | 98,9       | 10,08             |
| 500         | 95,5       | 9,73              |
| 1000        | 89,9       | 9,16              |
| 1500        | 84,6       | 8,62              |
| 2000        | 79,5       | 8,10              |
| 3000        | 70,1       | 7,15              |

**Москва ~150 м, СПб ~10 м, Краснодар ~30 м, Сочи ~0–500 м, Симферополь ~300 м, Ростов ~80 м, Екатеринбург ~250 м.** Для большинства КНС РФ влияние высоты несущественно (<3 % от NPSHa). Критично только для горных районов (Кавказ, Урал-Сибирь, Дальний Восток).

## 7.5 Способы устранения кавитации

1. **Уменьшить высоту всасывания** (затопление насоса).
2. **Снизить температуру жидкости** (если возможно).
3. **Увеличить диаметр всасывающего трубопровода** (DN_всас ≥ DN_напор + 1 стандартный шаг).
4. **Уменьшить количество местных сопротивлений на всасе** (минимум арматуры, минимум поворотов).
5. **Применить inducer** (предвключённый винт) — снижает NPSHr на 20–40 %.
6. **Снизить обороты** (и принять компромисс по Q).
7. **Применить параллельную работу** (Q делится между N насосами, каждый работает с меньшим NPSHr).
8. **Повысить давление в приёмном резервуаре** (наддув).

## 7.6 Кавитационная эрозия

### 7.6.1 Механизм
Схлопывающиеся пузыри создают микроскопические струи (микроджеты) до 100 м/с с локальным давлением до 1500 МПа. Эта циклическая ударная нагрузка усталостно разрушает поверхность.

### 7.6.2 Скорость эрозии
```
W_erosion ~ (NPSH_margin)^(-3) · ρ · v_tip⁶ · t
```

Снижение NPSH_margin вдвое → ускорение эрозии в 8 раз.

### 7.6.3 Материалы рабочих колёс по стойкости (от худшей к лучшей)

# 8. ГИДРОУДАР (Жуковский, Михайлов, Аллиев)

## 8.1 Природа гидроудара

При резком закрытии задвижки (или пуске/останове насоса) кинетическая энергия столба жидкости преобразуется в потенциальную (упругую). Возникает волна сжатия, бегущая со скоростью звука в жидкости (с упругой коррекцией трубы).

## 8.2 Формула Жуковского (полный гидроудар)

### 8.2.1 Базовая форма
```
ΔP = ρ · c · Δv      (Жуковский, 1898)
ΔH = c · Δv / g
```
- ΔP [Па] — пиковый прирост давления;
- ρ [кг/м³] — плотность жидкости;
- c [м/с] — скорость волны давления;
- Δv [м/с] — изменение скорости потока (обычно равно начальной v при полной остановке).

### 8.2.2 Условия полного удара
Закрытие происходит за **t_close < 2L/c** (фаза удара), где L — длина трубопровода, c — скорость волны. Тогда формируется максимальный пик.

Если t_close > 2L/c — частичный удар, формула Михайлова.

## 8.3 Скорость волны давления c

### 8.3.1 В бесконечно жёсткой среде
```
c_∞ = √(K/ρ)
```
Для воды при 20°C: c_∞ ≈ √(2,18·10⁹/998) ≈ 1480 м/с.

### 8.3.2 В упругой трубе (формула Кортевега-Жуковского)
```
c = √(K/ρ) / √(1 + (K/E)·(D/δ)·c₁)
```
где
- E [Па] — модуль Юнга материала трубы;
- D — внутренний диаметр;
- δ — толщина стенки;
- c₁ — поправка на способ закрепления (≈ 1 для свободно сжимающейся трубы).

### 8.3.3 Скорости волны для разных материалов (вода, 20°C, типичные SDR/PN)

| Материал трубы          | E, ГПа    | c, м/с (типичный SDR) |
|-------------------------|-----------|-----------------------|
| Сталь (PN16, толстостенная) | 200   | 1300–1400             |
| Сталь (PN10, тонкостенная)  | 200   | 1200–1300             |
| Чугун высокопрочный (ВЧШГ)  | 170   | 1100–1300             |
| Чугун серый                  | 100   | 1000–1200             |
| Бетон                        | 30    | 800–1100              |
| Стеклопластик GRP            | 25    | 600–900               |
| ПНД (PE100, SDR17)           | 1,0   | 250–350               |
| ПНД (PE100, SDR11)           | 1,0   | 350–450               |
| ПВХ (PVC-U, PN10)            | 3,0   | 350–500               |
| ПВХ (PVC-O, PN16)            | 4,5   | 450–600               |
| Полипропилен PP-R (PN20)     | 0,9   | 250–350               |

> **Важное наблюдение:** в пластиковых трубах гидроудар **в 3–5 раз слабее**, чем в стали. Это одна из причин массового перехода КНС на ПЭ-обвязку.

## 8.4 Формула Михайлова (частичный гидроудар)

При t_close > 2L/c (медленное закрытие):
```
ΔP_Михайлов = (2 · L · ρ · v) / t_close
ΔH = (2 · L · v) / (g · t_close)
```

Эта формула применяется для расчёта реалистичных гидроударов на закрытии обратного клапана с демпфером, останове насоса с торможением.

## 8.5 Метод Аллиева (численный, метод характеристик)

Уравнения:
```
∂H/∂t + (c²/g)·∂v/∂x + (f·v·|v|/(2gD)) = 0
∂v/∂t + g·∂H/∂x = 0
```

Решаются методом характеристик (MOC) на сетке Δx, Δt с условием Куранта Δt ≤ Δx/c. Реализация — в специализированных пакетах (Bentley HAMMER, AFT Impulse, FluidFlow).

## 8.6 Защита от гидроудара

### 8.6.1 Воздушно-гидравлические гасители (мембранные баки)
Объём гасителя:
```
V_газ = ρ·g·Q·v · t_close · K_безоп / (κ · p_газ_нач)
```
Для КНС обычно:
- ε_гасителя = 25–50 л на каждые 1000 кг·м/с импульса;
- p_зарядки = 1/2 от рабочего давления.

### 8.6.2 Плавное закрытие задвижек (электропривод с регулируемой скоростью)
- t_close > 5·2L/c — полностью гасит удар.
- Стандарт для DN200+ магистральных задвижек.

### 8.6.3 Обходные обратные клапаны
Параллельный байпас с обратным клапаном (направленным на сброс), позволяет волне разрядиться.

### 8.6.4 Сбросные клапаны (relief valve, противоразрывные)
Открываются при p > p_уставки, сбрасывают часть жидкости в дренаж.

### 8.6.5 Плавный пуск / останов насоса
- Ramp-up / ramp-down ПЧ на 3–5 секунд.
- УПП (устройство плавного пуска) — Schneider ATS22.

### 8.6.6 Воздушные клапаны (vacuum breakers / air valves)
На самой высокой точке трубопровода. При просадке давления < p_атм впускают воздух, не давая образоваться вакууму (и кавитации в трубе).

## 8.7 Типичные значения гидроудара в КНС

Для бытовой КНС D=110 мм, L=200 м ПЭ100 SDR17, v=1,5 м/с:
```
c ≈ 300 м/с
ΔP_Жуковский = 1000·300·1,5 = 450 000 Па = 4,5 бар
ΔH ≈ 46 м
```
**Это значительно больше нормального рабочего напора (12 м)!** Поэтому защита обязательна.

При установке мембранного гасителя 50 л:
```
ΔP_резидуальное ≈ 1,5 бар (снижение в 3 раза)
```

# 9. ПАРАЛЛЕЛЬНАЯ И ПОСЛЕДОВАТЕЛЬНАЯ РАБОТА

## 9.1 Параллельная работа

### 9.1.1 Графическая суммация
Q-H двух одинаковых параллельных насосов:
- При одной и той же H, расход складывается: Q_общ = 2·Q_единичного.
- Кривая «параллель 2-х насосов» — горизонтально удвоенная кривая одиночного.

### 9.1.2 Реальный прирост Q
Рабочая точка системы (с учётом квадратичной H_sys) **не удвоится** при включении второго насоса!

Пример:
- Один насос: Q₁ = 50 м³/ч, H₁ = 20 м.
- Двойной параллель в системе с тем же R: Q_общ ≈ 70–75 м³/ч (а не 100!).
- Прирост ~40–50 %, потому что H_sys ~ Q² растёт.

### 9.1.3 Эффективность параллели
Чем **круче** характеристика системы и **более пологая** Q-H насоса — тем меньше прирост от добавления параллельного насоса.

При статически-доминирующей сети (H_st >> R·Q²) — параллель почти удваивает Q.
При ресивер-доминирующей сети (H_st ≈ 0, R·Q² >> H_st) — параллель даёт всего ~1,4·Q.

### 9.1.4 Bear-traps (нестабильные зоны)

Опасная ситуация: насос с горбатой Q-H кривой работает в параллели, но рабочая точка попадает в **левую часть горба** (в зону нестабильности). Тогда возможны:
- Самопроизвольное «качание» подачи между насосами;
- Рывок одного насоса в shut-off (нулевая подача);
- Цикл shut-off — реакт. — работа — shut-off (cycling).

Во избежание — выбирать насосы с **monotonically falling** Q-H (без горба) или ставить байпас.

### 9.1.5 Рекомендации Hydraulic Institute (ANSI/HI 9.6.3)
- При параллели — рабочая точка **каждого** насоса в POR (70–120 % BEP).
- Между насосами должны стоять обратные клапаны.
- Желательно — независимые задвижки на каждом нагнетании.

## 9.2 Последовательная работа

### 9.2.1 Графическая суммация
Q-H двух последовательных насосов:
- При одном и том же Q, напор складывается: H_общ = 2·H_единичного.
- Кривая — вертикально удвоенная.

### 9.2.2 Применение
- **Бустерные станции** на длинных напорных коллекторах.
- **Многоступенчатые насосы** (внутренне последовательные ступени) для высоких H.
- **«Каскад» КНС** — несколько КНС вдоль маршрута, каждая поднимает воду на свой участок.

### 9.2.3 Особенности
- Уплотнение второго насоса должно быть рассчитано на **полное давление** (давление на входе во второй ≈ 1·H_первого).
- Электропривод второго насоса не «помогает» первому — оба должны работать.
- Если первый отключается, второй должен **немедленно** отключиться (защита от перегрева).

## 9.3 Резервирование (n+1, n+2)

Стандарт для КНС по СП 32 (п. 6.2.7):
- **1 рабочий + 1 резервный** для бытовых КНС с Q < 50 м³/ч (категория 3 надёжности).
- **2 рабочих + 1 резервный** для КНС 25–500 м³/ч (категория 2).
- **3 рабочих + 2 резервных** для крупных КНС > 500 м³/ч (категория 1).

Резервные насосы хранятся либо «на полке» (cold standby), либо «горячий резерв» в шкафу управления (готовы к запуску в 10 секунд).

# 10. ТЕПЛОВОЙ РАСЧЁТ ДВИГАТЕЛЯ

## 10.1 Источники потерь в асинхронном двигателе

### 10.1.1 Распределение потерь (типичный 4 кВт IE3)
| Потеря               | % от P_nom |
|----------------------|------------|
| Потери в меди статора | 35–45     |
| Потери в меди ротора  | 15–20     |
| Потери в стали (гистерезис + вихревые) | 20–25 |
| Механические (подшипники + вентилятор) | 10–15 |
| Дополнительные        | 5–10      |
| **Итого потерь**      | 12–18 % от P_nom (η = 82–88 %) |

### 10.1.2 Зависимость от нагрузки
- **Холостой ход**: только потери в стали + механика (~30 % от потерь номинала).
- **Номинал**: все потери в норме.
- **Перегруз 130 %**: потери растут как I² ⇒ температура растёт квадратично ⇒ срок службы изоляции падает экспоненциально.

## 10.2 Тепловой класс изоляции (IEC 60034-1)

| Класс | Макс. T_изоляции | Предельный нагрев Δθ при T_окр=40°C | Применение |
|-------|------------------|-------------------------------------|------------|
| Y     | 90 °C            | 50 K                                | устаревший |
| A     | 105 °C           | 60 K                                | дешёвый    |
| E     | 120 °C           | 75 K                                | бытовой    |
| **B** | **130 °C**       | **80 K**                            | **стандарт RU/EU** |
| **F** | **155 °C**       | **105 K**                           | **стандарт IE3+, КНС**|
| H     | 180 °C           | 125 K                               | ПЧ-приводы, тяжёлая работа |
| 200   | 200 °C           | 145 K                               | спец. применение |
| 220   | 220 °C           | 165 K                               | металлургия |
| 250   | 250 °C           | 195 K                               | высокотемп. среда |

> **«Использование» класса:** часто проектируют по F (155°C), но в эксплуатации греют только до B (130°C). Это даёт запас 25 K и удваивает срок изоляции (правило Аррениуса: на каждые +10 K срок делится пополам).

## 10.3 Срок службы изоляции (правило Аррениуса)

```
L = L₀ · 2^((T_max − T) / 10)
```
где
- L₀ — нормативный срок (20 000 ч при T_max класса);
- T — фактическая рабочая температура.

Пример: класс F (155°C), фактическая T = 130°C ⇒ L = 20000 · 2^2,5 ≈ 113 000 ч (≈ 13 лет).
А при T = 165°C (перегрев на 10°C): L = 20000 / 2 = 10 000 ч (~1 год).

## 10.4 Пусковая энергия и число пусков

### 10.4.1 Энергия одного пуска
```
E_пуск = J·ω²/2 + ∫₀ᵗ I²R·dt
```
где
- J — момент инерции системы (двигатель + колесо + жидкость);
- ω — конечная угловая скорость;
- I — пусковой ток (5–7 раз номинального);
- R — сопротивление обмотки.

### 10.4.2 Допустимое число пусков (IEC 60034-1, режимы S3-S10)
- **S1** (продолжительный): без ограничений по числу пусков.
- **S2** (кратковременный, 10/30/60/90 мин): 1 пуск из холодного.
- **S3** (повторно-кратковременный, ПВ%, 10/25/40/60 %): расчёт по нагреву.
- **S4** (с пусками): ≤ 6, 30, 60, 90, 120, 240 пусков/час (стандартные значения).
- **S6, S7, S8** — со встроенным охлаждением, регулирование частоты.
- **S9, S10** — нерегулярные циклы.

Для бытовой КНС обычно **S3 25 %** (или хуже — частые пуски). Поэтому:
- Двигатель должен иметь **запас по нагреву** (≥ 20 % недогрузка).
- ПЧ или УПП **обязателен** при количестве пусков > 6/час.
- Минимальное время между пусками: 60 с (для асинхронных).

### 10.4.3 Стандартные циклы для КНС (СП 32 рекоменд.)
| Тип КНС            | Пусков/час | Режим |
|--------------------|-----------|-------|
| Бытовая малая Q<10 м³/ч | до 30 | S3 25 % |
| Бытовая средняя 10-50    | 6-12  | S3 40 % или S6 |
| Промышленная 50-500      | 4-6   | S6 или S1 |
| Магистральная > 500       | 1-2   | S1   |

> **Решение**: для частых пусков (>10/час) применять ПЧ — это переводит режим из S3 в S1, продлевая жизнь двигателя в 3–5 раз.

## 10.5 Охлаждение двигателя погружного насоса

Способы:
1. **Естественное охлаждение жидкостью** (cooling jacket около статора): T_жидкости ≤ 40°C.
2. **Принудительное охлаждение** через рубашку с обводным потоком (Grundfos SEG.40.31).
3. **Воздушное охлаждение** (только для сухой установки).
4. **Масляное охлаждение** (старые серии Grundfos).

Для **бытовых КНС**: жидкостное (1) — стандарт. Допустимая T среды до 40°C.
Для **промстоков с T > 60°C** (литейный шлам, цех гальваники): только сухая установка с принудительным.

# 11. ПРОЧНОСТЬ НАСОСА И ОБВЯЗКИ

## 11.1 Допустимые нагрузки на фланец насоса (ANSI/HI 9.6.2 / ISO 5199)

Стандарт категорирует допустимые силы (F) и моменты (M) на входной и выходной патрубках насоса. Превышение → деформация корпуса, перекос вала, ускоренный износ подшипников и уплотнений.

### 11.1.1 Базовый принцип ANSI/HI 9.6.2 (для центробежного DN50-300)
```
F_max ≈ K_F · DN [Н]
M_max ≈ K_M · DN [Н·м]
```
Типичные значения (DN в мм):
| Насос          | K_F   | K_M    |
|----------------|-------|--------|
| Чугунный корпус (бытовой) | 13   | 10    |
| Стальной корпус            | 22   | 16    |
| Хим. насос с кислотостойким | 9   | 7     |

Например, для DN150:
- Чугун: F_max ≈ 2 кН на каждую ось, M_max ≈ 1500 Н·м.
- Превышение → производитель снимает гарантию.

### 11.1.2 Как контролировать
- **Гибкие компенсаторы** на входном/выходном патрубках (резиновые, сильфонные).
- **Опоры трубопровода** в пределах 1 м от фланцев насоса.
- **Расчёт термической компенсации** магистрали (для горячих сетей).

## 11.3 Расчёт фланцев на изгибающий момент трубопровода (ПНАЭ Г-7-002-86)

Изгибающий момент от температурного расширения / весовой нагрузки трубопровода:
```
M_изг = E·I·κ
σ_изг = M·D/(2·I) = E·κ·D/2
```
где
- E — модуль Юнга трубопровода;
- I — момент инерции сечения;
- κ — кривизна изгиба от тепловой деформации.

Для трубы DN200 (E=200 ГПа) с термоудлинением 10 мм на 50 м длины (T от 0 до +50°C):
- κ = 8·δ/L² = 8·0,01/50² = 3,2·10⁻⁶ 1/м;
- σ_изг = 200·10⁹·3,2·10⁻⁶·0,2/2 = 64 МПа.

Это **существенная нагрузка** на фланец насоса. Решение — П-образный компенсатор или сильфон.

## 11.4 Антивибрационные устройства

### 11.4.1 Резиновые компенсаторы
- Снижение вибрации на 70–85 % в диапазоне 5–500 Гц.
- Срок службы 5–10 лет (зависит от нагрузки и среды).
- DN50–600, PN10–16.
- Применение: вход и выход всех насосов.

### 11.4.2 Сильфонные компенсаторы (металлические)
- Высокая температура (до +400°C) и давление (до PN40).
- Меньше демпфирование, чем у резиновых.
- Применение: горячие сети, пар, химия.

### 11.4.3 Виброопоры (rubber-in-shear)
- Снижение передаваемой вибрации на 90–95 %.
- Под раму насосного агрегата.
- Расчёт по жёсткости: f_n = (1/2π)·√(k/m), должно быть < f_возмущения / 3.

# 12. РАСЧЁТ КОРПУСА КНС/НС

## 12.1 Гидростатическое давление на стенки

```
p_h(z) = ρ·g·h_water(z)        [Па]
```
- ρ = 1000 кг/м³ (вода);
- h_water — высота столба воды над расчётной точкой стенки.

### Распределение по высоте корпуса
| Глубина h, м | p_h, кПа | p_h, кгс/см² |
|--------------|----------|--------------|
| 1            | 9,8      | 0,1          |
| 2            | 19,6     | 0,2          |
| 4            | 39,2     | 0,4          |
| 6            | 58,8     | 0,6          |
| 8            | 78,5     | 0,8          |
| 10           | 98,1     | 1,0          |

Для типового КНС глубиной 6 м максимальное давление на дно ≈ 0,6 кгс/см² от воды.

## 12.2 Боковое давление грунта (формула Кулона)

### 12.2.1 Активное давление (стенка отклоняется от грунта)
```
p_a(z) = K_a · γ_грунта · z
K_a = tan²(45° − φ/2)
```
- γ — удельный вес грунта (16–22 кН/м³);
- φ — угол внутреннего трения (15–40° в зависимости от типа грунта);
- z — глубина от поверхности.

### 12.2.2 Покойное давление (жёсткая стенка не двигается, K₀)
```
p₀(z) = K₀ · γ · z
K₀ = 1 − sin(φ)         (для несвязных грунтов, формула Яки)
K₀ = (1 − sin φ)·OCR^sin(φ)   (для пере-уплотнённых)
```

Для КНС в **жёстком корпусе** применяется K₀ (стенка не пере-двигается).

### Типичные параметры грунтов
| Грунт                  | γ, кН/м³ | φ, °  | K₀     | K_a    |
|------------------------|----------|-------|--------|--------|
| Песок рыхлый            | 16       | 28    | 0,53   | 0,36   |
| Песок плотный           | 19       | 38    | 0,38   | 0,24   |
| Супесь                  | 18       | 30    | 0,50   | 0,33   |
| Суглинок                | 19       | 25    | 0,58   | 0,41   |
| Глина мягкая            | 18       | 18    | 0,69   | 0,53   |
| Глина твёрдая           | 21       | 28    | 0,53   | 0,36   |
| Торф                    | 11       | 12    | 0,79   | 0,66   |
| Скальный грунт         | 25       | 45    | 0,29   | 0,17   |

### 12.2.3 С учётом подземных вод (УГВ)
Если УГВ выше дна корпуса:
```
p_total(z) = (γ_грунта − γ_вод) · z + γ_вод · z   (для z > z_УГВ)
```
Грунт ниже УГВ становится «взвешенным», γ' ≈ γ − 10 кН/м³.

## 12.3 Подъёмная сила Архимеда (всплытие корпуса)

```
F_архим = ρ_воды · g · V_погружённой_части_корпуса
```

При УГВ выше дна корпуса возникает выталкивающая сила. Если она превышает суммарный вес корпуса + содержимого + грунт пригруза, корпус может всплыть.

### Условие безопасности
```
F_arch ≤ G_total / k_safety
G_total = G_корпус + G_оборудование + G_грунт_пригруз + G_бетон_якоря
k_safety = 1,3...1,5 (ВНТП 25-87)
```

### Пример: пластиковый цилиндр Ø2000×6000 мм, УГВ на 1 м ниже поверхности
```
V_корпуса = π·1²·6 = 18,85 м³ (если затоплен полностью)
V_below_УГВ = 18,85 − π·1²·1 = 15,7 м³
F_arch = 1000·9,81·15,7 = 154 кН
```

Вес самого пластика — ~2,5 кН. **Без пригруза корпус всплывёт!** Нужно:
- Бетонная якорная плита: V = 154/(2300·9,81/1000)/1,4 = ~5,5 м³ бетона.
- Альтернатива: грунтовые анкеры, стеновые рёбра жёсткости с пазами для зацепления грунта.

## 12.4 Боковая нагрузка от оборудования

Нагрузка от насоса с трубопроводом передаётся на дно корпуса через:
1. **Базу насоса (квадратный фланец)**: σ = G/A_base.
2. **Опорные кронштейны трубопровода**.
3. **Вибрация при работе** — динамический коэффициент 1,3–1,5.

Для типового погружного насоса 7,5 кВт (масса ~120 кг) с автоматической муфтой и трубопроводом:
- Статическая нагрузка ~2 кН на дно.
- Динамическая ~3 кН.
Полибетонное дно толщиной 200 мм с армированием — стандарт.

## 12.5 Нагрузка от снега и ветра на крышку

### 12.5.1 Снеговая нагрузка
```
S = S₀ · μ_формы · k_h · γ_сн
```
- S₀ — снеговая нагрузка района (СП 20 карта 1);
- μ_формы — для плоской крыши = 1,0;
- k_h — коэффициент перепада высот = 1,0 для одноуровневой крышки;
- γ_сн = 1,4 (предельное состояние).

Для III снегового района (Москва): S = 1,8 · 1,0 · 1,0 · 1,4 = 2,52 кН/м² = 252 кгс/м².

### 12.5.2 Ветровое давление (горизонтальная нагрузка на наземную часть)
```
W = w₀ · k_z · c · γ_ветр
```
- w₀ — нормативное давление района (СП 20 карта 3);
- k_z — коэффициент типа местности (А: открытая, Б: лесопарк, В: город);
- c — аэродинамический коэффициент (~0,8 для боковой стенки);
- γ_ветр = 1,4.

Для III ветрового района, тип А, h = 2 м (наземная часть КНС): 
W = 0,38 · 0,75 · 0,8 · 1,4 = 0,32 кН/м².

## 12.6 Сейсмика (СП 14.13330.2018, ОСР-2015)

### 12.6.1 Карты сейсмичности
- A — частые слабые землетрясения (90 % вероятность за 50 лет).
- B — средние (10 % за 50 лет, нормативные сооружения).
- C — редкие сильные (5 % за 50 лет, особо ответственные).

### 12.6.2 Балл сейсмичности и расчётное ускорение
| Балл MSK-64 | Расчётное a, доли g | Применение |
|------------|---------------------|------------|
| 5          | 0,025               | без специальных мер |
| 6          | 0,05                | минимальные |
| 7          | 0,1                 | стандарт для повышенной сейсмики |
| 8          | 0,2                 | южные регионы (Сочи, Дагестан) |
| 9          | 0,4                 | Курилы, Камчатка |
| 10         | 0,8                 | редкие сейсмические очаги |

### 12.6.3 Сейсмическая нагрузка на КНС
```
F_S = S_a · m_total · k_категория
```
- S_a = α · g (расчётное ускорение);
- m_total — масса всего сооружения;
- k_категория — 1,0 для обычных, 1,2 для категории III, 1,5 для категории II, 2,0 для категории I.

Для КНС в Сочи (8 баллов, категория II): F_S = 0,2 · 9,81 · m · 1,5 = 2,94·m [Н].
Сила направлена горизонтально. Пример: пустой КНС массой 5 т → F_S = 14,7 кН — сопоставимо с весом!

## 12.7 Анкеровка корпуса

### 12.7.1 Бетонная якорная плита
```
V_бетон = (F_arch + F_seismic) · k_safety / (γ_бетон_подв)
γ_бетон_подв = 2300 − 1000 = 1300 кгс/м³ = 12,75 кН/м³ (взвешенный)
```

### 12.7.2 Грунтовые анкеры (для глубоких КНС)
Натяжные анкеры с бетонной заделкой, выдерживающие до 200 кН каждый.

### 12.7.3 Анкерные ремни (для пластиковых корпусов)
ПНД-ленты или нержавеющие тросы, охватывающие корпус и крепящиеся к якорной плите. Стандарт для Plastek, Rainpark, BloPlast.

# 13. ВИБРОАКУСТИКА

## 13.1 Источники вибрации в насосе

1. **Дисбаланс ротора** (G2.5 или G6.3 по ISO 1940-1).
2. **Гидравлические пульсации** (Z·n частоты, где Z = число лопаток).
3. **Кавитация** (broad-band, 1–10 кГц).
4. **Подшипники** (характерные частоты BPFI, BPFO, BSF).
5. **Электромагнитные** (2·f_сети для двухполюсных, частоты пазов).

# 15. ЧИСЛЕННЫЕ МЕТОДЫ (CFD/FEM)

## 15.1 Метод конечных объёмов (Finite Volume Method, FVM)

### 15.1.1 Принцип
Расчётная область разбивается на конечные объёмы (ячейки). Для каждой ячейки — закон сохранения (массы, импульса, энергии) интегрируется по её объёму, обмен потоков идёт через грани.

### 15.1.2 Применение
- Решение Навье-Стокса в проточной части насоса.
- Симуляция кавитации (Schnerr-Sauer / Singhal).
- Multiphase flow (вода+воздух+ил).
- ANSYS CFX, ANSYS Fluent, OpenFOAM, COMSOL CFD.

### 15.1.3 Сетка (mesh)
- Структурированная (гекса) — точнее, требует ручного построения.
- Неструктурированная (тетра/полиэдрическая) — проще, но грубее.
- Hybrid — комбинированная.

Качество сетки оценивается по:
- Aspect ratio (отношение сторон ячейки) ≤ 50;
- Skewness (перекошенность) ≤ 0,9;
- Orthogonality ≥ 0,1.

## 15.2 Метод конечных элементов (Finite Element Method, FEM)

### 15.2.1 Принцип
Область разбивается на конечные элементы. Поле ищется как линейная комбинация базисных функций. Применяется в **прочностных** расчётах (не CFD).

### 15.2.2 Применение для КНС
- Прочность корпуса при нагрузках грунта/воды/сейсмики.
- Резонансный анализ системы насос+труба+фундамент.
- Теплопередача через стенки.

### 15.2.3 Программы
- ANSYS Mechanical
- Abaqus (Dassault)
- SolidWorks Simulation
- LS-DYNA (взрывы, удары)
- NASTRAN

## 15.3 Модели турбулентности (RANS)

### 15.3.1 k-ε (стандартная)
- Универсальная, простая.
- Слабее для отрывных и сильно вихревых течений.
- Быстро сходится. Для предварительных расчётов.

### 15.3.2 k-ω (Wilcox)
- Лучше в пристенной зоне.
- Чувствительна к ω в свободном потоке.

### 15.3.3 k-ω SST (Menter)
- Гибрид: k-ω в стенке, k-ε в свободном потоке.
- **Стандарт для лопастных машин** (центробежные насосы).

### 15.3.4 Reynolds Stress Model (RSM)
- Не использует гипотезу Буссинеска.
- Точнее для сильно анизотропных течений (после поворотов 90°).
- Дороже на ~50 %.

### 15.3.5 LES (Large Eddy Simulation)
- Прямое моделирование больших вихрей.
- Дороже в 10–100 раз RANS.
- Применяется для acoustic emission, вихревые сходы.

### 15.3.6 DNS (Direct Numerical Simulation)
- Полное разрешение всех масштабов.
- Только для академических задач (Re < 10⁴, простая геометрия).

## 15.4 Кавитационное моделирование

### 15.4.1 Schnerr-Sauer
- Базируется на уравнении Рэлея-Плессета.
- Применяется в OpenFOAM.

### 15.4.2 Singhal (Full Cavitation Model)
- Учитывает не только пар воды, но и неконденсируемые газы.
- Стандарт ANSYS CFX.

### 15.4.3 Zwart-Gerber-Belamri
- Упрощённая модель.
- Хорошо предсказывает NPSH3, но не пространственное распределение пузырей.

## 15.5 Программы CFD

### 15.5.1 ANSYS CFX
- Высокая точность для турбомашин.
- Tutorials по центробежным насосам.
- Лицензия дорогая (~3-5 млн ₽/год).

### 15.5.2 ANSYS Fluent
- Универсальная.
- Самая популярная в мире.

### 15.5.3 OpenFOAM
- Open source.
- Бесплатно.
- Гибкость solver-ов (simpleFoam, cavitatingFoam).
- Освоение требует знания C++.

### 15.5.4 SolidWorks Flow Simulation
- Простая, интегрирована в CAD.
- Для базовых расчётов.

### 15.5.5 COMSOL Multiphysics
- Multiphysics: CFD + thermal + structural одновременно.
- Удобный GUI.

### 15.5.6 STAR-CCM+
- Премиум, в ходу у автопрома.
- Поликмодельная сетка.

## 15.6 Когда нужен CFD для КНС

- **Не нужен** для типовых КНС с готовыми насосами (есть Q-H/η/NPSHr из каталога).
- **Нужен** для:
  - Расчёт нестандартных узлов (приёмная камера, форбассейн с криволинейным профилем);
  - Поиск/устранение причин ускоренной кавитации;
  - Оптимизация формы лопастей (конструктор насоса);
  - Прогноз времени осаждения песка/ила в КНС;
  - Анализ режима параллельной работы при пере-распределении расходов.

# 16. ГЛОССАРИЙ

| Термин | Определение |
|--------|-------------|
| **AOR** (Allowable Operating Range) | Диапазон Q, в котором насос может работать без преждевременного износа: 50–125 % BEP (по ANSI/HI 9.6.3). |
| **BEP** (Best Efficiency Point) | Точка наилучшего КПД на Q-H кривой насоса. |
| **BPFI / BPFO / BSF** | Bearing Pass Frequency Inner/Outer/Ball Spin — характерные частоты дефектов подшипника. |
| **Cavitation** | Кавитация: образование и схлопывание пузырей пара в потоке при p < p_sat. |
| **Critical speed** | Критическая скорость ротора — частота, при которой вал входит в резонанс. |
| **Dead head / Shut-off** | Нулевая подача (Q=0); работа против закрытой задвижки. Запрещено более 1–2 мин для большинства центробежных. |
| **Discharge head** | Напор нагнетания (на выходе насоса). |
| **Duty point** | Рабочая точка (Q*, H*) системы. |
| **Electrical pole / pair** | Полюс / пара полюсов асинхронного двигателя. n_синхр = 60·f / p_pairs. |
| **Friction loss** | Потери на трение. |
| **Gauge pressure** | Манометрическое давление (избыточное относительно атмосферного). |
| **Head**| Напор (всегда выражен в метрах столба перекачиваемой жидкости!). |
| **Hydraulic radius** | Гидравлический радиус: R = A / P (площадь на смоченный периметр). |
| **Inducer** | Предвключённый винт перед основным колесом, для снижения NPSHr на 20-40%. |
| **Manometric head** | Манометрический напор = ΔP/(ρg). |
| **MTBF** (Mean Time Between Failures) | Средняя наработка на отказ. |
| **NPSHa** (Net Positive Suction Head Available) | Доступный кавитационный запас (со стороны системы), м. |
| **NPSHr** (Required) | Требуемый кавитационный запас (со стороны насоса), м. |

## ПРИЛОЖЕНИЕ A — Контрольные примеры расчётов

### A.1 Пример 1: Подбор бытовой КНС на 30 чел.

**Исходные данные:**
- Q_сред = 30 чел · 200 л/(чел·сут) / 24 ч = 250 л/ч = 0,25 м³/ч (среднечасовой);
- k_общ = 2,5 ⇒ Q_расч = 0,625 м³/ч + округление до режима пуска ⇒ выбирают насос на ~5–10 м³/ч с режимом включения по уровню;
- Высота подъёма z = 6 м (от дна КНС до точки сброса);
- Длина напорного коллектора L = 50 м, ПЭ100 DN50 (внутр. 44 мм);
- Арматура: 1 затвор + 1 ОК + 2 колена 90° + выход.

**Расчёт:**
- v = (5/3600) / (π·0,022²) = 0,93 м/с при Q=5 м³/ч;
- Re = 0,93·0,044/(1,1·10⁻⁶) = 37 200 ⇒ турбулент;
- λ (Свами-Джейн, ε=0,01 мм): 0,022;
- h_f = 0,022·(50/0,044)·0,93²/(2·9,81) = 1,11 м;
- ζ_total = 0,5+0,3+1,5+0,21·2+1,0 = 3,72; h_loc = 3,72·0,93²/19,62 = 0,16 м;
- H_required = 6 + 1,11 + 0,16 + запас 10 % = 7,8 м.

**Подбор:** Pedrollo SAR 550 + VXm 15/50-N (Q_max = 12 м³/ч, H_max = 50 м).
**Рабочая точка:** ~5 м³/ч @ 8 м, η ~50 %, P ~0,3 кВт.
**Стоимость:** 70–110 тыс ₽ (готовый комплект).

### A.2 Пример 2: NPSH-проверка для горячей воды

**Исходные данные:**
- Котельная циркуляционный насос; T = 95 °C;
- p_sat(95°C) = 84,5 кПа; ρ = 962 кг/м³;
- h_atm = 10,0 м (Москва, p_atm = 100,5 кПа после поправки на высоту);
- Высота столба над насосом h_geom = 0,5 м (затопление);
- Потери на всасе h_loss = 0,3 м;
- NPSHr_насоса (по каталогу) при Q=20 м³/ч = 2,5 м.

**Расчёт NPSHa:**
```
NPSHa = (p_atm − p_sat)/(ρg) + h_geom − h_loss
     = (100,5 − 84,5)·10³/(962·9,81) + 0,5 − 0,3
     = 16/9,438 + 0,2
     = 1,69 + 0,2 = 1,89 м
```

**Сравнение:** NPSHa (1,89) < NPSHr (2,5) ⇒ **кавитация будет!**

**Решение:**
- Поднять заполнение системы до создания избыточного давления p_изб ≥ 0,1 МПа;
- Тогда NPSHa_new = 1,89 + 100/9,438 = 12,5 м ⇒ запас 10 м (отлично).

### A.3 Пример 3: Расчёт гидроудара

**Исходные данные:**
- L_напор = 200 м ПЭ100 SDR17 DN125 (внутр. 110 мм);
- v = 1,8 м/с (при Q = 60 м³/ч);
- Закрытие обратного клапана t_close = 0,5 с (без демпфера).

**Расчёт:**
- c (ПЭ100 SDR17) ≈ 280 м/с;
- t_фаза = 2L/c = 2·200/280 = 1,43 с > 0,5 с ⇒ **полный удар** (формула Жуковского);
- ΔP = 1000·280·1,8 = 504 000 Па = **5,04 бар!**
- При рабочем давлении 2 бар ⇒ пик 7 бар > PN10 ⇒ риск разрыва трубы.

**Решение:**
1. Заменить ОК на демпферный (t_close ≥ 2 с) ⇒ переход к Михайлову;
   - ΔP_Михайлов = 2·200·1000·1,8/2 = 360 000 Па = 3,6 бар (всё ещё много).
2. Установить мембранный гаситель 50 л на нагнетании ⇒ снижение пика в 3–4 раза до ~0,9 бар.
3. **Финал:** P_рабочее + ΔP = 2 + 0,9 = 2,9 бар << PN10 ⇒ безопасно.
