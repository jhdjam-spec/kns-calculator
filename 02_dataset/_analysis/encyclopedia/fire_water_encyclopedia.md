## 1. Нормативная база (полная карта)

Пожарное водоснабжение регулируется двумя слоями документов:

- **Технический регламент** (`123-ФЗ`) — обязательные требования верхнего уровня (категории, степени огнестойкости, время эвакуации).
- **Своды правил** (СП 8.13130, СП 10.13130, СП 485.1311500 и др.) — методики и числовые значения.

## 2. Категории зданий по пожарной опасности (ФЗ-123)

### 2.1. Категории взрывопожарной и пожарной опасности (ст. 27 ФЗ-123, СП 12.13130.2009)

Применяются к **производственным и складским помещениям**. Категория определяется по веществам и материалам, обращающимся в помещении.

| Категория | Название | Характеристика | Примеры |
|-----------|----------|----------------|---------|
| **А** | Повышенная взрывопожароопасность | Горючие газы, ЛВЖ с t_всп ≤28°C; вещества при взаимодействии с водой, кислородом или друг с другом дают взрыв | Цех окраски, нефтебазы, склад ацетона, водородная установка |
| **Б** | Взрывопожароопасность | Горючие пыли/волокна; ЛВЖ с t_всп >28°C; ГЖ в количествах, дающих взрывоопасную смесь | Мукомольное производство, склады мазута >100 т, цеха пыли алюминия |
| **В1** | Пожароопасность | Q_пож > 2200 МДж/м² или ЛВЖ/ГЖ хранятся открыто | Деревообработка, склад резины |
| **В2** | Пожароопасность | Q_пож = 1401-2200 МДж/м² | Цех пластмасс |
| **В3** | Пожароопасность | Q_пож = 181-1400 МДж/м² | Архив, библиотека, мебельный цех |
| **В4** | Пожароопасность | Q_пож = 1-180 МДж/м² | Электрощитовые, бытовые помещения |
| **Г** | Умеренная пожароопасность | Негорючие в горячем/расплавленном состоянии; сжигаемое топливо | Котельная, литейный цех, кузница |
| **Д** | Пониженная пожароопасность | Негорючие материалы в холодном состоянии | Цех мехобработки металла, склад инструмента, гараж легковых авто |

**Удельная пожарная нагрузка** Q_пож рассчитывается по формуле СП 12.13130 (5.1):

```
Q_пож = Σ(G_i · Q_p_i^н) / S, МДж/м²
```

где `G_i` — масса i-го горючего материала, кг; `Q_p_i^н` — низшая теплота сгорания, МДж/кг; `S` — площадь размещения, м².

## 5. Расчёт пожарного резервуара

### 5.1. Базовая формула

(СП 8.13130 п. 7.1, формула 7.1)

```
V_рез = (Q_наруж + Q_внутр) · T · 3.6 + V_спр + V_под
```

где:

- **Q_наруж** — расчётный расход на наружное пожаротушение, л/с (из табл. 1-3 СП 8.13130);
- **Q_внутр** — расход на внутренний водопровод (число струй × Q одной струи), л/с;
- **T** — расчётное время пожара, ч;
- **3.6** — переводной коэффициент (л/с · ч → м³): 1 л/с · 1 ч = 3.6 м³;
- **V_спр** — объём для спринклерной/дренчерной установки, м³;
- **V_под** — объём для автомобиля пожарной охраны (заправка) — обычно 50 м³.

### 5.2. Время пожара T (СП 8.13130 п. 7.4)

| Тип здания | T, ч |
|------------|------|
| Жилые и общественные I, II степ.огн. | **3** |
| Жилые III степ.огн. | 3 |
| Жилые IV, V степ.огн. | 3 |
| Производственные кат. Г, Д | **3** |
| Производственные кат. А, Б, В | **3** |
| Производственные кат. В при площади >50 000 м² | 6 |
| Склады кат. В | **3** (по умолчанию) |
| Стеллажные склады выс. >5.5 м | **2** (расчёт от АУП, СП 485) |
| Закрытые склады нефти и нефтепродуктов | **3-6** (по СП 155.13130) |
| Высотные >75 м (Ф1.3, Ф4) | **3** |
| АЗС | **3** (СП 156.13130) |
| Лесоматериалы | **6** |

### 5.3. Время восстановления (табл. 5 СП 8.13130)

После пожара резервуар должен пополниться за **T_восст**:

| Категория здания | Допустимое время восстановления, ч |
|-------------------|------------------------------------|
| Производственные кат. А, Б, В | **24** |
| Производственные кат. Г, Д | **36** |
| Жилые и общественные | **48** или **72** (для малых посёлков ≤5 тыс. чел.) |
| Сельскохозяйственные | **72** |

Отсюда требование к **расходу водоподпитки**:

```
Q_подпит = V_рез / (T_восст · 3.6), л/с
```

> **Пример**: V=475 м³, T_восст=24 ч → Q_подпит = 475 / (24·3.6) = **5.5 л/с**.

### 5.4. Число резервуаров

(СП 8.13130 п. 7.3)

- При V_рез ≥ **1000 м³** — **не менее 2** резервуаров одинакового объёма.
- При V_рез < 1000 м³ — допустим один (но проектировщики обычно ставят 2 по 50% — на случай ремонта).
- Расстояние между резервуарами — не менее **диаметра резервуара**, чтобы при разрушении одного не повредился второй.
- Подключение — каждый резервуар должен иметь **независимую обвязку** к насосной станции (всасывающая магистраль с задвижкой).

### 5.5. Контрольный объём (для пуска жокей-насоса)

(СП 8.13130 п. 8.2.7, ВНТП 24-86)

В пожарном резервуаре выделяется **неснижаемый запас** для срабатывания автоматики:

```
V_контр ≈ 5-15 м³ (обычно 10 м³)
```

При снижении уровня ниже контрольной отметки:

1. Сигнал на ПКП (приёмно-контрольный прибор);
2. Запуск жокей-насоса;
3. При продолжении падения — запуск основного пожарного насоса;
4. SMS/звонок дежурному.

### 5.6. Конструктивные требования к резервуарам

(СП 8.13130 раздел 7, Изм.№1 от 01.03.2024)

| Параметр | Требование |
|----------|------------|
| Материал | Железобетон (по ГОСТ 17608), стеклопластик, металл с антикоррозией |
| Утепление | Обязательно, если зимой t_грунт < +1°C на отметке низа ёмкости |
| Подогрев | Электрокабель саморегулирующийся 16-30 Вт/м или ПЭНы, если нет постоянного водообмена |
| Крышка | Утеплённая, с люком 800×800 мм, замок-КП или электромагнитный |
| Вентиляция | Дыхательный клапан + противомоскитная сетка |
| Уровнемер | Гидростатический или ультразвуковой, выдает сигнал в SCADA |
| Сигнализация уровня | Минимум 4 уровня: аварийно-низкий, низкий (пуск подпитки), рабочий, аварийно-верхний |
| Дренаж | С обратным клапаном, для удаления воды при ремонте |
| Изоляция от грунтовых вод | Гидроизоляция XYPEX или окрасочная битумная |

### 5.7. Особый случай: совмещение пож.запаса с хозпитьевым

(СП 8.13130 п. 7.5)

Допускается совмещение, если:

- хозпитьевая часть имеет **постоянный водообмен** (не более 24-72 ч застоя);
- неснижаемый пожарный объём **не используется** для хоз.нужд (отбор только сверху);
- предусмотрено перемешивание (циркуляция или подвод свежей воды);
- материалы резервуара санитарно совместимы с питьевой водой (СанПиН 2.1.4.1074-01).

Совмещение **не допускается**, если в технологии используются опасные вещества (заводы химии, металлургия — отдельный пожарный резервуар).

### 6.1. Общая структура НС ППВ

```

               │ всас. магистр.  │
       ┌───────┴──┐    ┌─────────┴──┐    ┌───────────┐

            │                │                │
    ────────┴────────────────┴────────────────┴──────► к ПКМ / гидрантам / ВПВ / АУП
            (нагнетательный коллектор Ø150-300)
```

Дополнительно (для объектов I категории):

- **Дизель-насос** (на случай отключения электроэнергии);
- **АВР** (автоматический ввод резерва) на 2 фидера электропитания;
- **Резервная линия наружного водопровода** (от другого источника).

### 6.2. Категории надёжности подачи воды (СП 8.13130 п. 6.6)

| **II** | МКД ≤50 м, школы, общественные ≤25 тыс. жителей, склады кат. Г, Д | До 6 ч (для устранения аварии) |
| **III** | Малые посёлки ≤5 тыс. чел., ИЖС, складские кат. Г, Д малой ёмкости | До 24 ч |

Категория определяет требования:

| Требование | I | II | III |
|------------|---|----|-----|
| Резервный пожарный насос | ОБЯЗАТЕЛЕН | ОБЯЗАТЕЛЕН | желательно |
| АВР (автоматический ввод резерва) | ОБЯЗАТЕЛЕН | ОБЯЗАТЕЛЕН | не требуется |
| 2-й независимый источник электропитания | ОБЯЗАТЕЛЕН | желателен | не требуется |
| Дизельный насосный агрегат | ОБЯЗАТЕЛЕН (или 2 эл. от разных подстанций) | желателен | — |
| Кольцевание сети ППВ | ОБЯЗАТЕЛЬНО | ОБЯЗАТЕЛЬНО | допустимо тупиковое до 200 м |
| Число вводов в здание | ≥2 | ≥2 при Q≥15 л/с | 1 |

### 6.3. Подбор насоса

**Расход насоса** (СП 8.13130 п. 8.3):

```
Q_нас = Q_наруж + Q_внутр + Q_спр (если нет отд. насоса)
```

**Напор насоса** (полный):

```
H_нас = H_геом + H_потери + H_своб + H_рукав
```

| Компонент | Значение |
|-----------|----------|
| H_геом | Разница отметок: верх здания − ось всаса насоса |
| H_потери | Потери в магистрали (труба + арматура), считаются по СП 30/СП 31 |
| H_своб (свободный) | **10 м.в.ст. у пожарного крана** для напора в стволе |
| H_рукав | Потери в рукаве: ~1.5 м на 20 м рукава при Q=2.6 л/с; ~3 м при Q=5 л/с |

**Пример** для МКД 16 эт.:

- H_геом = 16 · 3 = 48 м;
- H_потери = 0.05 · 48 ≈ 2.4 м (в стояке Ø80 при Q=5.2 л/с);
- H_рукав = 1.5 м;
- H_своб = 10 м;
- **H_нас = 48 + 2.4 + 1.5 + 10 ≈ 62 м**.

### 6.4. Структура: рабочий + резерв + жокей

| Тип насоса | Назначение | Q | H |
|------------|------------|---|---|
| Рабочий пожарный | Подача при пожаре | Q_расч | H_расч |
| Резервный пожарный | Резерв 100% | = рабочему | = рабочему |
| Жокей | Поддержание давления в магистрали | 0.3-1.0 л/с | = H_рабочего ± 5 м |
| Дизель (для I кат.) | Резерв при отказе эл-ва | = рабочему | = рабочему |

**Как срабатывает**:

1. Утечка/расход в системе → давление падает.
2. Жокей-насос включается на реле давления (P_низ ≈ H − 3 м).
3. Если давление продолжает падать (открыты пожарные краны / спринклеры) → запускается **рабочий пожарный** (P_пуск ≈ H − 5 м).
4. Если рабочий не вышел на режим за 30 с (СП 484 п. 7.3.1) → запускается **резервный**.
5. Если оба не справляются (или авария электропитания) → **дизель** (для I категории).

### 6.5. Обвязка насоса

**Всасывающая линия** (1 шт. на каждый насос отдельно):

- задвижка с электроприводом;
- виброкомпенсатор (резиновый);
- манометр на всасе;
- датчик «сухого хода»;
- DN всасывающего трубопровода ≥ DN насоса × 1.25.

**Нагнетательная линия**:

- виброкомпенсатор;
- обратный клапан (тип «бесшумный поворотный» или дисковый);
- задвижка с электроприводом;
- манометр на нагнетании;
- термореле (защита от перегрева при работе на закрытую задвижку);
- расходомер (электромагнитный или ультразвуковой);
- штуцер для манометра-регистратора.

**Коллектор нагнетания** — общий, DN = √(сумма DN отводов²) или по сумме расходов.

### 6.6. Требования к помещению насосной (СП 8.13130 п. 8.5)

| Параметр | Требование |
|----------|------------|
| Выделение | Отдельное помещение с противопожарной перегородкой 1-го типа (REI 45) |
| Дверь | Противопожарная EI 30, открывающаяся наружу |
| Высота помещения | ≥3.0 м (для обслуживания насосов с подвесом) |
| Температура | +5..+35°C |
| Освещение | Аварийное + рабочее, IP54 |
| Вентиляция | Естественная или принудительная, +10..+15°C на воздухе |
| Дренаж | Приямок с дренажным насосом 1-2 л/с |
| Прямой выход наружу | Обязателен для I категории |
| Связь | Прямая телефонная связь со зданием/диспетчерской/пожарной частью |
| Документация на стене | Принципиальная схема + инструкция по пуску |

### 6.7. Автоматика (СП 484.1311500.2020)

ПКП (приёмно-контрольный прибор) должен:

- получать сигналы от датчиков давления, уровня, потока;
- управлять задвижками и насосами;
- передавать сигнал «Пожар» на пульт ЕДДС города;
- иметь резервное питание (UPS на 24 ч);
- иметь журнал событий (минимум 1000 событий);
- иметь возможность тестирования без срабатывания установки.

```
Q_АУП = q_удел · S_защ, л/с
```

### 7.3. Зоны защиты, число оросителей

(СП 485 п. 5.5)

- Расстояние между оросителями: 3-4 м (стандартное).
- Расстояние от стены: ≤1.5 м.
- Высота установки: 0.08-0.40 м под потолком (для стандартных спринклеров).
- Тип спринклера:
  - **СВО** (стандарт. вод. ороситель) — t_сраб 57°C / 68°C / 79°C / 93°C / 141°C;
  - **СВН** (низкого реагирования) — для высоких потолков;
  - **ЕСFR** — early suppression fast response, для стеллажных складов.

### 7.4. Узел управления (УУ)

УУ — это «сердце» спринклерной установки. Размещается на каждой секции (на этаже / в торговом зале).

Состав:

```
Подвод от насоса
    │
    ├── Сигнализатор потока (ПС-ВС, водяной звонок) ──── к ПКП
    │
    ├── Манометр контрольного давления
    │
    ├── Главный запорный кран (с пломбой)
    │
    ├── Обратный клапан
    │
    ├── Подача в распределительную сеть
    │       │
    │       ├── Спринклер 1
    │       ├── Спринклер 2
    │       └── ...
    │
    └── Дренаж + ниппель для проверки

```

УУ устанавливается на доступной высоте 1.0-1.5 м от пола, в выделенном помещении или нише с дверкой.

### 7.5. Дренчерные установки

Отличие от спринклеров:

- **Дренчер** срабатывает целиком (вся секция одновременно) при сигнале от извещателя.
- Применяется для:
  - водяных завес (пожарных штор, занавесов в театрах);
  - орошения стен соседних зданий (наружный дренчер);
  - складов с быстрым распространением огня.
- Управление: электроклапан или пневмопривод от ПКП.

### 7.6. Тонкораспылённая вода (тонкорас)

Современная альтернатива:

- размер капель: 50-200 мкм (против 200-1000 для обычного спринклера);
- расход: в 5-10 раз меньше (0.02-0.05 л/(с·м²));
- работает по двойному механизму: охлаждение + замещение кислорода паром;
- применяется в: серверных, на судах, музеях, машинных залах ГЭС.
- Производители: Marioff (HI-FOG), Tyco AquaMist, INSERVO MicroFog `[ASSUMPTION]`.

### 8.1. Типы гидрантов (ГОСТ Р 53961-2010)

| Тип | Конструкция | Применение |

| Параметр | Значение |

### 8.4. Расчёт расстояния от гидранта до защищаемого объекта

**Радиус действия гидранта** определяется длиной рукавов автоцистерны:

- автонасос АЦ-40: 4×20 м рукавов магистральных (Ø80) + 2×20 м рабочих (Ø65) = до 120 м прямого хода;
- с учётом потерь в рукаве: эффективная зона **100-120 м** (по прямой).

**Покрытие здания**:

```
R_охват = L_рукавов − Δ_застройка
```

где `Δ` — извилистость пути (~20-30%).

Для крупных промышленных предприятий применяют **расчёт сети гидрантов**:

```
N_гидрантов = S_площадки / (π · R_охват²)
```

> **Пример**: завод 30 га (300 000 м²), R=100 м → N = 300 000 / (π · 100²) ≈ **10 гидрантов** минимум, плюс резерв на тупики/проезды.

### 8.5. Эксплуатация гидрантов

(СП 8.13130 п. 12.3, ППБ 01-03)

| Мероприятие | Периодичность |
|-------------|---------------|
| Проверка наличия и доступности | 1 раз/мес |
| Наружный осмотр (отсутствие повреждений) | 1 раз/мес |
| Проверка работоспособности (открытие штока, водоотдача) | 2 раза/год (весна и осень) |

| Окраска колонки (если наземный) | 1 раз/2 года |
| Акт водоотдачи | 1 раз/5 лет |

## 9. Связь пожарной с водоснабжением

### 9.1. Совмещённая система (ИЖС, малые объекты)

**Применение**: посёлки ≤5 тыс. чел., промышленные предприятия II-III категории.

**Схема**:

```
Скважина / водозабор
        │
        ▼
Хоз-питьевой резервуар (часть объёма — пожарный неснижаемый запас)
        │
        ▼
Хозяйственный насос ──► потребители (хозпитьё)
        │
        └──► Пожарный насос (запускается при пожаре) ──► гидранты + ВПВ
```

**Преимущества**:

- одна сеть (экономия трубы);
- циркуляция воды в пожарном объёме (нет застоя).

**Недостатки**:

- при крупном пожаре прекращается хозводоснабжение;
- риск загрязнения хозпитья при дренировании пожарной системы.

### 9.2. Раздельная система

**Применение**: ТРЦ, заводы, объекты МЧС, нефтебазы, высотки >75 м.

**Схема**:

```
Источник                          Источник
   │                                 │
   ▼                                 ▼
Хозпитьевой резервуар         Пожарный резервуар
   │                                 │
Хознасосы                      Пожарные насосы
   │                                 │
   ▼                                 ▼
Сеть хозпитья                  Сеть ППВ (своя, кольцевая)
```

**Преимущества**:

- независимость систем;
- санитарная безопасность хозпитья гарантирована;
- допустимы агрессивные добавки в пожарную воду (например, пенообразователь).

### 9.3. Кольцевая vs тупиковая разводка (СП 8.13130 п. 6.3-6.4)

| Параметр | Кольцевая | Тупиковая |
|----------|-----------|-----------|
| Надёжность | Высокая (вода идёт с двух сторон) | Низкая (одна точка отказа) |
| Допускается при | Все случаи | Только до 200 м от ввода |
| Q_расч | =Q_расч | Q_расч с коэф. 1.0 |
| Стоимость | Выше (больше трубы) | Ниже |
| Применение | Города, заводы, кварталы МКД | ИЖС, удалённые корпуса, хозблоки |

### 9.4. Двухзонная система (для высоток >50 м)

В высотках давление в нижних кранах не должно превышать 0.6 МПа (60 м.в.ст.). Поэтому система делится:

**Принципиальная схема**:

```
Резервуар (внизу)
    │
    ▼
Жокей-Н1 + Пожарный-Н1 (1-я зона) ──► 1-12 эт.
    │
    ▼
Промежуточный резервуар (на тех.этаже на отметке 36 м)
    │
    ▼
Жокей-Н2 + Пожарный-Н2 (2-я зона) ──► 13-25 эт.
    │
    ▼
Промежуточный резервуар (на тех.этаже на отметке 75 м)
    │
    ▼
Жокей-Н3 + Пожарный-Н3 (3-я зона) ──► 26-40 эт.
```

Альтернатива — **редукционные клапаны** на каждом этаже (упрощает схему, но усложняет ТО).

### 10.2. Пример 2. ЖК 12 эт., 50 квартир, V=15 000 м³

**Исходные данные**:

- 12 этажей, h_верх = 36 м, Ф1.3;
- 50 квартир, ~125 жителей;
- степень огн. II, С0;
- район плотной застройки, 25 000 жителей всего;
- городская сеть Ø150 с гидрантами;
- городская сеть давит 25 м.в.ст. (недостаточно для верхних этажей).

**Расчёт**:

| Параметр | Значение | Источник |
|----------|----------|----------|
| Q_наруж | **15 л/с** (V=15 000 м³, II степ., С0) | СП 8.13130 табл. 2, строка для I-II/С0/5-25 тыс.м³ |
| Q_внутр (число струй) | **2 струи × 2.6 л/с = 5.2 л/с** | СП 10.13130 табл. 1 |
| K_огн | 1.0 | СП 8.13130 п. 5.3 |
| n_пожаров | **2** (район 25 тыс.) | СП 8.13130 п. 5.4 |
| T | **3 ч** | СП 8.13130 п. 7.4 |

## 11. Типовые ошибки проектировщика

### 11.1. Неучёт времени восстановления

**Симптом**: проектировщик берёт V_рез по формуле V = Q · T · 3.6, но не проверяет, что подпитка резервуара успеет за T_восст.

**Пример**: Q_подпитка = 2 л/с, V_рез = 500 м³.
T_восст_расч = 500 / (2 · 3.6) = **69 ч** > 24 ч (норма для кат. А).

**Решение**: либо увеличить подпитку (бак к станции водопровода с большим расходом), либо запроектировать **2 резервуара поочерёдно** (один работает, другой пополняется и наоборот).

### 11.2. Завышение времени пожара

**Симптом**: для кат. В без больших площадей берут T=6 ч (вместо 3 ч). Резервуар получается в 2 раза больше реального.

**Решение**: T=6 ч **только для производственных кат. В при S>50 000 м²** (СП 8.13130 п. 7.4) и для лесных складов (СП 155).

### 11.3. Неправильный выбор категории помещения

**Симптом**: проектировщик ставит цех «В1» на основании оценки «там много дерева», но фактически по расчёту Q_пож < 1400 МДж/м² → это В3.

**Последствие**: завышение Q_наруж в 1.5 раза.

**Решение**: расчёт удельной пожарной нагрузки Q_пож по СП 12.13130, формула 5.1. При сомнении — пограничный кейс — проводить полный расчёт пожарного риска.

### 11.4. Игнорирование пожарных зон в высотке

**Симптом**: для МКД 25 эт. (h=75 м) проектируют один насос с H=85 м. На 1-м этаже у крана получается давление 80 м.в.ст. → разрушит рукава.

**Решение**: ОБЯЗАТЕЛЬНО разделение на пожарные зоны (1-12 эт., 13-25 эт. — каждая со своим насосом и резервуаром на тех.этаже).

### 11.5. Забытые гидранты у удалённых корпусов

**Симптом**: на промплощадке гидранты на главной аллее, но вспомогательный корпус в 250 м от ближайшего → не покрыт радиусом 200 м.

**Решение**: проверка покрытия по карте — каждое здание должно быть в зоне ≤200 м от ≥2 гидрантов с разных направлений.

### 11.6. Совмещение пожарного и хозпитьевого без водообмена

**Симптом**: в пожарной части резервуара вода застаивается → бактериальное загрязнение, неприятный запах при пожаре.

**Решение**: либо обеспечить **постоянный перелив** через пожарный объём (циркуляция), либо разделить системы.

### 11.7. Недостаточная подача воды от насоса

**Симптом**: насос подобран по расчётной точке (Q, H), но не учтена работа на закрытую задвижку (термическая защита, риск перегрева).

**Решение**: предусмотреть байпас от нагнетания на всас с термоклапаном или отвод в дренаж при срабатывании реле температуры.

### 11.8. Дренчер без своевременного срабатывания

**Симптом**: дренчер питается от того же ПКП, что и пожарная сигнализация. Пожар → СПС → ПКП → дренчер. Но если ПКП сбоит — нет тушения.

**Решение**: дублирование по 2-м независимым каналам; местная кнопка ручного пуска у входа в защищаемое помещение.

### 11.9. Неутеплённый резервуар в северных регионах

**Симптом**: в Якутске пожарный резервуар без подогрева → промерзание, вода превращается в лёд.

**Решение**: утепление + саморегулирующийся греющий кабель + автоматическая циркуляция (минимальный расход 0.2-0.5 л/с).

### 11.10. Неправильный расчёт высоты подъёма

**Симптом**: H_насоса считают только по H_геом, забывая про потери в магистрали 200 м длиной.

**Решение**: H = H_геом + h_потери (по СП 30 или Дарси-Вейсбаху) + H_своб.

## 12. Глоссарий

### А

**АВР** (автоматический ввод резерва) — устройство автоматического переключения на резервный источник электропитания при аварии основного. Обязателен для I категории надёжности.

**АУП** (автоматическая установка пожаротушения) — установка для автоматического обнаружения и тушения пожара (спринклер, дренчер, газовая, порошковая). Регламент — СП 485.1311500.2020.

**АУПС** — автоматическая установка пожарной сигнализации (СП 484).

**Атриум** — открытое многосветное пространство в здании высотой ≥2 этажа.

### Б

**БПЛ** — блочно-модульная пожарная лестница (запасная эвакуационная).

### В

**Водоотдача** — фактический расход воды (л/с), который сеть может обеспечить под расчётным напором (10 м.в.ст. у гидранта). Подтверждается актом.

**Водопотребление** — расход воды на обычные хозяйственные нужды.

**ВПВ** (внутренний противопожарный водопровод) — система внутри здания с пожарными кранами. Регламент — СП 10.13130.

**ВНС** — водопроводная насосная станция (для хоз-питья).

**ВЗУ** — водозаборное сооружение (скважина, водозабор из реки).

### Г

**Гидрант** (пожарный) — устройство для отбора воды из водопроводной сети в местах размещения пожарной техники. ГОСТ Р 53961-2010.

**Гасящие частицы** — порошок или газ для подавления пламени (для АУП газовых/порошковых).

**ГЖ** — горючая жидкость с t_всп >61°C (мазут, дизель).

### Д

**Дренчер** — спринклер без термозамка, открытый. Срабатывает по сигналу от извещателя, орошая всю секцию одновременно.

**Депо** (пожарное) — здание для размещения пожарной части (Ф4.4).

**Дыхательный клапан** — устройство на резервуаре для выравнивания давления при заполнении/опорожнении.

### Е

**ЕДДС** — единая дежурно-диспетчерская служба (городская).

### Ж

**Жокей-насос** — насос малой производительности (0.3-1 л/с), поддерживающий давление в магистрали в дежурном режиме.

### З

**Запас неснижаемый** — пожарный объём, который не используется для хоз.нужд.

**Зона пожарная** (в высотке) — диапазон этажей с одинаковым давлением подачи воды.

### И

**ИЖС** — индивидуальное жилищное строительство (Ф1.4).

**Извещатель пожарный** — датчик температуры/дыма/пламени (ИП 212, ИП 101 и т.д.).

### К

**Кат. А, Б, В, Г, Д** — категории помещений по взрывопожарной опасности (ст. 27 ФЗ-123).

**Класс С0-С3** — конструктивная пожарная опасность (С0 — не участвует, С3 — сильное участие).

**Колонка пожарная** — устройство для подключения рукавов к гидранту (КП-50, КП-65).

**Кольцевание** — двусторонняя подача воды по сети (повышает надёжность).

**Компактная часть струи** — длина монолитной струи без распыления, м. Минимум по СП 10.13130: 6/8/10 м.

**КП** — категория пожарной опасности.

### Л

**ЛВЖ** — легковоспламеняющаяся жидкость с t_всп ≤61°C (бензин, ацетон, спирт).

**Лестничная клетка незадымляемая** — НЛК (Н1, Н2, Н3) — для эвакуации в высотке.

### М

**Магистраль** — основной нагнетательный трубопровод от насосной станции.

**МЧС** — Министерство по делам гражданской обороны, чрезвычайным ситуациям и ликвидации последствий стихийных бедствий.

### Н

**НПБ** — Нормы пожарной безопасности (устаревшая нумерация, заменены СП 13130).

**НС** — насосная станция.

### О

**Ороситель** — сопло спринклера/дренчера. Бывает розеточный, мембранный, с регулировкой угла.

**Огнестойкость** — способность конструкции сохранять несущую способность при пожаре (R/REI/E).

### П

**ПКП** (приёмно-контрольный прибор) — управляет сигнализацией и автоматикой пожаротушения.

**ПКА** — пожарный кран автоматический.

**ПК** — пожарный кран.

**ППВ** — противопожарный водопровод.

**Подключение «всухую» (сухотруб)** — стояк ВПВ без воды, заполняется автонасосом снаружи. Применяется для неотапливаемых помещений.

**Помпа** — насос (на жаргоне).

### Р

**Радиус действия** — расстояние от пожарного крана/гидранта до самой удалённой точки защищаемого помещения, в пределах которого струя достигает.

**Резервуар пожарный** — ёмкость для хранения воды на случай пожара. V_рез по СП 8.13130.

**Резервный насос** — 100% дублирующий рабочий, запускается при отказе.

**Рукав пожарный** — гибкий трубопровод. ГОСТ Р 51049-2008. РПК-Н-50 / РПК-Н-65 / РПК-Н-80.

### С

**СВО** — стандартный водяной ороситель (спринклер).

**Спринклер** — ороситель с термозамком (стеклянная капсула или сплав Вуда), срабатывает индивидуально при нагреве.

**Сухотруб** — то же, что «подключение всухую».

**СОУЭ** — система оповещения и управления эвакуацией.

**СПС** — система пожарной сигнализации.

**Степень огнестойкости** — I, II, III, IV, V (СП 112).

**Ствол** (пожарный) — оконечное устройство для формирования струи (диаметр спрыска 13/16/19/25 мм).

### Т

**Термозамок** — элемент спринклера, разрушающийся при нагреве: стеклянная колба с жидкостью или сплав Вуда (легкоплавкий).

**Топка** — то же, что котёл (для категорий Г).

### У

**УУ** (узел управления) — секция спринклерной/дренчерной установки.

**УВПК** — узел внутренний пожарный кран.

### Ф

**Ф1-Ф5** — классы функциональной пожарной опасности (ст. 32 ФЗ-123).

**ФЗ-123** — Федеральный закон №123-ФЗ «Технический регламент о требованиях пожарной безопасности».

### Х

**Хозпитьевая вода** — вода для бытовых нужд (питьё, мытьё). СанПиН 2.1.4.1074.

### Ц

**Цех** — производственное помещение (обычно Ф5.1).

### Ш

**Шкаф пожарного крана** (ШПК) — корпус с пожарным краном, рукавом, стволом. ГОСТ Р 51844-2009.

### Э

**Эвакуация** — вынужденное движение людей наружу при пожаре.

**Эмульсия пенная** — водный раствор пенообразователя 1-6%.

## Приложение А. Формулы для калькулятора (быстрая справка)

### А.1. Полный расход на пожаротушение

```
Q_пож_итого = (Q_наруж + Q_внутр + Q_АУП) · K_огн · K_клим · n_пожаров
```

### А.2. Объём резервуара

```
V_рез = (Q_наруж · T_нар + Q_внутр · T_внутр + Q_АУП · T_АУП) · 3.6 + V_спр_зап + V_автоцист
```

### А.3. Подпитка

```
Q_подпит ≥ V_рез / (T_восст · 3.6), л/с
```

### А.4. Напор насоса

```
H_нас = H_геом + H_потери_трасса + H_потери_рукав + H_своб_у_крана(=10 м)
```

### А.5. Число гидрантов

```
N_гидр = ceil(P_контура / 200) + резерв
```

где `P_контура` — периметр площадки или сумма расстояний по дорогам, м.

### А.6. Число пожарных кранов на этаж

```
N_ПК_эт = ceil(P_коридора_эт / (R_струи + L_рукава))
```

где `R_струи` — радиус действия струи (16/20/24 м), `L_рукава` = 20 м.

### А.7. Расход одного спринклера

```
q_спр = K · √P, л/с
```

где `K` — коэффициент производительности (зависит от диаметра выходного отверстия): 0.27 для DN10, 0.42 для DN15, 0.80 для DN20; `P` — давление перед оросителем, бар.

### А.8. Площадь, защищаемая одним спринклером

```
S_спр = π · R² ≈ 12 м² (для радиуса 2 м, типовой)
N_спр = S_зала / S_спр
```

## Приложение Б. Пример полного расчётного блока (TЗ для МКД)

**Объект**: МКД 17 этажей, 4 секции, 250 квартир.

| Параметр | Значение |
|----------|----------|
| Высота верхнего этажа | 51 м |
| Объём здания V | 75 000 м³ |
| Степень огнестойкости | I |
| КПО | С0 |
| Количество жителей | 625 |
| Назначение | Ф1.3 |
| Тип района | Многоэтажная застройка, 50 тыс. жителей |
| Источник воды | Городская сеть Ø200 + резервный пожарный резервуар |

**Расчёт**:

1. Q_наруж = 20 л/с (СП 8.13130 табл. 2, V=50-150 тыс., 17-25 эт.).
2. Q_внутр = 2 струи × 2.6 л/с = 5.2 л/с (СП 10.13130 табл. 1, 17-25 эт.).
3. Зонирование:
   - Зона 1: 1-12 этажи (h до 36 м);
   - Зона 2: 13-17 этажи (h 36-51 м).
4. T = 3 ч.
5. n_пожаров = 1 (отдельное здание).
6. V_рез = (20 + 5.2) · 3 · 3.6 = **272 м³** + 50 м³ (автоцистерна) = **322 м³**.
7. Принять: 2 × 200 м³ железобетонных резервуара (запас 24%).
8. T_восст = 48 ч (общественные).
9. Q_подпит = 200 / (48 · 3.6) = **1.16 л/с** ≈ **1.5 л/с** (с запасом 30%).
10. Категория надёжности: II (h=51 м, на границе I; принять I для безопасности).
11. Структура НС: 2 пожарных насоса (1 рабочий + 1 резерв) + 1 жокей + 1 дизельный агрегат + АВР.
12. H_насоса (зона 2): 51 + 5 (потери) + 1.5 (рукав) + 10 (своб.) = **67.5 м** → 70 м.
13. Q_насоса = 25.2 л/с = **91 м³/ч**.
14. Подбор: KSB Etanorm-FXA 100-200 (Q=100 м³/ч, H=72 м, P=22 кВт).
15. Жокей: Wilo MVI 202 (1 м³/ч, 70 м, 0.55 кВт).
16. Дизельный: Антарус АНТ-Д 100-200 (Q=100, H=72, ЯМЗ-238).
17. Гидранты: 4 шт. на участке + городские (2 шт. в радиусе 100 м) = всего 6 в зоне.
18. Рукавов: 4 шт. на каждом этаже × 17 эт. × 4 секции = 272 шт. (с резервом 10%).
19. Спринклеры: только в подземном паркинге (S=2500 м²) → 250 шт. + узел управления + насос группы.

- район 25 тыс. жителей.

- T_наруж = 3 ч;
- V_рез ≈ 566 м³ → 2×300 м³;

## Приложение И. Связь с пожарными расчётами на риск-ориентированной основе

(Постановление Правительства РФ № 272 от 31.03.2009; Методика МЧС от 30.06.2009 № 382)

Если объект **не подпадает** под нормативные требования или **необходимо обоснование отступления** от нормы — допустим расчёт пожарного риска.

### Алгоритм:

1. Определение расчётных пожарных сценариев (минимум 3-5).
2. Расчёт времени блокирования путей эвакуации опасными факторами пожара (ОФП): температура, дым, токсичные газы, тепловое излучение.
3. Расчёт времени эвакуации (по СП 1.13130.2020).
4. Сравнение: если t_эвакуации < t_блокирования + запас, то риск приемлемый.

### Допустимый риск:

```
R_прив < 1·10^-6 (год)^-1
```

Если расчёт показывает приемлемый риск — допустимо упростить требования к ППВ (например, не делать резервуар при наличии городской сети с увеличенным временем доезда подразделений).

### Программное обеспечение:

- ToxiCalc;
- FireRisk (МЧС);
- PyroSim + FDS (Fire Dynamics Simulator).

## Приложение К. Полевые замеры и эксплуатационные проверки

### К.1. Акт водоотдачи (форма ППБ-2009-01)

Минимум содержит:

- Адрес объекта.
- Дата и время проверки.
- Метеоусловия (температура, осадки).
- Перечень проверенных гидрантов / кранов с координатами (GPS или № позиции на плане).
- Замеренный расход (л/с) и давление (м.в.ст.) на каждой точке.
- Соответствие проектным данным (отклонение ≤10%).
- Подписи: представитель эксплуатирующей организации, представитель пожарной охраны.

### К.2. Методика замера

- Использовать **расходомер пожарный** ИРВИС-РФП-50/65 или аналог (для гидрантов).
- Открыть гидрант полностью (8-12 оборотов штока).
- Дать стечь воде 10-15 с (для очистки колонки).
- Установить мерный мешок объёмом 100 л.
- Засечь время заполнения.
- Q = V / t, л/с.
- Манометр у штатива должен показать ≥10 м.в.ст. при свободном изливе.

### К.3. Часто встречающиеся отклонения

| Симптом | Причина | Что делать |
|---------|---------|------------|
| Q < 5 л/с при норме 10 л/с | Засорение, перекрытие на сети | Прочистка, ревизия задвижек на магистрали |
| Не открывается шток | Заклинивание после длит. простоя | Промывка, замена резиновых уплотнителей |
| Нет давления | Авария на сети | Сообщить в водоканал, поставить отметку в журнале |
| Утечка вокруг колонки | Нарушение уплотнения | Заменить манжету (плановое ТО раз в 5 лет) |
| Ржавая вода | Коррозия трубопровода | После 2 минут пролива — проверить чистоту воды для пожарных нужд (приемлемо), но для хозпитья нет |

## Приложение Л. Нюансы для конкретных типов объектов

### Л.1. Школы и детские сады (Ф1.1, Ф4.1)

- Резервуар обычно совмещённый хоз+пож;
- ВПВ в школах от 4-х этажей или V > 5000 м³;
- Дет.сад — ВПВ обычно не нужен, но обязательны автономные дымовые извещатели в каждом помещении;
- Спринклеры — по решению заказчика, не обязательны.

### Л.2. Больницы и поликлиники (Ф1.1, Ф3.4)

- Категория надёжности I (есть пациенты, ограниченные в движении);
- Дизель-агрегат обязателен;
- Резервуар отдельный от хоз;
- Спринклеры в архивах, серверных, кладовых.

### Л.3. Склады

- Стеллажные склады выс. >5.5 м — обязательно АУП по СП 485;
- Особое внимание: склады лесоматериалов (T=6 ч), склады каучука/резины (Q=0.4 л/(с·м²)), склады пиротехники (только спец. АУП).

### Л.4. Гостиницы (Ф1.2)

- ВПВ обязательно от 4 эт. (по Изм.№1 СП 10.13130);
- 1 струя × 2.6 л/с в номерах;
- 2 струи в коридорах и холлах;
- Спринклеры в подземных паркингах.

### Л.5. Высотные жилые комплексы (>50 м, особенно >75 м)

- Зонирование пожарной системы обязательно;
- Промежуточные резервуары на технических этажах;
- Незадымляемые лестничные клетки Н1/Н2/Н3 с подпором воздуха;
- Автоматическая система пожарной сигнализации с дублированием по 2 каналам;
- Пожарный лифт (по ГОСТ Р 53296);
- Связь со службой 112 и ЕДДС.

### Л.6. Логистические парки (Ф5.2)

- Огромные V (50-500 тыс. м³) → высокие Q (50-200 л/с);
- Решение: распределённая система (несколько НС по периметру, каждая на свою секцию);
- Резервуар 1500-3000 м³ на каждую секцию;
- АУП обязательно.

### Л.7. Промышленные предприятия с горючей пылью (Б)

- Категория Б = особо опасные (пыль = взрыв);
- Поправочный коэф. K = 1.2 на расход;
- ОБЯЗАТЕЛЬНО: автоматическая система обнаружения и подавления взрыва (ВЭП-системы);
- Спринклеры обычно неэффективны (пыль не тушится водой); применяют пены, инертные газы.

### Л.8. Кабельные тоннели и кабельные сооружения

- Дренчерное пожаротушение по СП 485;
- Альтернатива — азотное (заполнение N₂);
- Расход воды: 0.12 л/(с·м²), время 30 мин.

### Л.9. Серверные и data-центры

- ВОДА ПОД ЗАПРЕТОМ! (риск повреждения оборудования);
- Применяют газовое пожаротушение: FK-5-1-12 (Novec 1230), FE-13, или инертные смеси (Argonite, IG-541);
- Допустимая концентрация в воздухе: ≤30% от LOAEL (No Observed Adverse Effect Level) для эвакуации персонала;
- Подача газа за 60 секунд после обнаружения;
- Время удержания концентрации: ≥10 минут.

### Л.10. Подземные сооружения (метро, тоннели)

- Особый норматив: СП 120.13330.2012 «Метрополитены»;
- Обязательно водяное пожаротушение в кабельных каналах;
- Пожарные краны на платформах через 25 м;
- Резервуары на станционных уровнях.

## Приложение М. Чек-лист «На что обратить внимание ДО начала проектирования»

20 ключевых вопросов к заказчику:

1. Назначение объекта (точно указать класс Ф1.x / Ф2.x / Ф3.x / Ф4.x / Ф5.x).
2. Категория помещений по взрывопожарной опасности (А-Д) — есть ли расчёт?
3. Степень огнестойкости здания (I-V) — определена в АР?
4. Объём здания V в м³ (полный, не только полезный).
5. Высота от земли до верха верхнего этажа (для определения зон).
6. Число жителей / посетителей (для жилых/общественных).
7. Источник наружного водоснабжения: городская сеть Ø? с гидрантами? на каком расстоянии? давление?
8. Имеется ли акт водоотдачи (давность ≤5 лет)?
9. Если нет городской сети — есть ли скважина? Дебит? Качество воды?

## Приложение Н. Полезные расчёты «на пальцах»

### Н.1. Быстрая оценка V_рез

```
V_рез [м³] ≈ Q_общ [л/с] · 10
```

Грубая оценка: для T=3 ч → V = Q·3·3.6 = Q·10.8 м³. Если хотите запас — берите V = Q·12.

### Н.2. Быстрая оценка мощности насоса

```
P_насоса [кВт] = Q [л/с] · H [м] / (102 · η)
```

где `η` — КПД (~0.6-0.75 для пожарных насосов с учётом запаса по двигателю).

### Н.3. Быстрая оценка диаметра магистрали

При скорости v = 1.5-2.5 м/с:

```
D [мм] = √(4·Q [м³/с] / (π·v))·1000
```

| Q, л/с | D рекомендуемый, мм |
|---------|----------------------|
| 5 | 80 |
| 10 | 100 |
| 15 | 100-125 |
| 20 | 125 |
| 25 | 150 |
| 35 | 150-200 |
| 50 | 200 |
| 75 | 250 |
| 100 | 300 |
| 150 | 350 |
| 200 | 400 |

### Н.4. Быстрая оценка размера насосной станции (помещения)

```
S_помещ [м²] ≈ N_насосов · 8 + 20 (на коллектор, проход, пульт)
```

| Конфигурация | Площадь, м² |
|---------------|--------------|
| 1 рабочий + 1 резерв + 1 жокей | ~30 |
| 2 рабочих + 1 резерв + 1 жокей | ~40 |
| 2 рабочих + 1 резерв + 1 жокей + 1 дизель | ~60 |
| 3 рабочих + 1 резерв + 2 жокея + дизель + АВР | ~80 |

### Н.5. Быстрая оценка число гидрантов

```
N ≈ P_периметра / 200 + 1 (на тупиковый участок)
```

Для участка 100×80 м (P=360 м): N=2-3 гидранта (с учётом покрытия здания с двух сторон).
