# Энциклопедия водоснабжения А-Я

> Внутренний источник для модуля `/teach/water_supply` калькулятора КНС (Серво-Юг).
> Назначение: справочник проектировщика по холодному и горячему водоснабжению, наружным сетям, насосным станциям водоснабжения (ВНС), водозаборам, резервуарам, подкачкам и водоподготовке.
> Все нормы — действующие на 2026 г. редакции с указанием параграфов.
> Сокращения: ХВС — холодное водоснабжение; ГВС — горячее водоснабжение; ВНС — водопроводная насосная станция; ВЗС — водозаборное сооружение; В1 — хозпитьевой водопровод; В2 — пожарный; В3 — производственный; Т3/Т4 — горячая вода подающая/обратная.

### 1.2 СП 30.13330.2020 — детальное содержание (для проектировщика)

**Раздел 1. Область применения** — здания жилые, общественные, производственные.

**Раздел 4. Общие положения** — В1 (хозпитьевой), В2 (противопожарный), В3 (производственный), К1 (бытовая канализация), К2 (производственная), К3 (дождевая внутренняя).

**Раздел 5. Расчёт расхода воды**:
- §5.1 — Q сут (м³/сут), Q сред, Q max сут.
- §5.2 — секундный расчётный расход q с (л/с) через α(P·N) — табл. 3 СП 30 (а в прил. Б развёрнутая).
- §5.3 — расход на ввод и магистраль.
- §5.4 — для производственных — по технологии.

**Раздел 6. Системы внутреннего В1, В2, В3**:
- §6.1 — типы систем (тупиковая, кольцевая).
- §6.2 — В2: внутренний пожарный — 1-2-4 струи 2.5 л/с каждая (по этажности и площади).
- §6.3 — общий В1+В2 разрешён в зданиях до 12 этажей.
- §6.7 — раздельный В1+В2+В3 для производственных.

**Раздел 7. Сети, оборудование, узлы**:
- §7.1 — материалы (сталь, чугун, ПЭ, ППР, медь).
- §7.2 — скорости 0.7-2.0 м/с в магистрали; 0.7-1.5 в стояках; 1.5-2.0 на вводах.
- §7.3 — диаметры стояков, отводов, подводок.
- §7.4 — водомерный узел, обводная линия.
- §7.5 — счётчики воды (4 типа: крыльчатый сухой/мокрый, турбинный, комбинированный); табл. 7 — подбор.
- §7.6 — вводы: глубина заложения = глубина промерзания + 0.5 м.
- §7.10 — зонирование высотных зданий (Pmax = 0.45 МПа на нижнем этаже зоны).

**Раздел 8. ГВС**:
- §8.1 — типы (открытая = из теплосетей; закрытая = через теплообменник).
- §8.2 — норма ГВС: q h = 50-130 л/чел·сут (прил. А).
- §8.3 — циркуляция Т3/Т4 при длине магистрали > 20 м.
- §8.5 — температура подачи 60 °C (СанПиН — против Legionella), на смесителе ≥50 °C.
- §8.6 — мощность теплообменника = q ч.max ГВС × ρ × cp × ΔT.

**Раздел 9. Канализация К1, К2** — выходит за рамки этой главы.

**Раздел 10. Внутренние водостоки К3** — крыши.

**Приложения**:

### 1.4 СП 399.1325800.2018 — практика

Дополняет СП 30 и СП 31 в части производства работ:
- Глубина заложения = глубина промерзания + 0.5 м (для холодного водопровода).
- Уклоны самотёчных канализационных = 0.008-0.02 в зависимости от диаметра.
- Испытания на прочность — 1.5 × Pраб.
- Гидравлические испытания на герметичность.
- Промывка и хлорирование перед сдачей.

### 1.5 СанПиН 2.1.3684-21 — гигиенические требования

- Вода питьевая должна соответствовать гигиеническим нормативам по микробиологии, паразитологии, химии, радиологии (приложения к СанПиН 1.2.3685-21).
- Зоны санитарной охраны источника — обязательны.
- Контроль качества — производственный (лаборатория ВОДОКАНАЛА) + государственный (Роспотребнадзор).

### 1.6 ГОСТ Р 51232-98

Определение «питьевой воды»: должна соответствовать СанПиН 1.2.3685-21 (заменил 2.1.4.1074-01) по органолептическим, химическим, микробиологическим и радиологическим показателям.

Параметры МПК (наиболее частые при проектировании):
- Цветность ≤ 20 град.
- Мутность ≤ 1.5 мг/л.
- Запах ≤ 2 балла.
- pH 6.5–8.5.
- Жёсткость общая ≤ 7.0 мг-экв/л.
- Железо ≤ 0.3 мг/л.
- Марганец ≤ 0.1 мг/л.
- Сухой остаток ≤ 1000 мг/л.
- Хлориды ≤ 350 мг/л.
- Сульфаты ≤ 500 мг/л.
- Фтор ≤ 1.5 мг/л.
- Нитраты ≤ 45 мг/л.
- ОМЧ ≤ 50 КОЕ/мл, общие колиформы — отсутствие, термотолерантные колиформы — отсутствие.

### 1.7 ГОСТ Р 56541-2015 — гидравлика

Формула Дарси-Вейсбаха:
```
Δh = λ × (L/d) × (v²/(2g))
```

Где:
- Δh — потери напора, м.
- λ — коэффициент трения по Шифринсону или Альтшулю (0.02–0.04 для металла).
- L — длина участка, м.
- d — внутренний диаметр, м.
- v — скорость, м/с.
- g = 9.81 м/с².

Эквивалентная шероховатость k:
- Новая сталь — 0.05 мм.
- Эксплуатируемая сталь — 0.5–1.5 мм.
- Чугун — 0.5–1.0 мм.
- ПЭ100 — 0.01–0.02 мм.
- ППР — 0.007 мм.

## 2. Расход воды — нормы потребления (СП 30 прил. А)

### 2.1 Принцип нормирования

Норма расхода воды — количество воды на 1 расчётную единицу (житель / номер / учащийся / посетитель / койка) в сутки.

Для каждого типа объекта в прил. А СП 30.13330.2020 даны:
- q общ — общий расход (ХВС + ГВС вместе), л/сут.
- q гор — расход горячей воды, л/сут.
- q ч.общ — общий часовой максимальный расход, л/ч.
- q ч.гор — горячий часовой, л/ч.
- q с — секундный расчётный для α-метода, л/с.

## 3. Расходы Q сут / сред / max сут / max час / max сек

### 3.1 Q сут (м³/сут)

Среднесуточный расход:
```
Q сут.ср = N × q общ / 1000      [м³/сут]
```

Где:
- N — число расчётных единиц (жителей, номеров, посетителей).
- q общ — норма из табл. (л/чел·сут).

Пример: 50-квартирный дом, 3 чел/кв (среднее), q общ = 250 л/чел·сут (с центральным ГВС):
```
Q сут.ср = 150 × 250 / 1000 = 37.5 м³/сут
```

### 3.2 Q max сут (м³/сут) — максимально-суточный

```
Q max.сут = K сут.max × Q сут.ср       [м³/сут]
```

Где K сут.max — коэффициент суточной неравномерности (СП 31, §5.2):

| Тип объекта | K сут.max |
|-------------|-----------|
| Города и крупные посёлки (>50 тыс. чел.) | 1.1–1.2 |
| Малые посёлки (1–50 тыс. чел.) | 1.2 |
| Сёла | 1.3 |
| Промпредприятия (только бытовое) | 1.0 |
| Курортные / дачные посёлки (сезонная нагрузка) | 1.5–2.0 |

Расчёт магистралей и ёмкостных сооружений ведут по Q max.сут.

### 3.3 K сут.min, Q сут.min

```
Q сут.min = K сут.min × Q сут.ср
K сут.min = 0.7–0.9
```

Используется для проверки минимальных скоростей в трубопроводах (избежать осаждения).

### 3.4 Q max час (м³/ч) — максимально-часовой

```
Q max.час = (Q max.сут / 24) × K час.max     [м³/ч]
```

K час.max определяется по СП 31 табл. 2 для городов:

| Среднесут. расход в наиболее загруж. сутки, тыс. м³/сут | K час.max | K час.min |
|---------------------------------------------------------|-----------|-----------|
| До 0.1 | 4.5 | 0.01 |
| 0.1 – 0.2 | 3.5 | 0.05 |
| 0.2 – 0.5 | 2.8 | 0.1 |
| 0.5 – 1.0 | 2.5 | 0.15 |
| 1.0 – 5.0 | 2.0 | 0.2 |
| 5.0 – 50.0 | 1.7 | 0.3 |
| Свыше 50.0 | 1.5 | 0.4 |

Для малых объектов формула связи через α и β:
```
K час.max = α макс × β макс
α макс — 1.2–1.4 (тип объекта)
β макс — 4.5–1.5 (от числа жителей N)
```

K час.min = α мин × β мин (для проверки наименьшей скорости).

### 3.5 Q max сек (л/с) — максимально-секундный

Применяется для **внутренних** сетей В1, В2, В3 (СП 30, §5.2):

```
q с = q с0 × α(P, N)         [л/с]
```

Где:
- q с0 — секундный расход одним прибором (по табл. 1 СП 30): для смесителя ванны 0.25 л/с, для унитаза с бачком 0.1 л/с, для смесителя умывальника 0.12 л/с, для писсуара 0.035 л/с, для смесителя кухонной мойки 0.12 л/с, для душа 0.12 л/с.
- α — коэффициент совмещённого действия приборов (зависит от P × N).
- N — число водоразборных приборов на расчётном участке.
- P — вероятность одновременного действия одного прибора.

Расчёт P:
```
P = (q ч × U) / (q с0 × N × 3600)
```

Где:
- q ч — часовой расход прибора, л/ч.
- U — число потребителей (жителей).
- q с0 — секундный расход, л/с.
- N — число приборов.

### 3.6 α-коэффициенты (прил. Б СП 30) — табличные значения

| P × N | α | P × N | α |
|-------|---|-------|---|
| 0.001 | 0.200 | 0.5 | 0.751 |
| 0.005 | 0.207 | 1.0 | 1.000 |
| 0.01 | 0.222 | 2.0 | 1.435 |
| 0.02 | 0.245 | 5.0 | 2.625 |
| 0.05 | 0.292 | 10 | 4.302 |
| 0.1 | 0.350 | 20 | 7.302 |
| 0.2 | 0.456 | 50 | 16.05 |
| 0.3 | 0.555 | 100 | 30.05 |
| 0.4 | 0.654 | 200 | 56.05 |

> Примечания. Для значений P·N в диапазоне 0.001 – 200 — линейная интерполяция. При P·N > 200 формула α = 0.30 × √(PN) + 0.05.

### 3.7 Алгоритм расчёта q с (на пальцах)

1. Считаем N — общее число водоразборных приборов на расчётном участке (магистраль, стояк, отвод).
2. Принимаем q с0 — наибольшее значение прибора в системе (обычно 0.3 л/с — ванна с подмесом или 0.25 л/с — обычная ванна).
3. По табл. 2 СП 30 выбираем q ч в зависимости от типа здания (4–10 л/ч на 1 потребителя).
4. Считаем P = q ч × U / (q с0 × N × 3600).
5. Считаем P × N.
6. По табл. в Б СП 30 находим α.
7. Считаем q с = 5 × q с0 × α.

Пример: 50-квартирный дом, 150 жителей, 6 приборов на квартиру = 300 приборов:
```
q с0 = 0.3 л/с
q ч = 10 л/ч (центральное ГВС)
P = 10 × 150 / (0.3 × 300 × 3600) = 1500 / 324000 = 0.00463
P × N = 0.00463 × 300 = 1.389
α(1.389) ≈ 1.21 (интерполяция между 1.0 и 2.0)
q с = 5 × 0.3 × 1.21 = 1.815 л/с ≈ 1.8 л/с
```

### 3.8 q ч.max — максимальный часовой расход внутренних сетей

Для всего здания:
```
q ч = 0.005 × q ч.0 × α ч            [м³/ч]
α ч = α(P ч × N), где P ч = 3600 × P × q с0 / q ч.0
```

q ч.0 — часовой расход прибора (для ванны 200 л/ч, для унитаза 83 л/ч и т.п. по табл. 1).

### 3.9 Q max сут для пожарных нужд

Внутренний пожарный В2 — расход на 1 струю (СП 10.13130 §4):
- Жилые до 12 этажей: 1 струя × 2.5 л/с.
- Жилые 12-25 этажей: 2 струи × 2.5 л/с.
- Здания общественные с числом этажей до 10: 2 струи × 2.5 л/с.
- Здания общественные ≥ 16 этажей: 4 струи × 5 л/с.

Наружный пожар (СП 8.13130 §5, §6) для городов и посёлков:

| Численность населения, тыс. чел. | Расход на 1 пожар, л/с |
|----------------------------------|------------------------|
| До 1.0 | 5 |
| 1.0 – 5.0 | 10 |
| 5.0 – 10.0 | 10 |
| 10.0 – 25.0 | 15 |
| 25.0 – 50.0 | 25 |
| 50.0 – 100.0 | 35 |
| 100.0 – 200.0 | 40 |
| 200.0 – 300.0 | 55 |
| 300.0 – 500.0 | 65 |

При расчёте магистрали учитывают: 1 пожар (для нас. пунктов) или 2 пожара (для городов >100 тыс.). Время пожара 3 ч (для жилых и админ.) или 2 ч (для пром).

## 5. Внешние сети (СП 31)

### 5.1 Тупиковая vs кольцевая

**Тупиковая** — линейная схема. Используется для:
- Малых посёлков, отдельных групп зданий (≤ 1500 чел).
- Промплощадок без особых требований.

Минусы: при аварии — отключение всей последующей части; нет резервирования.

**Кольцевая** — все магистральные линии замкнуты в кольцо. Используется для:
- Городов, крупных посёлков.
- Объектов с противопожарным водопроводом В2.
- Крупных промпредприятий.

Плюсы: 2-сторонняя подача (резервирование); меньшее давление в час пик; высокая пожарная надёжность.

Согласно СП 31 §11.4: для городов с ≥ 1500 чел. сети ХВС с противопожарным расходом — обязательно кольцевые.

### 5.2 Совмещённые / раздельные системы

#### Хозпитьевая + противопожарная (В1+В2)

Допускается совместная сеть (ХВС-противопожарная) когда:
- ХВС и В2 идут от одного источника (ВНС).
- Расчётный расход = q ХВС.час.max + q В2.

Важно: на вводе в каждое здание — обязательный ввод, на котором стоит обратный клапан и пож. насос с пониженным запретным режимом, чтобы при пожаре не «садились» здания вокруг.

#### Хозпитьевая + производственная (В1+В3)

Не допускается смешивать, если:
- В3 содержит вредные вещества (есть риск загрязнения В1).
- Питьевая вода идёт под давлением выше технической — возможен подсос.

Для разделения ставят зону санитарной защиты (разрыв струи / обратный клапан с проверкой ASSE 1015 или СП 30 §7.7).

### 5.3 Проектирование магистралей — методы расчёта

#### Метод увязки колец (Лобачёва-Кросса)

Алгоритм:
1. Назначаем диаметры всех участков предварительно (по экономической скорости 0.7–1.5 м/с).
2. Считаем потери напора по каждому участку Δh = S × q².
3. На каждом кольце сумма потерь по часовой - сумма против часовой = δ ≠ 0.
4. Корректируем расходы Δq = -δ / (2 × Σ S × q ).
5. Повторяем 2-4 до δ < 0.5 м (5-10 итераций).

#### Метод Шевелёва

Использует таблицы потерь для стальных и чугунных труб (1976 г.) с коррекцией на возраст (k = 1+a×L где a — старение).

#### Современные программы

- **Hydra** (российская) — Лобачёв-Кросс, гидравлический расчёт.
- **EPANET** (США, бесплатная) — стандарт де-факто.
- **WaterGEMS** (Bentley) — премиум.
- **Гидросистема** (НТП «Трубопровод») — российская промышленная.

### 5.4 Глубина заложения

```
H зал = H пром + 0.3 м        [для холодной питьевой]
H зал = H пром – 0.5 м        [для горячей или магистральных в промзоне]
```

Глубина промерзания (СП 131.13330):
- Москва — 1.4 м.
- Санкт-Петербург — 1.2 м.
- Краснодар — 0.6 м.
- Новосибирск — 2.2 м.
- Якутск — 3.0 м.
- Сочи — 0.4 м.
- Симферополь — 0.6 м.

Над верхом трубы должно быть ≥ 0.5 м засыпки + 0.5 м асфальт/дорожное покрытие в проездах.

## 6. Насосные станции водоснабжения (ВНС)

### 6.1 Классификация по подъёмам

#### I подъём (от водозабора к РЧВ или станции водоподготовки)

Назначение: забор воды из источника (скважина, река, водохранилище) и подача на станцию очистки или РЧВ.

Особенности:
- Работает 24/7 в равномерном режиме.
- Q I подъём = Q сред.сут (с учётом резерва станции водоподготовки).
- Насосы — обычно скважинные (для подземных) или горизонтальные центробежные (для поверхностных) с пологой характеристикой.

#### II подъём (от РЧВ в город)

Назначение: подача воды из РЧВ в распределительную сеть города.

Особенности:
- Работает в неравномерном режиме (следует за потреблением).
- Имеет частотный регулятор (VFD) или ступенчатое регулирование (несколько насосов).
- Q II подъём = Q max.час городского.
- Резервирование 100 % (категория I надёжности).

#### III подъём (повысительные внутри города)

Назначение: повышение давления для отдалённых районов или верхних этажей.

Особенности:
- Применяется в высотной застройке и в районах с большим перепадом высот.
- Q III подъём = local q max.
- Может стоять в подвале здания или в отдельной камере.

### 6.2 Подбор насоса по точке Q-H

Расчётная точка определяется:
```
Q расч = Q max.час(с) для II/III подъёмов
Q расч = Q сред.сут.час для I подъёма

H расч = H геом + Σ Δh + H ост        [м]
H геом — высота подъёма от источника до точки потребления
Σ Δh — потери в трубопроводах и арматуре
H ост — остаточный напор на нижнем краю потребителя (для В2 ≥ 10 м, для бытовых ≥ 6-10 м)
```

После расчётной точки на графике Q-H конкретного насоса:
1. Q расч должен попадать в рабочий диапазон 50-100 % от номинального.
2. КПД на расчётной точке ≥ 75 % (оптимум для пром насоса 75-85 %).
3. NPSH доступный ≥ NPSH требуемый + 0.5 м (запас от кавитации).

### 6.3 Параллельное включение

Использование 2-3 насосов параллельно увеличивает Q при том же H (или почти том же).

При параллельной работе суммарная характеристика:
- Q сум(H) = n × Q отдельный(H) — при идеальном режиме.
- На практике при росте Q потери растут — характеристика «выгибается».

Регулирование:
- **Ступенчатое** — включается/выключается насос по уставке давления.
- **Частотное (VFD)** — изменяется скорость двигателя; самая энергоэффективная.
- **Гидроаккумулятор** — буферирует суточные пики (для малых систем).

### 6.4 Проектирование ВНС — состав

Стандартная компоновка:
1. Помещение машинного зала (3-6 насосов).
2. Электрощитовая.
3. Помещение приборов управления (ЩУ/АСУ).
4. Аварийный санузел.
5. Венткамера (при > 50 кВт суммарной).
6. Помещение оператора (категория I надёжности).
7. Кладовая ЗИП.

Элементы:
- Магистральный коллектор с задвижками.
- Обратные клапаны на каждом насосе.
- Ра-измерения давления и расхода.
- Дренажный приямок с дренажным насосом.
- Автоматические гидроаккумуляторы 100-2000 л.

### 6.5 Категории надёжности (СП 31 §6.5)

| Категория | Допустимый перерыв подачи | Применение |
|-----------|----------------------------|------------|
| I | Не допускается | Города с населением ≥ 50 тыс., больницы, ОПО, военные объекты |
| II | До 6 ч в сутки (с пониженным расходом) | Населённые пункты 5-50 тыс. |
| III | До 24 ч в сутки | Малые посёлки, дачные посёлки |

Для I категории:
- Минимум 2 источника (или 2 ВНС).
- 2 ввода на здание.
- Полное резервирование оборудования (n+1).
- Аварийное электропитание (ДГУ).

### 6.6 Резервный насос

По СП 31 §9.2:
- 1 рабочий насос — 1 резервный (минимум).
- 2-3 рабочих — 1 резервный.
- ≥ 4 рабочих — 2 резервных.
- Для III категории резерв может не предусматриваться, если есть резервный источник или устаревшее оборудование на складе.

### 6.7 Запас в РЧВ

Согласно СП 31 §10.1:
```
V РЧВ = V регулирующий + V пожарный + V аварийный + V на собственные нужды
```

- V регулирующий = 10-20 % от Q max.сут (для городов до 50 тыс.) или 4-8 % (для крупных).
- V пожарный = 3 ч × q пож (для жилых) + расход на наружное и внутреннее пожаротушение.
- V аварийный = время устранения аварии × Q max.сут / 24 (≥ 1 ч).
- V на собственные нужды = 5-10 % (промывка фильтров и т. п.).

Пример: город 30 тыс. чел., Q max.сут = 7000 м³/сут, q пож = 25 л/с:
- V рег = 10 % × 7000 = 700 м³.
- V пож = 3 × 3600 × 25 / 1000 = 270 м³ + 50 м³ внутренний = 320 м³.
- V авар = 2 × 7000 / 24 = 580 м³.
- V соб = 5 % × 7000 = 350 м³.
- V РЧВ ≥ 1950 м³ → принимаем 2 РЧВ × 1000 м³ или 1 × 2000 м³.

### 6.8 ВНС блочно-модульного исполнения

В современной практике ВНС часто поставляются в блочно-модульном исполнении (БМ-ВНС):
- Заводская готовность 95 %.
- Габариты 6×3 м, 9×3 м, 12×3 м.
- Утеплённый корпус (сэндвич-панели).
- Климатика (отопление + вентиляция).
- Внутри: коллектор, насосы, гидроаккумулятор, ЩУ.

Производители: ИСТРАТЕХ (Москва), Чистый-Путь (Краснодар), Велмет (СПб), КИТ (Подмосковье), Промбэйс (Самара).

## 7. Скважинные водозаборы

### 7.1 Расчёт расхода скважины (формула Дюпюи)

Для напорной (артезианской) скважины с полным фильтром:
```
Q = (2 × π × k × m × S) / ln(R/r)        [м³/с]
```

Для безнапорной (грунтовой) скважины:
```
Q = (π × k × (H² - h²)) / ln(R/r)        [м³/с]
```

Где:
- k — коэффициент фильтрации водоносного пласта, м/с (см. табл. ниже).
- m — мощность напорного пласта, м.
- H — мощность безнапорного пласта (от подошвы до уровня грунтовых вод), м.
- h — мощность пласта с учётом понижения = H − S, м.
- S — понижение уровня в скважине, м.
- R — радиус депрессионной воронки, м (≈ 1.5–3.0 × √S × √(k × t/μ), где t — время откачки, μ — недостаток влагоёмкости).
- r — радиус скважины, м.

#### Коэффициент фильтрации k для пород

| Тип пород | k, м/сут | k, м/с |
|-----------|----------|--------|
| Глины плотные | 0.001-0.05 | 1.2e-8 - 6e-7 |
| Супеси | 0.1-0.5 | 1.2e-6 - 6e-6 |
| Пески мелкозернистые | 1-5 | 1.2e-5 - 6e-5 |
| Пески среднезернистые | 5-25 | 6e-5 - 3e-4 |
| Пески крупнозернистые | 25-75 | 3e-4 - 9e-4 |
| Гравий | 75-250 | 9e-4 - 3e-3 |
| Известняки трещиноватые | 50-500 | 6e-4 - 6e-3 |
| Известняки массивные | 0.1-10 | 1.2e-6 - 1.2e-4 |

### 7.2 Подбор скважинного насоса

Стандартные модели:
- **Pedrollo 4SR** — 4″, 1-15 кВт, Q 1-25 м³/ч, H до 250 м.
- **Pedrollo 6SR** — 6″, 4-37 кВт, Q 10-90 м³/ч.
- **Grundfos SP** — 4-12″, серия лидер на рынке. SP1A-SP90. Q 1-380 м³/ч, H до 850 м.
- **Wilo TWU** — 4″, 1.1-15 кВт, Q 1-30 м³/ч.
- **Wilo TWI** — 6″, 4-30 кВт, Q 5-100 м³/ч.
- **ЭЦВ** (российские) — 4-10″, серия СССР, ныне Климов и др., от 5 до 200 м³/ч.

Алгоритм:
1. Расход Q расч = Q max.сут / 16 ч (16 ч работы в сутки) — или Q max.час с запасом 20 %.
2. Напор H расч = H статический + H понижение (расчётное) + H трубопровод + H остаточный.
3. Тип скважины (4″ / 6″ / 8″ / 10″) — по диаметру обсадной трубы.
4. Подбор по графикам Q-H конкретного производителя.
5. Глубина установки = H статический − 5 м (минимум 5 м под динамическим уровнем).

### 7.3 Динамический уровень

Статический уровень — уровень воды в скважине в покое (без откачки).

Динамический уровень — уровень при работающем насосе с заданной производительностью.

Понижение S = h дин − h стат.

Допустимое понижение S доп ≤ 0.7 × m напорного пласта (или 0.5 × H безнапорного).

### 7.4 Глубина установки насоса

Согласно ВНТП 2-91:
- Минимум 5 м ниже динамического уровня (запас от потери всасывания при колебаниях УГВ).
- Минимум 1 м над фильтром скважины (избежать всасывания песка).
- При сезонных колебаниях УГВ ≥ 3 м — глубина учитывает максимально возможное опускание.

### 7.5 Зоны санитарной охраны скважин (СанПиН 2.1.4.1110-02)

#### 1-й пояс (зона строгого режима)

Радиус 30 м (для надёжно защищённых артезианских пластов) или 50 м (для незащищённых грунтовых).

В пределах 1-го пояса:
- Запрет на любую хозяйственную деятельность.
- Только работы по эксплуатации скважины.
- Ограждение глухим забором, охрана.

#### 2-й пояс (зона ограничений по микробиологии)

Радиус определяется временем дохода микроорганизмов до скважины (Tмикр):
- Для надёжно защищённых = 100 сут.
- Для недостаточно защищённых = 200 сут.
- Для незащищённых = 400 сут.

```
R 2 = √((Q × Tмикр) / (π × n × m))
```

Где n — пористость, m — мощность пласта.

В пределах 2-го пояса:
- Запрет на полигоны ТКО, кладбища, скотомогильники.
- Запрет на склады удобрений, ГСМ.
- Ограничено внесение удобрений (только разрешённые).

#### 3-й пояс (зона ограничений по химии)

Радиус по химическому Tхим — обычно 25 лет (минимальная стойкость загрязнителей).

```
R 3 = √((Q × Tхим) / (π × n × m))
```

В пределах 3-го пояса:
- Контроль за нефтебазами, химзаводами.
- Запрет на новые предприятия 1-2 класса опасности.

#### Для поверхностных источников

ЗСО для рек:
- 1-й пояс — 100-200 м вверх по течению, 100 м вниз, 100 м вглубь от берега.
- 2-й пояс — 5-10 км вверх (по времени Tмикр).
- 3-й пояс — водосборный бассейн.

## 9. Подкачка для высотных зданий

### 9.1 Зонирование при H > 50 м (СП 30 §7.10)

Согласно СП 30 §7.10:
- Pmax = 0.45 МПа (45 м водяного столба) на нижнем этаже зоны.
- Если высота здания > 50 м (16-17 этажей и более) — обязательное зонирование.

Зоны:
- Зона I — 1-15/16 этаж (магистраль из городской сети).
- Зона II — 17-30/31 этаж (через ВНС подкачки в подвал → отдельный стояк).
- Зона III — 31-50 этаж (через ВНС подкачки на тех. этаже 30 этажа → стояк).
- И т. д. через каждые 50 м.

Для каждой зоны — отдельная сеть стояков, отдельный счётчик зональный, отдельный пожарный В2.

### 9.2 Гидробак (гидроаккумулятор) vs повысительная ВНС vs VFD-станция

#### Гидробак (мембранный гидроаккумулятор)

Принцип: бак с мембраной, сжатый воздух с одной стороны, вода с другой. Включается / выключается насос по уставке.

Применение:
- Малые объекты (ИЖС, дачные посёлки).
- Объём 24-1000 л.
- Цена 5-50 тыс. ₽.

Минусы: ступенчатая работа (включение / выключение каждые 1-5 мин); большие гидроудары.

#### Повысительная насосная ВНС с двумя насосами

Принцип: 2 одинаковых насоса работают по очереди (1 на этой неделе, 2 на следующей). Включаются по уставке давления.

Применение:
- Средние объекты (50-200 кв., административные здания).
- Q расч 5-50 м³/ч.
- Цена 200-1500 тыс. ₽.

Минусы: ступенчатость, больше всё ещё гидроудар.

#### VFD-станция (с частотным регулированием)

Принцип: 1-3 насоса на VFD (частотном преобразователе). Скорость регулируется так, чтобы давление в магистрали было постоянным.

Применение:
- Многоквартирные дома, бизнес-центры, гостиницы.
- Q расч 5-200 м³/ч.
- Цена 350-3500 тыс. ₽ (зависит от Q, числа насосов, бренда VFD).

Плюсы: плавная регулировка, нет гидроударов, экономия 20-30 % электроэнергии (особенно в часы малой нагрузки).

Готовые серии:
- Grundfos Hydro MPC.
- Wilo SiBoost Smart.
- KSB BoosterPump.
- DAB Pumps DEC, GENYO.
- ИСТРАТЕХ HMV.
- Velmet VST.

### 9.3 Жокей-насос для поддержания давления

Для систем В2 и ВНС магазинного склада:
- Жокей-насос — небольшой (Q = 1-3 м³/ч) с высоким напором.
- Поддерживает давление в магистрали круглосуточно при отсутствии расхода.
- Включается главный насос только когда давление падает ниже уставки + появилась утечка / открыт пож. кран.

### 9.4 Расчёт подкачки

Общая формула:
```
H подкачка = H зоны + Δh трубопровод + H остат – H город
```

Где:
- H зоны — максимальная отметка зоны (этаж × 3 м).
- Δh трубопровод — потери в магистрали и стояке.
- H остат — остаточный напор на самом верхнем этаже зоны (≥ 6 м для бытовых, ≥ 10 м для В2).
- H город — давление городской сети (обычно 30-40 м, узнать у Водоканала).

Пример: 25-этажный дом, зона II 16-25 этажи, ввод в подвал на –3 м, городское давление 30 м:
- Уровень 16 этажа = 16 × 3 + 0 = 48 м.
- Уровень 25 этажа = 25 × 3 = 75 м.
- Δh = 5 м (магистраль) + 7 м (стояк 25 этажей × 3 м × i 0.05 = 3.75) ≈ 10 м.
- H остат = 6 м.
- H подкачка = 75 + 10 + 6 – 30 = 61 м.

Принимаем насос с H ном ≥ 70 м (запас 15 %) и Q расч по формуле α-метода для зоны II (например, 5 л/с = 18 м³/ч).

## 10. Подготовка воды

### 10.1 Обеззараживание

#### УФ-облучение

Принцип: УФ-лампы 254 нм разрушают ДНК микроорганизмов.

Дозировка: 30-40 мДж/см² (для пит. воды), 200-400 мДж/см² (для оборотной).

Особенности:
- Не оставляет послед-эффекта (нужна вторичная защита остаточным хлором).
- Не меняет химию воды.
- Эффективно для бактерий, вирусов, частично для цист (Giardia, Cryptosporidium).
- Производители: ЛИТ (Москва), Wedeco (Xylem), Trojan UV.

#### Гипохлорит натрия (NaClO)

Принцип: распад до HOCl и ClO−, которые окисляют органику и бактерии.

Доза: 1.5-3.0 мг/л (по активному Cl). Остаточный после контакта 30-60 мин = 0.3-0.5 мг/л.

Применение:
- Электролизные станции на месте (Хлордозаторы, ЛИДЕР, Эколайн).
- Готовый раствор 12-15 % (бочки 1 м³).

Минусы: образование хлорорганики (тригалометаны).

#### Диоксид хлора (ClO2)

Принцип: окислитель сильнее хлора, не образует хлорорганики.

Доза: 0.2-0.5 мг/л.

Применение: Lonza CDX, Грюндфос Selcoperm.

Цена: дороже NaClO в 2-3 раза, но и эффективнее, и безопаснее.

#### Озонирование (O3)

Принцип: озон распадается до O2 и атомарного кислорода — окисляет всё.

Доза: 1-3 мг/л.

Применение: крупные ВНС (Москва — Рублёвская, Северная), бассейны.

Минусы: дорого (генератор + вторичная защита по NaClO); озон опасен для персонала.

### 10.2 Умягчение

Жёсткость воды — общая (Ca + Mg) в мг-экв/л.
- Мягкая — ≤ 2.
- Средне-жёсткая — 2-7.
- Жёсткая — 7-10.
- Очень жёсткая — > 10.

Методы умягчения:
- **Ионный обмен (катионит)** — натрий-катионирование. Состав: фильтр + катионит (Purolite C-100E, Lewatit S 1467) + регенерация раствором NaCl. Останавливается при насыщении (10-20 мг-экв на 1 м³ катионита).
- **Обратный осмос (RO)** — мембрана; убирает всё, не только Ca/Mg.
- **Электродеионизация** — для ультрачистой воды.
- **Полифосфатные дозаторы** — для предотвращения отложений в технике (без удаления солей).

### 10.3 Обезжелезивание

Если железа > 0.3 мг/л (МПК) — нужно убрать.

Методы:
- **Аэрация + фильтр**: воздух окисляет Fe²⁺ до Fe³⁺ (нерастворимый), фильтр удерживает осадок. Применяется для Fe ≤ 5 мг/л.
- **Каталитический фильтр** (BIRM, Pyrolox, MTM): катализирует окисление.
- **Окислитель + фильтр** (NaClO, KMnO4 + фильтр): для Fe > 5 мг/л или сложных вод (с Mn, H2S).

### 10.4 Системы глубокой очистки

#### Обратный осмос (RO)

Применение: производство дист. воды, питьевая в плохих регионах, фармацевтика.

Параметры:
- Мембрана: полиамидный композит (Toray, FilmTec, Hydranautics).
- Давление: 10-15 атм для бытового, 50-70 атм для морской.
- Степень опреснения: 95-99 %.
- Расход: 1 л пермеата на 3-5 л концентрата (для бытового), 1:2 (промышл.).

#### Нанофильтрация (NF)

Промежуточная между RO и UF.
- Удаляет двухвалентные ионы (Ca²⁺, Mg²⁺, SO4²⁻), пропускает одновалентные.
- Применение: умягчение природной воды.

#### Ультрафильтрация (UF)

Удаляет частицы > 10 нм (бактерии, вирусы).
- Не удаляет растворённые соли.
- Применение: предочистка перед RO; обеззараживание малых объёмов.

### 10.5 Cyclic rinse / самопромывка

Большинство современных фильтров (умягчители, обезжелезователи) имеют автоматическую регенерацию:
- Контролируется блоком управления (Clack WS1/WS3, Pentair Logix, Aquacom).
- Срабатывает по объёму обработанной воды или по таймеру.
- Цикл: обратная промывка (10-15 мин) → регенерация (60-120 мин) → медленная промывка (30-60 мин).

## 11. Расчётные примеры

### 11.1 ИЖС: 4 человека, скважина

**Исходные данные:**
- Семья 4 человека.
- Дом с водопроводом, ваннами, центральным ГВС от газового котла → норма 250 л/чел·сут.
- Скважина диаметром 4″, глубина 60 м, статический уровень 15 м, дебит при S = 5 м: Q доп = 1.5 м³/ч.
- Резервуар (бак) 200 л в техпомещении.

**Расчёт:**
- Q сут.ср = 4 × 250 / 1000 = 1.0 м³/сут.
- Q max.сут = 1.0 × 1.3 = 1.3 м³/сут (К сут.max = 1.3 для ИЖС).
- Q max.час = 1.3 / 16 × 2.5 = 0.20 м³/ч (16 ч работы насоса в сутки, K час 2.5).
- Q max.сек по α-методу: 6 приборов на дом, q с0 = 0.3 л/с. P = 10 × 4 / (0.3 × 6 × 3600) = 0.00617. P×N = 0.037. α ≈ 0.27. q с = 5 × 0.3 × 0.27 = 0.405 л/с ≈ 0.4 л/с = 1.5 м³/ч.

**Подбор:**
- Скважинный насос: Pedrollo 4SR 4/9 (Q ном = 4 м³/ч, H ном = 70 м, 1.1 кВт). Запас по дебиту 1.5 м³/ч ≥ Q max.час 0.2 м³/ч с лихвой.
- Глубина установки: динамический уровень при S = 5 м = 20 м. Установка на 25 м (5 м под динамическим).
- Гидробак: 100-200 л Reflex DE.
- Реле давления: Grundfos PCK или Italtechnica 1.5-3.0 атм.

**Оценка:**
- Бюджет: насос ~ 25 тыс. ₽, гидробак ~ 8 тыс., автоматика 5 тыс., трубы 10 тыс. = 50 тыс. ₽.
- Энергопотребление: 1.1 кВт × 1 ч × 30 = 33 кВт·ч/мес.

### 11.2 50-квартирный дом, ВНС подкачки

**Исходные данные:**
- 50 квартир, 3 чел/кв = 150 жителей.
- Норма 250 л/чел·сут (центральное ГВС от ИТП).
- 12 этажей, высота 36 м.
- Городское давление на вводе 30 м.

**Расчёт расхода:**
- Q сут.ср = 150 × 250 / 1000 = 37.5 м³/сут.
- Q max.сут = 37.5 × 1.2 = 45 м³/сут.
- Q max.час = 45 / 24 × 2.5 = 4.7 м³/ч (для города 5-50 тыс. на 50 квартир, K час 2.5).
- Q max.сек α-методом: N = 6 × 50 = 300 приборов; P = 10 × 150 / (0.3 × 300 × 3600) = 0.0046; PN = 1.39; α = 1.21; q с = 5 × 0.3 × 1.21 = 1.815 л/с ≈ 6.5 м³/ч.

**Расчёт напора:**
- Уровень последнего этажа 36 м.
- Δh магистраль 5 м, стояк 4 м.
- H остат 6 м.
- H подкачка = 36 + 9 + 6 – 30 = 21 м.

**Подбор:**
- ВНС с 2 насосами SCM-30/2 ИСТРАТЕХ (Q ном = 30 м³/ч, H ном = 30 м), один рабочий + один резервный.
- VFD контроль (для экономии).
- Гидроаккумулятор 200 л.

**Оценка:**
- Бюджет ВНС в сборе: 380-450 тыс. ₽.

### 11.3 Гостиница 100 номеров (4 звезды)

**Исходные данные:**
- 100 номеров × 1.5 чел = 150 гостей в среднем.
- Норма для гостиницы 4* = 300 л/чел·сут (q гор = 130).
- Бассейн 25×12 м (300 м³).
- Прачечная 500 кг белья/сут.
- Пожарный В2: внутренний 2×2.5 = 5 л/с; внешний 25 л/с (гостиница до 25 тыс. жителей).

**Расход бытовой:**
- Q сут.ср = 150 × 300 / 1000 = 45 м³/сут.
- Q max.сут = 45 × 1.3 = 58.5 м³/сут.
- Q max.час = 58.5 / 24 × 2.5 = 6.1 м³/ч.
- Q max.сек α-методом: ≈ 8-9 л/с.

**Расход бассейна:**
- Заполнение 1 раз в 6 мес = 300 / 180 ≈ 1.7 м³/сут.
- Подпитка 5 % объёма/сут = 15 м³/сут.
- Циркуляция (фильтрация) 2 объёма/сут = 600 м³/сут (в режиме оборота).

**Расход прачечной:**
- 500 × 75 / 1000 = 37.5 м³/сут.

**Итого:**
- Q max.сут общий = 58.5 + 15 + 37.5 = 111 м³/сут.

**ВНС подбор:**
- Q max.сек = 8 + 2 (бассейн) + 1.5 (прачечная) = 11.5 л/с.
- Если высота гостиницы > 50 м — нужно зонирование.
- Магистральная подкачка: Grundfos Hydro MPC 3CR15-3 (3 насоса × 15 м³/ч × 25 м, VFD). Цена ~ 850 тыс. ₽.

**Пожарка:**
- Внутренний пожарный — отдельная ВНС-пожарная: 2 насоса × 5 л/с × 30 м (Wilo Helix), цена 320 тыс.
- Подключение к городскому пожгидранту.

### 11.4 Промпредприятие 1000 человек + технология

**Исходные данные:**
- 1000 человек на смену (3 смены) → 3000 чел/сут (расчёт по 1 смене).
- Норма горячий цех = 45 л/чел·смену.
- Технологический расход = 50 м³/сут (по технологии).
- Полив территории 5000 м² × 3 = 15 м³/сут.

**Расход бытовой:**
- Q сут = 1000 × 45 = 45 м³/сут (на 1 смену) × 3 = 135 м³/сут.

**Душевые:**
- 50 % рабочих в горячем цехе = 500 чел.
- Душ. сетки: 1 на 5 чел = 100 шт. Расход в смене: 500 л/сетку×ч × 0.75 ч = 375 л/сетку = 37.5 м³/смену = 112 м³/сут.

**Итого Q max.сут = 135 + 112 + 50 + 15 = 312 м³/сут.**

**ВНС:**
- Q max.час пик в начале/конце смены (душевые) = 70-90 м³/ч.
- 3-4 насоса CR45-3 параллельно с VFD.
- Цена ~ 1.8-2.5 млн ₽.

**Пожарка:**
- Расход 35 л/с (50-100 тыс. жителей условно, для пром).
- Резервуар на 3 ч × 35 л/с = 380 м³.
- Пожарная ВНС с 2 насосами 35 л/с × 50 м.

## 12. Расчёт горячей воды (СП 30 §8)

### 12.1 Q гв (м³/сут)

```
Q гв.ср = N × q гор / 1000        [м³/сут]
```

Норма q гор (л/чел·сут):
- Жилые с центральным ГВС: 105-120.
- Гостиницы 3*: 100-110.
- Гостиницы 4-5*: 130.
- Больницы: 100-180.
- Офисы: 7-10.

### 12.2 Q гв.час и Q гв.сек

```
Q гв.час.max = N × q гч.max / 1000        [м³/ч]
Q гв.сек = q с0.гор × α гор             [л/с]
```

q с0.гор для смесителя ванны = 0.2 л/с (α-метод по тем же правилам, но для ГВС-приборов).

### 12.3 Бойлер косвенного нагрева

Применяется в системах с теплообменом от теплосети или газового котла:
- Бойлер ёмкостной (50-3000 л).
- Часовой пик расходуется из ёмкости, котёл догревает между пиками.

#### Расчёт ёмкости

```
V бойлера = (Q гв.час.max – Q котла.макс.час) × t пик
```

Где:
- Q котла.макс.час — максимальный часовой расход котла (по паспорту).
- t пик — длительность пика (1.5-2.5 ч в жилом доме).

### 12.4 Мощность котла для ГВС

```
P ГВС = Q гв.ч × ρ × cp × ΔT / 3600       [Вт]
ΔT = 60 - 5 = 55 °C
ρ = 1000 кг/м³
cp = 4187 Дж/(кг·К)
```

Пример: 50-кв. дом, 150 чел, q гор = 105 л/чел·сут, q ч.гор = 7 л/ч:

```
Q гв.ч = 0.005 × 7 × α(1.39) = 0.005 × 7 × 1.21 = 0.0424 м³/с = 152 л/ч
```

Подождите, формула верная для секундного. Часовой через α ч, который ниже.

Используем готовую формулу из СП 30, формула 5.10:
```
Q гв.ч = 0.005 × q гч.0 × α ч       [м³/ч]
α ч от P ч × N
P ч = 3600 × P × q с0 / q ч.0
```

Для нашего случая P = 0.0046, q с0 = 0.2 (горячий смеситель), q ч.0 = 200 л/ч:
```
P ч = 3600 × 0.0046 × 0.2 / 200 = 0.0166
P ч × N = 0.0166 × 300 = 4.97
α ч ≈ 2.61
Q гв.ч = 0.005 × 200 × 2.61 = 2.61 м³/ч
```

Мощность котла:
```
P = 2.61 × 1000 × 4187 × 55 / 3600 = 167 кВт
```

С запасом 1.2 → 200 кВт котла или 2 котла по 100 кВт.

### 12.5 Циркуляция ГВС (без неё застой и легионеллёз)

Согласно СП 30 §8.3:
- Если расстояние от ИТП до самой удалённой точки разбора > 20 м (или объёма воды в Т3 > 3 л) — обязательна циркуляция Т3/Т4.
- Без циркуляции — вода стынет, образуются колонии Legionella pneumophila, возникает риск пневмонии.

#### Расчёт расхода циркуляции

```
Q цирк = (Σ Q потерь × 1000) / (cp × ρ × ΔT цирк)        [м³/ч]
ΔT цирк = 5-10 °C (между Т3 и Т4)
Σ Q потерь — сумма теплопотерь стояков и магистралей в Вт
```

Стандартная норма:
- Q цирк ≈ 10-30 % от Q ГВС часового расхода.
- Циркуляционный насос (cirpump) — Wilo Star Z, Grundfos UPS 25-60, ИСТРАТЕХ HZ 25.

### 12.6 Температура подачи 60 °C, обратки 50 °C

Согласно СанПиН 2.1.3684-21:
- Температура ГВС в точке разбора ≥ 60 °C (защита от Legionella).
- Не ≥ 75 °C (опасность ожогов).
- Допускается до 50 °C только в детских и лечебных учреждениях с термосмесителями.

В стояках:
- Подача Т3 = 60-65 °C.
- Возврат Т4 = 50-55 °C.

### 12.7 Защита от легионеллёза

- Регулярная (1 раз в неделю) термическая дезинфекция: подъём Т до 70 °C на 30 мин во всех точках сети.
- Контроль наличия стоячих участков (тупиковые отводы > 0.5 м удалить).
- Слив воды в неэксплуатируемых линиях.
- Фильтры на смесителях (Pall, 3M).

## 13. Полив, автомойка, бассейн

### 13.1 Расход на полив газонов

Норма (СП 30 прил. А):
- Газоны и зелёные насаждения травяные — 3 л/м²·сут.
- Цветники — 6 л/м²·сут.
- Деревья и кустарники — 1 л/м²·сут.
- Огороды — 4-6 л/м²·сут (южные регионы).

Сезон полива:
- В средней полосе: с мая по сентябрь (5 мес).
- На юге: с апреля по октябрь (7 мес).
- Оросительные системы — автоматические таймеры.

Время полива:
- Утром (с 6 до 9) — оптимально.
- Вечером (с 18 до 21).
- Не в полдень (испарение, ожог листьев).

#### Подбор насоса для полива

```
Q расч = (S полива × q полива) / (t × 3600)        [л/с]
H расч = H статич + Δh трубопровод + H ост (на дождевателе 25-35 м)
```

Пример: 1 га (10000 м²) газона, q = 3 л/м²·сут, t = 4 ч полива в сутки:
```
Q = 10000 × 3 / (4 × 3600) = 2.08 л/с = 7.5 м³/ч
H = 30 м (дождеватель) + 5 м (потери) + 5 м (геом) = 40 м
```

Подходит Pedrollo 2CP 25/130 (Q = 9 м³/ч, H = 40 м, 1.5 кВт).

### 13.2 Автомойка

Без оборотного водоснабжения: 200-500 л/авто.
- Бесконтактная мойка: 500 л/авто.
- Контактная (с губкой): 300-400 л/авто.
- Самообслуживание: 200-300 л/авто.

С оборотным водоснабжением (80 % воды возвращается): 50-100 л/авто.

Состав системы оборотной автомойки:
- Песколовка / нефтеуловитель (отбор крупных фракций).
- Тонкая очистка (флотатор, биофильтр).
- Резервуар чистой воды.
- Дезинфекция (NaClO).
- Циркуляционный насос.

#### Расчёт ВНС для автомойки

Пример: автомойка на 4 поста, 60 машин/сут, оборот 80 %:
- Q расход свежей воды = 60 × 100 = 6 м³/сут.
- Q цирк = 60 × 400 = 24 м³/сут.
- Q max.час пик = 4 поста × 1 авто × 400 л / 0.5 ч = 800 л / 0.5 ч = 1600 л/ч = 1.6 м³/ч пиковый.

### 13.3 Бассейны

#### Расчёт наполнения

```
V бассейна = L × W × H ср    [м³]
```

Время наполнения 4-12 ч (зависит от Q ввода).

#### Циркуляция

Норма: объём бассейна должен пройти через систему фильтрации **не реже 6 раз/сут** (4 ч полный оборот) или 4 раза/сут (для частных).

```
Q цирк = V бассейна × n / 24       [м³/ч]
n = 4-6 для общественных, 2-3 для частных
```

Пример: 25×12×1.5 м = 450 м³, n = 6:
```
Q цирк = 450 × 6 / 24 = 112.5 м³/ч ≈ 30 л/с
```

#### Подпитка

Норма: 5 % объёма/сут (испарение, унос воды на купальщика, продувка).

```
Q подп = 0.05 × V       [м³/сут]
```

Пример (тот же): 0.05 × 450 = 22.5 м³/сут.

#### Производители оборудования

- **Hayward** (США) — премиум фильтрация.
- **Pentair** — премиум.
- **Astralpool** — Испания, средний+.
- **Emaux** — Китай, бюджет.
- **Российские**: Bestway, Oase, Karcher.

Состав:
- Циркуляционный насос (Pedrollo PVm, Wilo Stratos).
- Фильтр песочный (диатомитовый, картриджный).
- Хлоратор / УФ / соляной хлоринатор.
- Подогреватель (теплообменник от котельной или ТН).

### 13.4 Декоративные фонтаны

Подпитка 5-10 % объёма/сут (испарение).

Циркуляция: насос с производительностью полного объёма за 2-4 ч.

Пример: фонтан 100 м³:
- Подпитка 5-10 м³/сут.
- Циркуляция Q = 100 / 3 ≈ 33 м³/ч ≈ 9 л/с (Grundfos CR 32-2 за ~ 250 тыс).

## 15. Глоссарий

**А-Б**

- **АИВ** — автоматический индикатор воды (расходомер с записью).
- **Артезианская скважина** — скважина, проникающая в напорный водоносный пласт; вода поднимается выше водоупорной кровли пласта.
- **АУП** — автоматическая установка пожаротушения (спринклеры, дренчеры).
- **Бак-аккумулятор** — ёмкость для аккумулирования воды (чаще ГВС) под давлением.
- **Балансовый учёт** — учёт расхода воды на вводе и стоков на выходе для контроля потерь.
- **Биообрастание** — образование колоний бактерий и водорослей на стенках труб и резервуаров.
- **Бойлер** — ёмкостный или проточный нагреватель воды.

**В**

- **В1** — хозяйственно-питьевой холодный водопровод (по СП 30 / СНиП 2.04.01).
- **В2** — пожарный водопровод.
- **В3** — производственный водопровод.
- **Вантуз** — клапан для впуска / выпуска воздуха в верхних точках сети.
- **ВДПО** — Всероссийское добровольное пожарное общество.
- **ВДУ** — водопроводно-дренажный узел.
- **ВЗС** — водозаборное сооружение (скважина, водоприёмник, родниковый каптаж).
- **ВНС** — водопроводная насосная станция.
- **Водомерный узел** — узел учёта расхода воды на вводе в здание.
- **Водопотребление безвозвратное** — расход на полив, испарение, технологию (не возвращается в сеть).
- **Водопотребление оборотное** — циркуляция (бассейны, охлаждение).
- **ВПК** — внутренний пожарный кран.
- **ВРУ** — водомерно-распределительное устройство.
- **Высотное здание** — здание с этажностью > 25 этажей или высотой > 75 м.

**Г**

- **Гидроаккумулятор** — мембранный бак с воздушной подушкой для аккумулирования давления.
- **Гидрант** — устройство для отбора воды в пожарных целях из наружной сети (ПГ-5).
- **Гидрозатвор** — защита от обратного движения газа из канализации.
- **Гидроудар** — резкое изменение давления в трубопроводе при быстром закрытии запора.
- **Гидрофор** — устаревшее название гидроаккумулятора с насосом и автоматикой.
- **Глубина промерзания** — нормативная глубина (СП 131), на которую промерзает грунт в данной местности.
- **ГВС** — горячее водоснабжение.

**Д**

- **Дебит скважины** — производительность скважины при заданном понижении уровня (л/с или м³/ч).
- **Депрессионная воронка** — снижение уровня грунтовых вод вокруг работающей скважины.
- **Динамический уровень** — уровень воды в скважине при работающем насосе.
- **Диаметр условный (DN)** — номинальный внутренний диаметр трубы.
- **Дренчерная установка** — пожаротушение в режиме «откроется по сигналу».

**Е-З**

- **Ёмкостный теплообменник** — теплообменник с буферной ёмкостью для ГВС.
- **Ж/б — железобетон**.
- **Жокей-насос** — небольшой насос для поддержания давления в магистрали В2 (1-3 м³/ч × 30-60 м).
- **Зона санитарной охраны (ЗСО)** — территория и участки 1-го/2-го/3-го пояса вокруг источника.

**И-К**

- **Инфильтрация** — просачивание воды через грунт.
- **Кавитация** — разрыв сплошности потока воды на входе в насос при низком NPSH.
- **К1** — бытовая канализация.
- **К2** — производственная канализация.
- **К3** — дождевая (ливневая) канализация.
- **Колодец** — подземная камера для размещения арматуры или служебных целей.
- **Кольцевая сеть** — сеть с замкнутыми магистралями (надёжная).
- **КИП** — контрольно-измерительные приборы.
- **КПД** — коэффициент полезного действия.

**Л-М**

- **ЛОС** — локальное очистное сооружение (для канализации).
- **Магистраль** — основной трубопровод сети водоснабжения.
- **Манометр** — прибор для измерения давления.
- **МПК** — максимально допустимая концентрация (например, для химических веществ в питьевой воде).

**Н**

- **Напор** — энергия воды на 1 кг массы, м водяного столба.
- **Невозвратный (обратный) клапан** — клапан, пропускающий поток только в одну сторону.
- **Норма расхода** — количество воды на 1 расчётную единицу (СП 30 прил. А).
- **NPSH (Net Positive Suction Head)** — кавитационный запас на всасывании насоса (м).

**О**

- **Обвязка насоса** — комплект труб, арматуры, КИП, соединяющий насос с магистралью.
- **Оборотное водоснабжение** — циркуляция (бассейн, охлаждение, мойка).
- **Объём резервуара** — V = V рег + V пож + V авар + V соб.
- **Однотрубная система** — без циркуляции (для ГВС не рекомендуется при > 20 м длины).

**П**

- **ПВД** — пожарно-водозаборный узел.
- **Пиезометр** — устройство (трубка), измеряющее уровень воды (давление) в скважине или сети.
- **Подкачка** — повышение давления для отдалённых частей сети или верхних этажей.
- **Подъём (I, II, III)** — насосная станция от водоисточника, от РЧВ, повысительная.
- **Промерзание** — глубина, на которую промерзает грунт зимой (СП 131).
- **ПЭ100** — полиэтилен низкого давления, марка для трубопроводов под давлением.

**Р**

- **РЧВ** — резервуар чистой воды.
- **Распределительная сеть** — сеть, доставляющая воду от ВНС к потребителям.
- **Расчётный расход** — q сред / q max.сут / q max.час / q max.сек, в зависимости от целей расчёта.
- **Реле давления** — переключатель насоса по уставкам Pmin / Pmax.

**С**

- **Самотёчная сеть** — сеть, работающая под действием силы тяжести (без насосов).
- **СВН** — совмещённый водопровод низкого давления (бытовой + пожарный совмещённый).
- **СКВ — скважина с водоупорным забоем**.
- **Скоростной коэффициент** — для расчёта потерь в местных сопротивлениях.
- **СПК** — система противопожарного контроля.
- **Спринклер** — оросительная головка с термозамком.
- **Стояк** — вертикальный трубопровод между этажами.

**Т**

- **Т3** — подающая магистраль ГВС (60 °C).
- **Т4** — циркуляционная (обратная) магистраль ГВС (50 °C).
- **Турбидиметр** — прибор для измерения мутности воды.
- **Тупиковая сеть** — линейная сеть без замыкания (для малых объектов).

**У-Ф**

- **УФ-облучение** — обеззараживание воды ультрафиолетом 254 нм.
- **УГВ** — уровень грунтовых вод.
- **Фильтр механический** — для отделения твёрдых частиц (грязевик).
- **Фильтр угольный** — для удаления хлора и органики.

**Х-Ч**

- **ХВС** — холодное водоснабжение.
- **Хлоратор** — устройство для дозирования NaClO в магистраль.
- **ЦНС** — центробежный насос секционный (российская серия).
- **Циркуляция** — постоянное движение воды в магистрали (для ГВС, бассейна).

**Ш-Я**

- **Шевелёв** — автор таблиц гидравлических расчётов 1976 г.
- **Шуруповод** — узел соединения трубы с фитингом.
- **Эмаль** — защитное покрытие резервуара (стеклоэмаль ЭП-918).
- **Энергоэффективный класс** — IE2 / IE3 / IE4 / IE5 для двигателей (CEMEP-CEN).
- **Эпюра потерь** — графическое представление потерь давления вдоль магистрали.
- **ЯР** — ядро регулирования (резервный объём в РЧВ).

### D. Базовые формулы — шпаргалка

```
Q сут.ср = N × q общ / 1000               [м³/сут]
Q max.сут = K сут × Q сут.ср             [м³/сут]
Q max.час = (Q max.сут / 24) × K час     [м³/ч]
Q max.сек = q с0 × α × 5                 [л/с]
P = q ч × U / (q с0 × N × 3600)
P × N → α по табл. Б СП 30

Δh = λ × (L/d) × (v² / (2g))             [м]

H насоса = H геом + Σ Δh + H ост         [м]
P насоса = (Q × H × ρ × g) / (3600 × η)  [Вт]

V РЧВ = V рег + V пож + V авар + V соб   [м³]
V пож = 3 × 3600 × q пож / 1000          [м³] (для жилых)

T мс = 100-400 сут (по защищённости пласта)
R 2 пояса ЗСО = √(Q × T / (π × n × m))   [м]
```
