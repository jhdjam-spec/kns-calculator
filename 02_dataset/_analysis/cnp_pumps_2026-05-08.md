## 8. Пробелы и followup

- **Точные кривые Q-H** не у всех моделей — пока вписываем `Q_BEP/H_BEP` из обозначения (точка номинального режима).
- **eta_BEP** редко указан в каталогах дилеров — берём 30-50% для WQ, 50-65% для CDM.
- **NPSHr** отсутствует — применять консервативный 4-6 м для WQ, 2-3 м для CDM (стандарт серий).
- **Free-passage WQ**: по типу обозначения. WQ без суффикса = vortex (50-80 мм для 50WQ/65WQ, 80-110 мм для 100WQ). WQ-W = cutter (мелкий проход).
- **NES, NSC, BRM, AIKON SDS, SJ скважинные** — в публичном прайсе у atpump/baymart не нашлось — требуют запроса у baumgroup.ru или termopartner.ru. Отложить на следующую сессию.
- **NSC (двойного всасывания)** — стратегически важная для крупных тендеров (КНС-1, КНС-2 водоканалов с Q≥500). Цены только по запросу. Целесообразно сделать запрос baumgroup на типовые НСС 200/40, 200/100, 250/65.
