# Нормативные требования к насосному оборудованию для КНС/НС/ЛОС в РФ (2026)

**Дата:** 2026-05-08
**Применимость:** проектирование и закупка насосов для канализационных насосных станций (КНС), насосных станций водоснабжения (НС), станций повышения давления (СПД/ВНС), пожарных насосных станций (ПНС/НС-ПТ), очистных сооружений и локальных очистных систем (ЛОС).

## 2. Ключевые количественные требования по СП 32.13330.2018 (КНС)

### 2.1. Подбор насосов (раздел 8.2)

> «Насосы, оборудование и трубопроводы следует выбирать в зависимости от расчётного притока и физико-химических свойств сточных вод или осадков, высоты подъёма, с учётом характеристик насосов и напорных трубопроводов» (п. 8.2.1).

**Расчётный приток:**
- определяется как `Q_расч = Q_сут_ср × K_сут_max × K_час_max`
- значения коэффициентов — по СП 31.13330.2021

**Расход для подбора:** «Расчётные расходы для сетей и сооружений при подаче сточных вод насосами следует принимать равными производительности насосных станций» (п. 5.1.7).

### 2.2. Резервирование (п. 8.2.10-8.2.13)

| Категория КНС | Кол-во рабочих + резерв | Условие |
|---|---|---|
| **I** (большая, населённый пункт >50 тыс. жит. или особо ответственная) | 2 рабочих + 1 резервный | обязательно |
| **II** (средняя 5-50 тыс. жит.) | 2 рабочих + 1 резервный | обязательно |
| **III** (малая <5 тыс. жит.) | допускается 1 рабочий + 1 на складе | при возможности замены за 2-6 часов |

> «Допускается не предусматривать установку резервных агрегатов при условии хранения их в помещении насосной станции и наличии возможности замены в течение 2-6 ч» (п. 8.2.13).

### 2.3. Подача (расход) и напор

- Для **бытовой канализации**: расходы согласно СП 31, K_общ_max = 1.5-3.5 в зависимости от средней суточной подачи.
- Для **производственной**: по технологическому регламенту предприятия.
- Для **дождевой/ливневой**: по СП 32 §6 (см. отдельный пакет реф. документации `reference_storm_calculator_research_2026.md`).

**Минимальный диаметр напорного трубопровода:**
- 100 мм — для расчётных расходов до 70 л/с
- 150 мм — для расходов 70-200 л/с
- 200 мм — для расходов >200 л/с

**Минимальная скорость в напорном трубопроводе** для предотвращения осаждения:
- 0.7 м/с — при поступлении бытовых стоков
- 0.9 м/с — при поступлении смешанных сточных вод
- 1.0 м/с — при наличии абразивных примесей

### 2.4. Допустимая частота включений

- При напорной работе с переменным разбором: **не более 6 включений/час** для двигателей >7.5 кВт без частотника
- С частотным регулированием: ограничение снимается

### 2.5. Требования к материалам

- **Чугун СЧ20** — стандарт для бытовых стоков
- **Нерж. сталь AISI 316 / 1.4408** — для агрессивных сред (рН <6, >9, фильтраты, хлориды)
- **Бронза** — для морских/солёных стоков (УГВ = уровень моря)

## 3. Ключевые количественные требования по СП 30.13330.2020 (СПД/ВНС внутренние)

### 3.1. Давление в водоразборной арматуре

- **Максимум** на наинижнем санитарном приборе:
  - **0.45 МПа** — для нового строительства
  - **0.6 МПа** — допускается для существующих зданий при реконструкции
- **Минимум** на верхнем приборе: **0.2 МПа** (или согласно паспорту прибора)

### 3.2. Зонирование

> «При зонировании систем водоснабжения подача воды в каждую зону должна осуществляться независимыми насосными установками» (п. 7.4.4).

### 3.3. Объединение вводов перед насосами

> «Вводы водопровода должны быть объединены перед насосами с задвижкой на соединительном трубопроводе для обеспечения подачи воды от любого ввода. При устройстве самостоятельных насосных установок на каждом вводе объединение вводов не требуется» (п. 7.4.7).

### 3.4. Резервирование

- Для зданий I категории по водообеспечению (больницы, противопожарные, метрополитен): 2 рабочих + 1 резервный, **с автоматическим вводом резерва (АВР)**
- Для зданий II категории: 1 рабочий + 1 резервный
- Для зданий III категории: 1 рабочий + 1 на складе

## 4. Ключевые количественные требования по СП 8.13130.2020 (наружное пожаротушение)

### 4.1. Категории надёжности насосных станций

> «Насосные станции, подающие воду непосредственно в противопожарные сети, относятся к зданиям I категории по электроснабжению. Для НС, обеспечивающих противопожарные сети, может быть допущена II категория, если объект имеет дополнительные источники противопожарной воды с достаточным запасом для установленной длительности тушения» (п. 4.2).

### 4.2. Запуск насоса

> «Для противопожарных трубопроводов высокого давления стационарные пожарные насосы должны быть оборудованы устройствами, обеспечивающими включение насосов не позднее чем через 5 минут после получения сигнала о пожаре» (п. 9.7).

### 4.3. Резерв пожарных насосов

- Минимум: **1 рабочий + 1 резервный** для всех ПНС
- Для I категории объектов (особо опасные): **2 рабочих + 1 резервный**

### 4.4. Качество воды

> «Качество воды, предназначенной для тушения пожара, должно соответствовать условиям эксплуатации пожарной техники и применяемым способам пожаротушения» (п. 4.5).

## 5. Ключевые количественные требования по СП 10.13130.2020 (внутреннее пожаротушение, ВПВ)

### 5.1. Электроснабжение

- Все пожарные насосные станции внутреннего пожаротушения отнесены к **I категории** по надёжности электроснабжения.
- Дизель-генератор как резерв ввода обязателен для зданий >50 м или >5000 посетителей.

### 5.2. Допустимые типы насосов для ВПВ

> «Пожарные насосы могут получать питание от вводных трубопроводов от наружных сетей водопровода или от пожарных резервуаров, и допускаются другие типы повысительных установок, если они обеспечивают заданные параметры внутреннего противопожарного водопровода и удовлетворяют нормам, такие как насосы хозяйственно-питьевого водопровода или насосы технической воды» (п. 4.3).

> «Пожарные насосные агрегаты могут включать в себя погружные насосные агрегаты» (п. 4.4).

Это означает, что **для ВПВ допустимы погружные насосы** (не только сухоустановочные) — важная норма, расширяющая выбор.

### 5.3. Время выхода на режим

- Стационарный пожарный насос — **не более 30 секунд** от подачи сигнала пуска до выхода на расчётный режим (для систем тушения пеной, спринклерных).

## 6. Применение требований при подборе насоса (чек-лист для калькулятора)

### 6.1. Обязательные параметры

| Параметр | Значение для проверки | Как извлечь |
|---|---|---|
| Q (расчётный) | `Q_расч = Q_сут_ср × K_сут_max × K_час_max` | по СП 31 + ТЗ |
| H (расчётный) | геометрический + потери в трубопроводе + остаточный напор | гидрорасчёт |
| Резервирование | min 1 рабочий + 1 резерв (по категории) | определить категорию по СП 32/30/8/10 |
| Сертификация ЕАС | обязательна (ТР ТС 010/2011) | из паспорта производителя |
| Электробезопасность | ТР ТС 004/2011 — для двигателей <1000 В | паспорт двигателя |
| ЭМС | ТР ТС 020/2011 — для частотников | паспорт |
| Ex (если объект EX) | ТР ТС 012/2011 + спец. сертификат | для нефтянки/химии |
| IP-класс | min IP68 для погружных | паспорт |

### 6.2. Желательные параметры

- **NPSHr** — обязательно проверить для horizontal и при глубине всасывания >3 м
- **КПД при BEP** — для оптимизации энергопотребления (требование энергоэффективности по 261-ФЗ)
- **Free passage (свободный проход)** — для submersible: min 50 мм для бытовых стоков, 65-80 мм для промышленных
- **Класс энергоэффективности двигателя**: IE3 минимум, IE4 предпочтительно

### 6.3. Учёт преференций (для гос-заказчика)

При формировании КП по 44-ФЗ:

1. Проверить, есть ли производитель в **реестре Минпромторг (gisp.gov.ru)** — если есть, применять понижающий коэф. 0.85 при сравнении с ним конкурентов.
2. Указать **код КТРУ** (Каталог товаров, работ, услуг) для соответствия НМЦК.
3. Приложить **выписку из реестра российской промышленной продукции** к коммерческому предложению.

## 7. Что калькулятор должен выдавать в BOM/спецификации

Минимальный набор данных по подобранному насосу:

```yaml
насос:
  модель: <code>
  производитель: <name>, страна_происхождения: <country>
  Q_рабочая_точка: <m3/h>
  H_рабочая_точка: <m>
  P_двигателя: <kW>
  N_двигателя: <RPM>
  напряжение: <V>
  IP: <code>
  материал_корпуса: <e.g. чугун СЧ20>
  материал_рк: <e.g. чугун + AISI 316>
  свободный_проход: <mm>  # для submersible
  тип_рк: <vortex|channel|cutter|centrifugal>
  NPSHr: <m>  # обязательно для horizontal
  КПД_при_BEP: <%>
  макс_частота_включений_в_час: <int>
  сертификаты:
    - ЕАС (ТР ТС 010/2011)
    - ТР ТС 004/2011
    - ТР ТС 020/2011
    - ТР ТС 012/2011 (если Ex)
  ГОСТ_испытаний: ГОСТ Р 53675-2009 (класс 2B)
  гарантия: 24 мес
  паспорт_url: <link>
  реестр_минпромторг: <yes|no>
  применимая_преференция_44фз: <0|15|30 %>
  цена_2026_рубRUB: <num>
  лед_тайм_дней: <num>
```
